## 概览 [#overview]

请在 {frameworkName(props.framework)} 与 Fumadocs 两端设置 i18n 路由。

Fumadocs 会负责文档内容与侧边栏的 i18n。应用的其他部分，请通过你自己的 i18n 设置来进行国际化。

<show when={props.framework === 'next'}>
  你也可以搭配 Fumadocs 使用 [next-intl](https://github.com/amannn/next-intl) 等函数库。如需了解基本概念，请参阅 [Next.js 的 i18n](https://nextjs.org/docs/app/building-your-application/routing/internationalization)。
</show>

## 设置 [#setup]

请在一个文件中定义 i18n 设置。本指南会以 `@/lib/i18n` 导入该设置。

<show when={props.framework === 'next'}>

  ```ts title="lib/i18n.ts"
    defaultLanguage: 'en',
    languages: ['en', 'cn'],
  });
  ```
</show>

<show when={props.framework === 'next'}>
  ### 中间件 [#middleware]

  创建一个中间件，将用户重定向到对应的语系。

  ```ts title="proxy.ts"
  import { createI18nMiddleware } from 'fumadocs-core/i18n/middleware';
  import { i18n } from '@/lib/i18n';

  export default createI18nMiddleware(i18n);

  export const config = {
    // Matcher ignoring `/_next/` and `/api/`
    // You may need to adjust it to ignore static assets in `/public` folder
    matcher: ['/((?!api|_next/static|_next/image|favicon.ico).*)'],
  };
  ```

  <Callout title="想使用自己的中间件？">
    默认的中间件并非必要。你也可以使用自己的中间件，或 i18n 函数库提供的中间件。

    请确认其行为与你在 i18n 设置中指定的 [`hideLocale`](/docs/headless/internationalization/config#hide-locale-prefix) 选项一致。
  </Callout>
</show>

### 搜索 [#search]

请在你使用的搜索方案中设置 i18n。

* **内置搜索：** 请参阅[国际化](/docs/headless/search/orama#internationalization)。
* **云端方案 (例如 Algolia) ：** 这类方案通常有官方的多语系支持。

## 编写文档 [#writing-documents]

请参阅 [i18n 路由](/docs/page-conventions#i18n-routing)，了解如何为特定语系创建页面。

### 导航 [#navigation]

Fumadocs 只会处理其自身布局 (例如侧边栏) 中的导航。

  ```tsx
  import Link from 'next/link';
  ```
