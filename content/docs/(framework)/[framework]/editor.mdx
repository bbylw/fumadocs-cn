## 简介 [#introduction]

[Fumadocs Editor](https://editor.fumadocs.dev) 是 Fumadocs MDX 的可视化编辑器。

### 从 Studio 开始 [#start-with-studio]

Studio 会在浏览器中打开你的本地文档，无须在应用中加入编辑器。
请在你的 Fumadocs 项目中运行：

```bash
npx @fumadocs-editor/studio
```

Studio 需要 **Node.js 24 或更新版本**。它会寻找 `content/docs`，若找不到，则改为在上层目录中寻找。
若要指定其他内容文件夹：

```bash
npx @fumadocs-editor/studio --root ./docs
```

编辑内容会自动保存至磁盘，你在代码编辑器中所做的变更也会合并至当前打开的文档。
文件列表会依照 `meta.json` 中的顺序排列。

请在 Git 中检阅变更，再通过网站平时使用的部署流程发布。

> Studio 只能编辑现有文件。若要创建、重命名或删除文件，请改用代码编辑器或文件管理员。

### 使用组件撰写 [#write-with-components]

内置编辑支持涵盖 Fumadocs 组件，例如 Callout、Cards、Steps、Accordions 和 Files。

自定义组件可通过[组件规格](https://editor.fumadocs.dev/components)定义专属的可编辑区域。

<Callout title="沿用你现有的内容设置">
  编辑器直接处理你的 Markdown 与 MDX 文件。你可以继续使用 [Fumadocs MDX](/docs/mdx) 加载
  这些文件，并通过你的 React 框架渲染发布后的网站。
</Callout>
