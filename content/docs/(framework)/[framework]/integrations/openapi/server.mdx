## OpenAPI 服务器 [#openapi-server]

Fumadocs OpenAPI 的主要设置。

> 请勿在浏览器环境中引用此设置。

### `input` [#input]

要读取的 OpenAPI schema。

* 文件路径
* 外部 URL
* 函数 (见下文) 

只有列在此处的 schema 才能加载；若传入 `getSchema()` 或由页面预先加载的是其他 ID，则会抛出错误。

<Callout type="warn">
  请勿将不受信任的 schema 传入 `input`，因为其中的 `$ref` 可以读取本地文件并截取 URL，私有主机也包含在内。
</Callout>

```ts tab="Basic"
import { createOpenAPI } from 'fumadocs-openapi/server';

export const openapi = createOpenAPI({
  input: ['./unkey.json'],
});
```

```ts tab="Functions"
import { createOpenAPI } from 'fumadocs-openapi/server';

export const openapi = createOpenAPI({
  input: {
    // [id]：已下载的 OpenAPI schema
    my_schema: async () => {
      const res = await fetch('https://registry.scalar.com/@scalar/apis/galaxy/latest?format=json');
      return res.json();
    },
  },
});
```

## 只加载一次文档 [#loading-documents-once]

页面会通过 props 接收完整的文档，因此每次加载页面、切换页面与预先截取时，都会重新发送整篇文档。若文档较大，建议将其排除：

```ts title="lib/openapi.ts"
import { createOpenAPI } from 'fumadocs-openapi/server';

export const openapi = createOpenAPI({
  // ID 最后会出现在 URL 中，请确保可安全用于 URL
  input: { museum: './museum.yaml' },
  includeDocument: false, // [!code ++]
});
```

<show when={props.framework !== 'tanstack-start'}>
  传入 `loadDocument`，即可让每份文档在每个浏览器工作阶段中只加载一次。它在服务端渲染时也会运行：
</show>

<show when={props.framework === 'next'}>
  ```tsx title="components/api-page.tsx"
  'use client';
  import { preload } from 'react-dom';
  import { createOpenAPIPage } from 'fumadocs-openapi/ui';

  export const OpenAPIPage = createOpenAPIPage({
    async loadDocument(id) {
      if (typeof window === 'undefined') {
        // 浏览器会在加载页面的同时开始下载它
        preload(`/api/openapi/${id}`, { as: 'fetch', crossOrigin: 'anonymous' });
        const { openapi } = await import('@/lib/openapi');
        return (await openapi.getSchema(id)).bundled;
      }
      return (await fetch(`/api/openapi/${id}`)).json();
    },
  });
  ```
</show>

<show when={props.framework === 'tanstack-start'}>
  TanStack Start 的路由加载器会同时在服务器与浏览器上运行，因此你的文档路由不需要 `loadDocument` 就能加载文档。只有在浏览器尚未取得文档时，才需要调用 server function：

  ```tsx title="src/routes/docs/$.tsx"
  import { createServerFn } from '@tanstack/react-start';
  import type { Document } from 'fumadocs-openapi';
  import { openapi } from '@/lib/openapi';

  // 浏览器已加载的文档
  const documents = new Map<string, Document>();

  const getDocument = createServerFn({ method: 'GET' })
    .validator((id: string) => id)
    .handler(async ({ data: id }) => (await openapi.getSchema(id)).bundled);

  export const Route = createFileRoute('/docs/$')({
    component: Page,
    loader: async ({ params }) => {
      const data = await serverLoader({ data: params._splat?.split('/') ?? [] });
      if (data.type === 'openapi') {
        const { document: id, payload } = data.props;
        payload.bundled = documents.get(id) ?? (await getDocument({ data: id }));
      }
      return data;
    },
  });

  function Page() {
    const page = useFumadocsLoader(Route.useLoaderData());
    // 第一个页面的文档也一并记录
    if (page.type === 'openapi' && typeof window !== 'undefined')
      documents.set(page.props.document, page.props.payload.bundled!);
    // ...
  }
  ```
</show>

## 创建代理服务器 [#creating-proxy]

代理服务器发送 HTTP 请求时不受浏览器的 CORS 限制。API 交互测试区会在以下情况使用它：

* 请求未通过 CORS 允许你的来源的 API 端点。
* 机密客户端 (具有 client secret) 的 OAuth 请求，以及设备授权流程。

<Callout type="warn">
  代理服务器是公开的，无须验证即可访问。它会转送请求的标头与 body，包括 `Authorization`。请使用 [`allowedOrigins`](#allowed-origins) 与 `filterRequest` 限制其访问。
</Callout>

### 设置 [#setup]

为代理服务器创建路由处理程序：

  ```ts title="app/api/proxy/route.ts"
  export const { GET, HEAD, PUT, POST, PATCH, DELETE } = openapi.createProxy();
  ```
</show>

<show when={props.framework === 'react-router'}>

  ```ts tab="app/routes/proxy.ts"
  import { openapi } from '@/lib/openapi';

  const proxy = openapi.createProxy();

  export const loader = ({ request }: Route.LoaderArgs) => proxy.handle(request);
  export const action = ({ request }: Route.ActionArgs) => proxy.handle(request);
  ```

  ```ts tab="app/routes.ts"

  export default [
    // [!code ++]
    route('api/proxy', 'routes/proxy.ts'),
    // ...
  ] satisfies RouteConfig;
  ```
</show>


### 允许的来源 [#allowed-origins]

代理服务器默认会接受任何公开来源，并拒绝私有网络上的主机 (例如 `localhost`) ，也不会转送你网站的 Cookie。
若要限制访问范围，或要代理私有 API，请在代理服务器路由中列出允许的来源：

```ts
openapi.createProxy({
  // 字符串或正则表达式
  allowedOrigins: ['https://api.example.com', 'http://localhost:8080'],
});
```

重定向也会依照相同的规则进行检查。

<Callout type="warn">
  封锁私有网络的功能需要 Node.js 或 Deno。若使用其他运行时 (例如 Bun) ，请指定
  `allowedOrigins`。
</Callout>

你可以使用 `filterRequest` 拒绝请求，例如只允许读取操作：

```ts
openapi.createProxy({
  // 返回 false 的代理请求会被拒绝
  filterRequest: (request) => request.method === 'GET',
});
```

## OAuth 重定向 [#oauth-redirect]

OAuth 提供者只接受已注册的重定向 URI，但 API 交互测试区默认会重定向到当前页面。
请创建一个路由处理程序，作为所有页面共用的重定向 URI。它会将用户导回发起流程的页面。

<show when={props.framework === 'next'}>
  ```ts title="app/api/oauth/route.ts"

  export const GET = openapi.createOAuthHandler();
  ```

</show>

<Callout title="内容安全政策（Content Security Policy）">
  处理程序会通过其自身路由提供的脚本将用户导回。若该路由受 Content Security Policy 规范，该政策必须允许 `'self'` 脚本。使用 `'strict-dynamic'` 的政策会忽略 `'self'`，因此请改为将该路由排除在这类政策之外。
</Callout>

### 静态网站 [#static-sites]

在静态网站中，路由会预先渲染为文件。请传入 `inline: true` 将脚本内嵌于页面中，并让路径以 `.html` 结尾，让静态主机将该文件视为 HTML 提供。
