## 简介 [#introduction]

Fumadocs Story 可用来展示组件并为其编写文档。
它是 [Storybook](https://storybook.js.org) 的轻量替代方案，以文档为内核，主要为组件库而设计。

如果你初次接触组件情境 (Story) 的概念，以下是 **Storybook** 文档中的简短说明：

<blockquote>
  组件情境记录了 UI 组件已渲染的状态。它是一个带有注解的对象，
  用来描述组件在给定一组参数时的行为与外观。
</blockquote>

<Callout title="何时该可选它，而不是 Storybook？">
  Fumadocs Story 并非用来取代 Storybook。若要进行完整的 UI 测试，我们仍建议使用 Storybook。
</Callout>

### 创建组件情境 [#create-a-story]

创建一个组件情境工厂，用来存放你的全域设置：

<show when={props.framework === 'next'}>
  ```ts title="lib/story.ts"
  import { defineStoryFactory } from '@fumadocs/story/next/client';

  export const { defineStory } = defineStoryFactory();
  ```
</show>

<show when={props.framework !== 'next'}>
  ```ts title="lib/story.ts"
  import { defineStoryFactory } from '@fumadocs/story/vite/client';

  export const { defineStory } = defineStoryFactory();
  ```
</show>

接着创建你的第一个组件情境：

<show when={props.framework === 'next' || props.framework === 'waku'}>
  ```tsx tab="my-component.story.tsx"
  import { defineStory } from '@/lib/story';
  import { MyComponent } from './my-component';

  export const story = defineStory({
    // 传入的组件必须是客户端组件
    Component: MyComponent,
    args: {
      // 默认 props（建议设置）
      initial: {},
    },
  });
  ```

  ```tsx tab="my-component.tsx"
  'use client';

  export interface MyComponentProps {
    title?: string;
  }

  export function MyComponent({ title }: MyComponentProps) {
    return <p>{title}</p>;
  }
  ```
</show>

<show when={props.framework !== 'next' && props.framework !== 'waku'}>
  ```tsx tab="my-component.story.tsx"
  import { defineStory } from '@/lib/story';
  import { MyComponent } from './my-component';

  export const story = defineStory({
    Component: MyComponent,
    args: {
      // 默认 props（建议设置）
      initial: {},
    },
  });
  ```

  ```tsx tab="my-component.tsx"
  export interface MyComponentProps {
    title?: string;
  }

  export function MyComponent({ title }: MyComponentProps) {
    return <p>{title}</p>;
  }
  ```

</show>

## 设置 [#configurations]

### 变体 [#variants]

你可以通过 `args` 为组件提供多个变体：

```ts
import { defineStory } from '@/lib/story';
import { Callout } from '@/components/callout';

export const story = defineStory({
  Component: Callout,
  args: [
    {
      variant: 'Default',
      initial: {
        title: 'This is a Callout',
      },
    },
    {
      variant: 'Warning',
      initial: {
        title: 'This is a Callout',
      },
      // props 的固定值
      fixed: {
        type: 'warning',
      },
    },
  ],
});
```

### `controls` [#controls]

控制项会根据组件的 props 自动生成。你可以指定控制项节点来取代它们：

```tsx
import { defineStory } from '@/lib/story';
import { GraphView } from '@/components/graph-view';

export const story = defineStory({
  Component: GraphView,
  args: {
    controls: {
      node: {
        type: 'object',
        properties: [],
      },
    },
  },
});
```

### `frame` [#frame]

填满整个 viewport 的组件 (例如布局) 可以在 iframe 中渲染。
组件情境面板会将 frame 缩小至合适的大小，并提供按钮让你以全屏幕打开。

```tsx title="components/my-layout.story.tsx"
import { defineStory } from '@/lib/story';
import { MyLayout } from './my-layout.lazy';
import { Window } from './window';

export const story = defineStory({
  Component: MyLayout,
  frame: {
    src: '/story/my-layout',
    // 查看区大小（选填）
    width: 1280,
    height: 800,
    // 包裹 frame 的容器，例如窗口（选填）
    Container: Window,
  },
});
```

在 `src` 创建一个页面来渲染组件。此页面会接收来自组件情境面板的参数：

只要页面渲染了组件情境，就会加载其组件。建议改为传入延迟加载的组件，让组件只在 frame 中加载：

<show when={props.framework === 'next'}>
  ```tsx title="components/my-layout.lazy.tsx"
  'use client';
  import dynamic from 'next/dynamic';

  export const MyLayout = dynamic(() => import('./my-layout').then((mod) => mod.MyLayout));
  ```
</show>

<show when={props.framework === 'waku'}>
  ```tsx title="components/my-layout.lazy.tsx"
  'use client';
  import { lazy } from 'react';

  export const MyLayout = lazy(() =>
    import('./my-layout').then((mod) => ({ default: mod.MyLayout })),
  );
  ```
</show>

<show when={props.framework !== 'next' && props.framework !== 'waku'}>
  ```tsx title="components/my-layout.lazy.tsx"
  import { lazy } from 'react';

  export const MyLayout = lazy(() =>
    import('./my-layout').then((mod) => ({ default: mod.MyLayout })),
  );
  ```
</show>

<Callout title="小提醒">
  * 此页面必须与你的文档位于相同来源 (origin) 。
  * 参数是通过 `postMessage()` 发送，因此必须可序列化 (不能包含函数或 JSX) 。

  <show when={props.framework === 'next' || props.framework === 'waku'}>
    - `Container` 必须是客户端组件。
  </show>
</Callout>

### 国际化 [#internationalization]

假设你已在 UI 层级设置好[国际化](/docs/internationalization)：

```tsx title="layout.shared.tsx"
import { defineI18n } from 'fumadocs-core/i18n';
import { uiTranslations } from 'fumadocs-ui/i18n';
import { storyTranslations } from '@fumadocs/story/i18n';

const i18n = defineI18n({
  languages: ['en', 'cn'],
  defaultLanguage: 'en',
});

export const translations = i18n
  .translations()
  .extend(uiTranslations())
  // [!code ++]
  .extend(storyTranslations())
  .add({
    cn: {
      displayName: 'Chinese',
      // [!code ++]
      'Add Item(story arguments form)': '添加项目',
    },
  });
```

详情请参阅[翻译](/docs/ui/translations)。
