---
title: Obsidian
description: 使用 Fumadocs 直接渲染 Obsidian vault。
---

`fumadocs-obsidian` 提供运行时的内容来源。它会直接读取并编译 vault，因此不会生成中介的 MDX 文件，也不需要 Fumadocs MDX 的 remark 插件。

支持的 Obsidian 语法包括：

* Wikilink 与嵌入。
* Callout。
* 块 ID。
* 注解。

名称有歧义的 wikilink 会比照 Obsidian 的方式解析：笔记优先于附件，其次以路径最短者为准。未知语言 (例如 `dataview`) 的代码块会以纯文字渲染。

## 设置 [#setup]

安装包：

```package-install
fumadocs-obsidian shiki
```

### 生成样式 [#generate-styles]

`fumadocs-obsidian/ui` 中的组件使用 Tailwind CSS 撰写样式。请加入以下这行，以生成这些组件所需的 class：

```css title="Tailwind CSS"
@import 'tailwindcss';
@import 'fumadocs-ui/css/neutral.css';
@import 'fumadocs-ui/css/preset.css';
/* [!code ++] */
@import 'fumadocs-obsidian/css/preset.css';
```

### 设置来源 [#configure-source]

创建 Obsidian 来源，并将它传入 `dynamicLoader()`：

```ts title="lib/source.ts"
import { dynamicLoader } from 'fumadocs-core/source';
import { obsidian } from 'fumadocs-obsidian';

const vault = obsidian({
  dir: 'public/vault',
  // 将 vault 附件对应到其公开 URL
  url: (path) => `/vault/${path}`,
});

const vaultLoader = dynamicLoader(vault.dynamicSource(), {
  baseUrl: '/docs',
});

export function getSource() {
  return vaultLoader.get();
}
```

此示例将 vault 放在 `public/vault`，让你的框架能通过 `url` 返回的 URL 提供附件。若你的应用会另行提供或上传附件，也可以将 vault 放在其他位置。

  import type { Route } from './+types/docs';

  import { DocsLayout } from 'fumadocs-ui/layouts/docs';

    const page = source.getPage(params['*'].split('/').filter((v) => v.length > 0));

    const renderer = useMemo(() => rendererFromSerialized(render), [render]);

    return (
      <DocsLayout tree={pageTree}>
        <DocsPage toc={toc}>
          <DocsBody>{body}</DocsBody>
        </DocsPage>
      </DocsLayout>
    );
  }

        </DocsLayout>

在同一个 vault 快照中，`page.data.load()` 对每个页面最多只会编译一次。Vault 内容会以纯 Markdown 编译：渲染时只会将其对应为 JSX 并解析组件名称，因此内容中的 JavaScript 一律不会运行。媒体文件通过 URL 参照，不会读入内存。

## 静态来源 [#static-source]

若 vault 只需读取一次，请使用 `staticSource()`：

```ts title="lib/source.ts"
import { loader } from 'fumadocs-core/source';
import { obsidian } from 'fumadocs-obsidian';

const vault = obsidian({
  dir: 'public/vault',
  url: (path) => `/vault/${path}`,
});

export const source = loader(await vault.staticSource(), {
  baseUrl: '/docs',
});
```

## Schema [#schema]

你可以使用兼容于 Standard Schema 的验证器，自定义页面的 frontmatter 与 `meta.json` 文件：

```ts title="lib/source.ts"
import { frontmatterSchema, obsidian } from 'fumadocs-obsidian';
import { metaSchema } from 'fumadocs-core/source/schema';
import { z } from 'zod';

const vault = obsidian({
  dir: 'public/vault',
  frontmatterSchema: frontmatterSchema.extend({
    tags: z.array(z.string()).optional(),
  }),
  metaSchema,
});
```

默认的 `frontmatterSchema` 能容许结构较松散的 vault：像 `title: 2024` 这类纯量标题会自动转换为字符串，而 `aliases` 可接受单一名称，也可接受列表。未通过验证的笔记会被回报并略过，不会影响 vault 中的其他内容。

### 额外功能 [#additions]

如需激活个别语法功能，请另外传入对应的 remark/rehype 插件：

* [Mermaid](/docs/markdown/mermaid)。
* [数学公式](/docs/markdown/math)。

```ts title="lib/source.ts"
import { obsidian } from 'fumadocs-obsidian';
import remarkMath from 'remark-math';
import rehypeKatex from 'rehype-katex';

const vault = obsidian({
  dir: 'public/vault',
  remarkPlugins: [remarkMath],
  rehypePlugins: [rehypeKatex],
});
```
