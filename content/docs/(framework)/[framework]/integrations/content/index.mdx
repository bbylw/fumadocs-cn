## 简介 [#introduction]

**Fumadocs 非常有弹性。** 你可以集成任何内容来源，即使没有官方适配器也没问题。

### 示例 [#examples]

以下是将 Fumadocs 搭配 CMS 使用的示例。CMS 能提供良好的内容发布体验，并可实时更新内容，无需重新构建应用。

* [BaseHub](https://github.com/fuma-nama/fumadocs-basehub)
* [Sanity](https://github.com/fuma-nama/fumadocs-sanity)
* [社区：Payload CMS (由 `MFarabi619` 提供) ](https://github.com/MFarabi619/fumadocs-payloadcms)
* [社区：Payload CMS (由 `bapspatil` 提供) ](https://github.com/bapspatil/fumadocs-payload-template)

还不够吗？[创建你自己的内容来源](/docs/integrations/content/custom)。
