## 概览 [#overview]

除了 `@fumadocs/asyncapi/ui` 之外，其余皆为无头式。

| 路径                              | 模块                        |
| ------------------------------- | ------------------------- |
| `@fumadocs/asyncapi`            | 页面：文档、其服务器，以及你的组件         |
| `@fumadocs/asyncapi/operation`  | 单一 operation：其频道、参数、消息与回复 |
| `@fumadocs/asyncapi/playground` | operation 频道上的工作阶段        |

## 页面 [#page]

`createAsyncAPIRenderer()` 会接收你的组件，并返回 `<AsyncAPIPage />`，该组件接受所生成页面的 props。

```tsx title="components/api-page.tsx"
'use client';
import { type CodeBlockProps, createAsyncAPIRenderer } from '@fumadocs/asyncapi';
import { Operation } from '@/components/my-operation';
import { SchemaUI } from '@/components/my-schema';

export const AsyncAPIPage = createAsyncAPIRenderer({
  components: {
    Operation,
    SchemaUI,
    CodeBlock({ lang, code }: CodeBlockProps) {
      return (
        <pre>
          <code className={`language-${lang}`}>{code}</code>
        </pre>
      );
    },
  },
});
```

| 组件          | 渲染内容                                         |
| ----------- | -------------------------------------------- |
| `Operation` | 页面中的每个 operation，请参阅 [Operation](#operation) |
| `SchemaUI`  | 参数、标头及消息负载的 JSON schema                      |
| `Layout`    | 可选，用来包覆已渲染的 operation                        |

### Hooks [#hooks]

页面底下的组件可以读取页面的状态。

| Hook                 | 返回值                   |
| -------------------- | --------------------- |
| `useAsyncAPI()`      | 已解参照的文档 (`doc`) 与页面选项 |
| `useComponents()`    | 传入页面的组件               |
| `useServer()`        | 服务器列表、当前选中的服务器及其变量    |
| `useRenderContext()` | 页面的渲染选项，例如 `content`  |

若要自行渲染 operation，请改为挂载 `<AsyncAPIProvider document={bundled} components={...} />`，以取代 `createAsyncAPIRenderer()`。

## Operation [#operation]

`<OperationProvider />` 只会推导一次 operation 的详细信息：应用 traits，并解析其频道、参数、消息与回复。

```tsx title="components/my-operation.tsx"
'use client';
import {
  OperationProvider,
  type PageOperationProps,
  useOperation,
  useOperationSecurity,
} from '@fumadocs/asyncapi/operation';

export function Operation(props: PageOperationProps) {
  return (
    <OperationProvider {...props}>
      <Content />
    </OperationProvider>
  );
}

function Content() {
  const { title, channel, parameters, messages } = useOperation();
  const security = useOperationSecurity();

  return (
    <>
      <h2>{title}</h2>
      <code>{channel.address}</code>
      <ul>
        {parameters.map((param) => (
          <li key={param.name}>{param.name}</li>
        ))}
      </ul>
      {messages.map((message) => (
        <section key={message.id}>
          <h3>{message.name}</h3>
          {message.examples.map((example) => (
            <pre key={example.id}>{JSON.stringify(example.payload, null, 2)}</pre>
          ))}
        </section>
      ))}
      <p>{security.operation.map((item) => item.id).join(', ')}</p>
    </>
  );
}
```

| Hook                     | 返回值                                |
| ------------------------ | ---------------------------------- |
| `useOperation()`         | 已解析详细信息的 operation                 |
| `useOperationSecurity()` | 所选服务器与该 operation 的安全性方案 (两者都会应用)  |
| `useChannelMessages()`   | 读者在该频道上接收与发送的消息，涵盖该频道的所有 operation |

## 交互测试区 [#playground]

`usePlayground()` 会在 `<OperationProvider />` 之下，通过传输层连接至 operation 的频道。

```tsx
'use client';
import { usePlayground } from '@fumadocs/asyncapi/playground';
import { mqttTransport } from '@/lib/mqtt-transport';

export function Playground() {
  const { url, status, connect, disconnect, send, log } = usePlayground({
    // 叠加在页面的 `playground.transports` 之上
    transports: { mqtt: mqttTransport },
  });
  if (!url) return null; // 此服务器没有可用的传输层

  return (
    <>
      <button onClick={status === 'closed' ? connect : disconnect}>{status}</button>
      {send && <button onClick={() => send('{"type":"ping"}')}>Ping</button>}
      {log.map((entry) => (
        <p key={entry.id}>
          {entry.type} {entry.message?.name} {entry.data}
        </p>
      ))}
    </>
  );
}
```

* 地址参数、query 与验证输入都属于表单 `stf`，`url` 会随其值更新。
* 连接期间即可使用 `send`，除非该连接仅能接收消息。
* 收到的消息会与频道上各消息的负载进行比对，`entry.message` 即为对应的文档化消息；二进位消息则存放于 `entry.binary`。

### 传输层 [#transports]

传输层负责连接至某个协定的服务器，示例请参考 [MQTT 示例](/docs/integrations/asyncapi/api-page#custom-transports)。系统会依序从 `usePlayground()` 的 `transports`、页面的 `playground.transports` 中选取，最后才使用内置的 WebSocket 传输层。

`usePlaygroundTransport()` 接受相同的 `transports`，并返回所选服务器对应的传输层；若没有任何传输层能连接至该服务器，则返回 `undefined`。
