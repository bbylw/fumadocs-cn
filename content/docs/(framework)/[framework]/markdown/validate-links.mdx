## 设置 [#setup]

你可以使用 [`next-validate-link`](https://next-validate-link.vercel.app) 验证内容文件中的链接。

> 本指南主要以 **Fumadocs MDX** 为主，其他设置方式请参阅 `next-validate-link` 的文档。

创建一个脚本来扫描应用的路由，并通过 `populate` 列出文档路由的参数：

<show when={props.framework === 'next'}>
  ```ts title="scripts/lint.ts"
  import { type FileObject, printErrors, scanURLs, validateFiles } from 'next-validate-link';
  import { source } from '@/lib/source';

  const scanned = await scanURLs({
    preset: 'next',
    populate: {
      'docs/[[...slug]]': source.getPages().map((page) => ({
        value: { slug: page.slugs },
        hashes: getHeadings(page.data),
      })),
    },
  });
  ```
</show>

<show when={props.framework === 'react-router'}>
  ```ts title="scripts/lint.ts"
  import { type FileObject, printErrors, scanURLs, validateFiles } from 'next-validate-link';
  import { source } from '@/lib/source';
  import routes from '../app/routes';

  const scanned = await scanURLs({
    preset: 'react-router',
    routerConfig: routes,
    populate: {
      // async 集合会在加载内容时一并加载目录
      'docs/[[...splat]]': await Promise.all(
        source.getPages().map(async (page) => ({
          value: { splat: page.slugs },
          hashes: getHeadings(await page.data.load()),
        })),
      ),
    },
  });
  ```
</show>

接着在同一个脚本中，以扫描到的 URL 验证你的内容文件：

```ts title="scripts/lint.ts"
import type { TOCItemType } from 'fumadocs-core/toc';

printErrors(
  await validateFiles(await getFiles(), {
    scanned,
    // 检查各种 MDX 组件中的 `href` 属性
    markdown: {
      components: {
        Card: { attributes: ['href'] },
      },
    },
    // 检查相对路径
    checkRelativePaths: 'as-url',
  }),
  true,
);

function getHeadings({ toc }: { toc: TOCItemType[] }): string[] {
  return toc.map((item) => item.url.slice(1));
}

function getFiles() {
  const promises = source.getPages().map(async (page): Promise<FileObject> => ({
    path: page.absolutePath,
    content: await page.data.getText('raw'),
    url: page.url,
    data: page.data,
  }));

  return Promise.all(promises);
}
```

### 运行 Lint [#running-lint]

若要在应用运行时之外访问 `source` 对象，请为 Bun 设置 [Fumadocs MDX 加载器](/docs/mdx/loader/bun)。

接着，运行脚本来验证链接：

```bash
bun ./scripts/lint.ts
```

<Callout title="Node.js 加载器">
  你可能需要设置 TypeScript 转译 (或改用较新版本的 Node.js) ，以及 [Fumadocs MDX 加载器](/docs/mdx/loader/node)。

  若无特殊需求，直接使用 Bun 或 [`tsx`](https://github.com/privatenumber/tsx) 会比较简单。
</Callout>
