## 使用方式 [#usage]

```npm
npx create-fumadocs-app@latest my-docs
```

运行时会询问要使用的模板与要设置的功能，你也可以直接通过选项传入。

### 选项 [#options]

| 选项                  | 说明                                                                                                 |
| ------------------- | -------------------------------------------------------------------------------------------------- |
| `--template <name>` | 要使用的模板，请参阅[模板](#templates)。                                                                        |
| `--src`             |  (仅限 Next.js) 使用 `src/` 目录。                                                                        |
| `--linter <name>`   | 设置 linter：`eslint` (仅限 Next.js) 、`oxlint` 或 `biome`。                                               |
| `--search <name>`   | 搜索方案：`orama` (默认，本地搜索) 、`orama-cloud`、`algolia`、`meilisearch`、`typesense` 或 `mixedbread` (需要服务器) 。 |
| `--og-image <name>` | OG 图片：`next-og` (仅限 Next.js) 或 `takumi`，其他框架一律使用 Takumi。                                           |
| `--ai-chat <name>`  | AI 聊天：`openrouter`、`llmgateway` 或 `inkeep`，不适用于静态、SPA 及 Astro 模板。                                  |
| `--install`         | 自动安装依赖包。                                                                                          |
| `--no-git`          | 略过 Git 保存库初始化。                                                                                     |
| `--pm <name>`       | 包管理器：`npm`、`pnpm`、`yarn` 或 `bun`，会依据调用 CLI 的方式自动侦测。                                               |
| `-y, --yes`         | 略过交互提示，未指定的选项一律使用默认值。                                                                              |

### 模板 [#templates]

| 值                            | 说明                     |
| ---------------------------- | ---------------------- |
| `+next+fuma-docs-mdx`        | Next.js (默认)           |
| `+next+fuma-docs-mdx+static` | 采用静态导出的 Next.js        |
| `waku`                       | Waku                   |
| `react-router`               | React Router           |
| `react-router-spa`           | SPA 模式的 React Router   |
| `tanstack-start`             | TanStack Start         |
| `tanstack-start-spa`         | SPA 模式的 TanStack Start |
| `astro`                      | Astro                  |

### 非交互模式 [#non-interactive]

传入 `--yes` 即可略过所有提示，适合在脚本、CI 及 AI 代理中使用：

```npm
npx create-fumadocs-app@latest my-docs --template +next+fuma-docs-mdx --install --yes
```

未指定的选项会使用默认值：不使用 linter、使用本地搜索、不启用 AI 聊天。若目标目录已存在且不是空的，指令会运行失败。

模板没有提供 i18n 选项。若要为新项目加入 i18n，请参考对应框架的国际化指南：[Next.js](/docs/next/internationalization)、[React Router](/docs/react-router/internationalization)、[TanStack Start](/docs/tanstack-start/internationalization)、[Waku](/docs/waku/internationalization) 或 [Astro](/docs/astro/internationalization)。

## 程序化 API [#programmatic-api]

除了传统的 CLI 用法之外，你也可以在脚本中使用它，例如：

```npm
npm install create-fumadocs-app
```

```ts
import { create } from 'create-fumadocs-app';

await create({
  outputDir: 'my-app',
  template: '+next+fuma-docs-mdx',
  packageManager: 'pnpm',
});
```
