---
title: 预览
description: 用来检视 Markdown 档案的轻量工具。
---

`fumadocs-preview` 可让您使用 Fumadocs 检视 Markdown 档案，很适合用来阅读 skills 档案与笔记。

请在您的专案目录下执行此指令。

```npm
npx fumadocs-preview dir/to/content
```
如需其他设定，您可以在本机安装：

```npm
npm install fumadocs-preview -D
```

接著初始化设定档：

```npm
npx fumadocs-preview init
```
