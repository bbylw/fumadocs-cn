## 简介 [#introduction]

`fumadocs-preview` 可让你使用 Fumadocs 查看 Markdown 文件，很适合用来阅读 skills 文件与笔记。

请在你的项目目录下运行此指令。

```npm
npx fumadocs-preview dir/to/content
```

### 设置 [#configurations]

如需其他设置，你可以在本地安装：

```npm
npm install fumadocs-preview -D
```

接着初始化配置文件：

```npm
npx fumadocs-preview init
```
