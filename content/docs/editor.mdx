[Fumadocs Editor](https://editor.fumadocs.dev) 是 Fumadocs MDX 的视觉化编辑器。

### 从 Studio 开始 [#start-with-studio]

Studio 会在浏览器中开启您的本机文件，无须在应用程式中加入编辑器。
请在您的 Fumadocs 专案中执行：

```bash
npx @fumadocs-editor/studio
```

Studio 需要 **Node.js 24 或更新版本**。它会寻找 `content/docs`，若找不到，则改为在上层目录中寻找。
若要指定其他内容资料夹：

```bash
npx @fumadocs-editor/studio --root ./docs
```

编辑内容会自动储存至磁碟，您在程式码编辑器中所做的变更也会合并至目前开启的文件。
档案清单会依照 `meta.json` 中的顺序排列。

请在 Git 中检阅变更，再透过网站平时使用的部署流程发布。

> Studio 只能编辑现有档案。若要建立、重新命名或删除档案，请改用程式码编辑器或档案管理员。

### 使用元件撰写 [#write-with-components]

内建编辑支援涵盖 Fumadocs 元件，例如 Callout、Cards、Steps、Accordions 和 Files。

自订元件可透过[元件规格](https://editor.fumadocs.dev/components)定义专属的可编辑区域。

<Callout title="沿用您现有的内容设定">
  编辑器直接处理您的 Markdown 与 MDX 档案。您可以继续使用 [Fumadocs MDX](/docs/mdx) 载入
  这些档案，并透过您的 React 框架算绘发布后的网站。
</Callout>
