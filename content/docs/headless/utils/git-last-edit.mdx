## 使用方式 [#usage]

请传入你的保存库名称及文件路径。

```ts
import { getGithubLastEdit } from 'fumadocs-core/content/github';

const time = await getGithubLastEdit({
  owner: 'fuma-nama',
  repo: 'fumadocs',
  // 示例："content/docs/index.mdx"
  path: `content/docs/${page.path}`,
});
```

### Github Token [#github-token]

请注意，在开发模式下很容易就会达到速率限制，因此建议你传入 Github token，以取得较高的速率限制。

进一步了解
[向 REST API 进行验证](https://docs.github.com/en/rest/overview/authenticating-to-the-rest-api)。

```ts
import { getGithubLastEdit } from 'fumadocs-core/content/github'

 const time = await getGithubLastEdit({
    ...,
    token: `Bearer ${process.env.GIT_TOKEN}`
  })
```

此外，若你在开发模式下不需要此功能，也可以略过这个步骤。

```ts
process.env.NODE_ENV === 'development'? null : getGithubLastEdit(...)
```

### 自定义 GitHub 基础 URL [#custom-github-base-url]

如果你需要访问的 GitHub 运行个体位于 `https://api.github.com` 以外的 URL，可以覆盖基础 URL：

```ts
import { getGithubLastEdit } from 'fumadocs-core/content/github';

const time = await getGithubLastEdit({
  owner: 'your-org',
  repo: 'your-repo',
  path: `content/docs/${page.path}`,
  baseUrl: 'https://api.octocorp.ghe.com', // 你的自定义 GitHub API URL
});
```

若未指定，`baseUrl` 参数的默认值为 `'https://api.github.com'`。
