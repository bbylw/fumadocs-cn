## 概览 [#overview]

`fumadocs-core/server` 会将 React 服务器组件渲染为 Markdown 文档：

```tsx tab="Input"
import { renderToMarkdown } from 'fumadocs-core/server';

const text = await renderToMarkdown(
  <div>
    <h2>Hello World</h2>
    <p>
      Some <b>rich</b> content.
    </p>
  </div>,
);
```

```md tab="Output"
## Hello World

Some **rich** content.
```

[Remark LLMs](/docs/headless/mdx/remark-llms#jsx-elements) 所导出的组件即以它为基础运作；凡是你想以 Markdown 形式提供的服务端渲染内容，也都能使用它。

> `renderToMarkdown()` 仅能在服务端使用。

## `asMarkdown` [#asmarkdown]

组件会自行定义其 Markdown 形式。在渲染期间调用 `asMarkdown()` 即代表选择启用此功能：当组件正被渲染为 Markdown 时，它会返回对应的[目标](#targets)，且组件返回的 HTML 元素会一并转换。

```tsx
import { asMarkdown, md } from 'fumadocs-core/server';

function Callout({ title, children }) {
  if (asMarkdown()) return md.linePrefix('> ')`**${title}**\n${children}`;

  return <div className="...">...</div>;
}
```

未调用它的组件会以 JSX 语法连同其 props 一并保留，例如：

```mdx
<Tabs items={['a', 'b']}>...</Tabs>
```

这也包括不会在服务器上运行的客户端组件。

### 目标 [#targets]

树会针对某个目标进行渲染，也就是 `renderToMarkdown()` 的 `target` 选项：

* `markdown` (默认) ：提供给 AI 代理的文档。
* `search`：[搜索记录](/docs/headless/mdx/structure#components)的文字。其中保留链接的文字，但不含图片与代码块；没有 Markdown 形式的组件会输出为 HTML 标签，并附上其文字 props。

这些规则适用于组件返回的元素，例如 `<a href>`。若在 `md` 模板中以纯文字撰写链接，搜索结果仍会保留其链接目标，因此请返回元素，或自行检查目标。

`asMarkdown()` 会返回当前的目标，因此组件可以提供给 AI 代理比搜索索引更多的内容：

```tsx
import { asMarkdown, md } from 'fumadocs-core/server';

function Version({ name, released }) {
  const target = asMarkdown();
  if (target === 'search') return name;
  if (target) return md`${name} (released ${released})`;

  return <span title={released}>{name}</span>;
}
```

## `md` [#md]

用于输出 Markdown 的标签样板 (tagged template) ，插值可以是字符串、React 节点、Promise，或由它们组成的数组。你可以先用它将 `children` 转为字符串，再进行处理。

以下两种变体会以块形式返回内容：

* `md.linePrefix(prefix)`：为每一行加上前缀，例如以 `'> '` 创建引用块。
* `md.indent(size)`：将每一行缩进。

## `renderRoute` [#renderroute]

将页面元素渲染为 Markdown；若其组件未调用 `asMarkdown()`，则返回 `undefined`。

```tsx
import { renderRoute } from 'fumadocs-core/server';

const text = await renderRoute(<Page params={params} />);
```

适合用来提供路由的 Markdown 版本：有选择启用的页面会生成 Markdown，其他页面则返回 `undefined`，让你可以改为返回 404 或改用其他来源。
