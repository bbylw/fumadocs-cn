---
title: Markdown 算绘
description: 将 React 元素算绘为 Markdown。
---

`fumadocs-core/server` 会将 React 伺服器元件算绘为 Markdown 文件：

```tsx tab="Input"
import { renderToMarkdown } from 'fumadocs-core/server';

const text = await renderToMarkdown(
  <div>
    <h2>Hello World</h2>
    <p>
      Some <b>rich</b> content.
    </p>
  </div>,
);
```

```md tab="Output"
## Hello World

Some **rich** content.
```

[Remark LLMs](/docs/headless/mdx/remark-llms#jsx-elements) 所汇出的元件即以它为基础运作；凡是您想以 Markdown 形式提供的伺服器端算绘内容，也都能使用它。

> `renderToMarkdown()` 仅能在伺服器端使用。

## `asMarkdown` [#asmarkdown]

元件会自行定义其 Markdown 形式。在算绘期间呼叫 `asMarkdown()` 即代表选择启用此功能：当元件正被算绘为 Markdown 时，它会回传对应的[目标](#targets)，且元件回传的 HTML 元素会一并转换。

```tsx
import { asMarkdown, md } from 'fumadocs-core/server';

function Callout({ title, children }) {
  if (asMarkdown()) return md.linePrefix('> ')`**${title}**\n${children}`;

  return <div className="...">...</div>;
}
```

未呼叫它的元件会以 JSX 语法连同其 props 一并保留，例如：

```mdx
<Tabs items={['a', 'b']}>...</Tabs>
```

这也包括不会在伺服器上执行的用户端元件。

### 目标 [#targets]

树会针对某个目标进行算绘，也就是 `renderToMarkdown()` 的 `target` 选项：

* `markdown` (预设) ：提供给 AI 代理的文件。
* `search`：[搜寻纪录](/docs/headless/mdx/structure#components)的文字。其中保留连结的文字，但不含图片与程式码区块；没有 Markdown 形式的元件会输出为 HTML 标签，并附上其文字 props。

这些规则适用于元件回传的元素，例如 `<a href>`。若在 `md` 范本中以纯文字撰写连结，搜寻结果仍会保留其连结目标，因此请回传元素，或自行检查目标。

`asMarkdown()` 会回传目前的目标，因此元件可以提供给 AI 代理比搜寻索引更多的内容：

```tsx
import { asMarkdown, md } from 'fumadocs-core/server';

function Version({ name, released }) {
  const target = asMarkdown();
  if (target === 'search') return name;
  if (target) return md`${name} (released ${released})`;

  return <span title={released}>{name}</span>;
}
```
用于输出 Markdown 的标签样板 (tagged template) ，插值可以是字串、React 节点、Promise，或由它们组成的阵列。您可以先用它将 `children` 转为字串，再进行处理。

以下两种变体会以区块形式回传内容：

* `md.linePrefix(prefix)`：为每一行加上前缀，例如以 `'> '` 建立引用区块。
* `md.indent(size)`：将每一行缩排。

## `renderRoute` [#renderroute]

将页面元素算绘为 Markdown；若其元件未呼叫 `asMarkdown()`，则回传 `undefined`。

```tsx
import { renderRoute } from 'fumadocs-core/server';

const text = await renderRoute(<Page params={params} />);
```

适合用来提供路由的 Markdown 版本：有选择启用的页面会产生 Markdown，其他页面则回传 `undefined`，让您可以改为回传 404 或改用其他来源。
