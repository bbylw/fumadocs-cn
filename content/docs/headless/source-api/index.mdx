---
title: 载入器 API
description: 将内容来源转换为统一的介面
---

`loader()` 提供一个介面，让 Fumadocs 能与各种内容来源整合。

* 产生[页面 slug 与页面树](/docs/headless/page-conventions)。
* 为每个页面指派 URL。
* 提供实用的工具函式，方便您操作内容。

<Callout type="warn" title="重要须知">
  - `loader()` 是伺服器端 API，既不是建置时期的魔法，也不是可在浏览器中使用的 API。
  - 它采用记忆体内储存，档案由您的内容来源传入。
</Callout>

## 使用方式 [#usage]

您可以搭配 Fumadocs MDX 等内容来源使用，详情请参阅 [`source`](/docs/headless/source-api/source)。

```ts
import { loader } from 'fumadocs-core/source';
import { docs } from 'collections/server';

export const source = loader({
  source: docs.toFumadocsSource(),
  baseUrl: '/docs',
});
```
您可以覆写基础 URL，或指定一个函式来产生每个页面的 URL。

```ts
import { loader } from 'fumadocs-core/source';

loader({
  baseUrl: '/docs',
  // 或者您也可以使用函式自订
  url(slugs, locale) {
    if (locale) return '/' + [locale, 'docs', ...slugs].join('/');
    return '/' + ['docs', ...slugs].join('/');
  },
});
```
定义自订函式，用来根据页面档案产生 slug。

```ts
import { loader } from 'fumadocs-core/source';

loader({
  slugs(file, next) {
    console.log(file.path, file.data);
    // 您可以透过 `next()` 在预设 slug 的基础上扩充
    if (file.path.startsWith('blog/')) return ['blog', ...next()];
    // 或回传 `undefined` 以改用预设值
    return ['my', 'slug'];
  },
});
```
载入页面与 meta 档案中指定的 [icon](/docs/headless/page-conventions#icons) 属性。

```ts
import { loader } from 'fumadocs-core/source';
import { icons } from 'lucide-react';
import { createElement } from 'react';

loader({
  icon(icon) {
    if (!icon) {
      // 您可以设定预设图示
      return;
    }

    if (icon in icons) return createElement(icons[icon as keyof typeof icons]);
  },
});
```
请将 `i18n` 设定传入载入器。

```ts title="lib/source.ts"
import { i18n } from '@/lib/i18n';
import { loader } from 'fumadocs-core/source';

export const source = loader({
  i18n, // [!code highlight]
});
```

启用 i18n 后，载入器会为每个语系产生一个页面树。

若某个页面缺少翻译，则会改用 [`fallbackLanguage`](/docs/headless/internationalization/config#fallback-language) 作为备用语系。

## 输出 [#output]

它会输出一个内容载入器实例。

### 取得页面 [#get-page]

依据 slugs 取得页面。

```ts
import { source } from '@/lib/source';

source.getPage(['slug', 'of', 'page']);

// 使用 i18n 时
source.getPage(['slug', 'of', 'page'], 'locale');
```
您可以将 props 传入页面内容，例如读者所选的版本。内容会透过 `props` 读取这些值，用法与[路径参数](/docs/headless/page-conventions#path-params)相同：

```ts
import { source } from '@/lib/source';

const page = source.getPage(['slug', 'of', 'page'], {
  props: { version: 'v2' },
  // 使用 i18n 时
  language: 'locale',
});
```

页面资料 (包括内容与目录) 是根据这些 props 产生的。MDX 元件也属于 props；若希望处理后的 Markdown 能算绘出您的元件，请将它们传入：

```ts
import { getMDXComponents } from '@/components/mdx';

const page = source.getPage(['slug', 'of', 'page'], {
  props: { components: getMDXComponents() },
});
const markdown = await page.data.getText('processed');
```

<Callout title="小提醒">
  搜寻与 LLM 路由是透过 `getPages()` 读取页面，而这些页面只带有路径参数。若要让搜寻或 LLM 看到某个变体，该变体就必须是路径参数。
</Callout>

### 取得页面 [#get-pages]

取得指定语系下可用的页面清单。

```ts
import { source } from '@/lib/source';

// 取得所有语系的页面
source.getPages();

// 取得特定语系的页面
source.getPages('locale');
```
```ts
import { source } from '@/lib/source';

// 未使用 i18n
source.getPageTree();

// 使用 i18n
source.getPageTree('locale');
```
页面树的节点会保留指向其原始档案路径的参照。
您可以透过树状节点找到对应的原始页面或 meta 档案。

```ts
import { source } from '@/lib/source';

source.getNodePage(pageNode);
source.getNodeMeta(folderNode);
```
产生每个页面的路径参数，以便预先算绘页面。
产生的参数名称为 `slug: string[]` 与 `lang: string` (仅限 i18n) 。

```ts tab="Next.js" title="app/docs/[[...slug]]/page.tsx"
import { source } from '@/lib/source';

export function generateStaticParams() {
  return source.generateParams();
}
```

```ts tab="Waku" title="src/pages/docs/[...slugs].tsx"
import { source } from '@/lib/source';

export async function getConfig() {
  const pages = source
    .generateParams()
    .map((item) => (item.lang ? [item.lang, ...item.slug] : item.slug));

  return {
    render: 'static' as const,
    staticPaths: pages,
  } as const;
}
```

```astro tab="Astro" title="src/pages/docs/[...slug].astro"
---
import type { GetStaticPaths } from 'astro';
import { source } from '@/lib/source';

export const prerender = true;

export const getStaticPaths = (() => {
  return source.getPages().map((page) => ({
    params: { slug: decodeURI(page.slugs.join('/')) || undefined },
    props: { page },
  }));
}) satisfies GetStaticPaths;
---
```

React Router 与 TanStack Start 是依 URL 进行预先算绘，因此请改为列出 `source.getPages()` 各页面的 `url`。

### 语言项目 [#language-entries]

取得所有可用的语言及其对应页面。

```ts
import { source } from '@/lib/source';

// 语言 -> 页面
const entries = source.getLanguages();
```
载入器 API 最适合在 RSC 环境中使用，因为 RSC 允许跨越伺服器与用户端的边界传递 JSX 节点。

在非 RSC 环境中，载入器 API 则提供一个轻量的序列化层。

```ts tab="Server"
import { source } from '@/lib/source';

// 在此传递 loader 资料
async function loader() {
  const pageTree = source.getPageTree();

  return {
    pageTree: await source.serializePageTree(pageTree),
  };
}
```

```tsx tab="Client"
import { useFumadocsLoader } from 'fumadocs-core/source/client';

function MyComponent() {
  // `useLoaderData()` 会取得 loader 资料（由您的 React 框架提供）
  const { pageTree, ...data } = useFumadocsLoader(useLoaderData());

  // 接著进行算绘（例如透过 Fumadocs UI）
  return <DocsLayout tree={pageTree}>...</DocsLayout>;
}
```
`dynamicLoader()` 可为内容来源提供额外的重新验证功能，请搭配 [Dynamic 来源](/docs/headless/source-api/source#dynamic-source)使用。

```ts
import { dynamicLoader } from 'fumadocs-core/source';
import { createMySource } from './my-source';

const source = dynamicLoader(createMySource(), {
  baseUrl: '/docs',
});

export async function getSource() {
  return source.get();
}
```

呼叫 `await source.get()` 时，会回传一个一般的内容载入器物件：

```ts
const docs = await getSource();

const page = docs.getPage(['...']);
```
载入器会快取 Dynamic 来源。

如果您的来源会随时间变动，请呼叫 `invalidate()` 清除快取，或呼叫 `revalidate()` 更新快取：

```ts
source.invalidate();

await source.revalidate();
```

若采用[多来源](/docs/headless/source-api/source#multiple-sources)的设定，您可以针对特定来源进行失效 (invalidate) 或重新验证 (revalidate) ：

```ts
source.invalidate('docs');

await source.revalidate('docs');
```
