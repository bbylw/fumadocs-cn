## 概览 [#overview]

加载器插件可以扩展 `loader()`，以自定义其输出结果。

内置插件列表：

* **Lucide Icons**：使用 [Lucide React](https://lucide.dev) 提供的图标 (需先安装 `lucide-react`) 。

  ```ts
  import { loader } from 'fumadocs-core/source';
  import { lucideIconsPlugin } from 'fumadocs-core/source/lucide-icons';

  export const source = loader({
    // ...
    plugins: [lucideIconsPlugin()],
  });
  ```

## 创建插件 [#creating-plugins]

每个插件都是一个对象：

```ts tab="Strictly Typed"
import { loader } from 'fumadocs-core/source';

export const source = loader({
  plugins: ({ typedPlugin }) => [
    typedPlugin({
      // 插件设置
    }),
  ],
});
```

```ts tab="Simple"
import { loader, type LoaderPlugin } from 'fumadocs-core/source';

export const source = loader({
  plugins: [myPlugin()],
});

function myPlugin(): LoaderPlugin {
  return {
    // 插件设置
  };
}
```

<Callout title="小提示">
  `typedPlugin` 会为插件应用更精确的类型，包括你内容来源中的自定义属性。

  不过，若要让插件能在不同的加载器之间重复使用，请改用 `LoaderPlugin` 类型。
</Callout>

### 保存空间 [#storage]

在处理过程中，你输入的来源文件会被解析，并在内存中形成虚拟保存空间。

若要在处理之前运行虚拟文件系统操作，你可以使用 `transformStorage` hook。

```ts
import { loader } from 'fumadocs-core/source';

export const source = loader({
  plugins: ({ typedPlugin }) => [
    typedPlugin({
      transformStorage({ storage }) {
        storage.read('my/path');
      },
    }),
  ],
});
```

### 页面树 [#page-tree]

页面树会根据你的文件系统生成，并过滤掉部分不必要的信息 (例如未使用的 frontmatter 属性) 。

你可以通过 `transformPageTree` 自定义页面树，例如为节点附加自定义属性，或自定义页面的显示名称。

```tsx
import { loader } from 'fumadocs-core/source';

export const source = loader({
  plugins: ({ typedPlugin }) => [
    typedPlugin({
      transformPageTree: {
        file(node, file) {
          // 访问原始（未经过滤的）文档数据
          if (file) console.log(this.storage.read(file));

          // 修改节点
          node.name = <>Some JSX Nodes here</>;
          return node;
        },
      },
    }),
  ],
});
```
