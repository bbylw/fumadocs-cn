## 概览 [#overview]

内容加载器通过 `source` 界面，可接受各种不同的内容来源。

### 多个来源 [#multiple-sources]

请改为传入由多个来源对象组成的对象 (Record) 

```ts
import { loader } from 'fumadocs-core/source';
import { blog, docs } from 'collections/server';
import { lucideIconsPlugin } from 'fumadocs-core/source/lucide-icons';

export const source = loader(
  {
    docs: docs.toFumadocsSource(),
    openapi: blog.toFumadocsSource(),
  },
  {
    baseUrl: '/docs',
  },
);
```

若要访问各个来源专属的属性：

```ts
const page = source.getPage(['...']);

if (page.type === 'docs') {
  console.log(page.data);
} else {
  console.log(page.data);
}
```

### 静态来源 [#static-source]

若要接入你自己的内容来源，请创建 `StaticSource` 对象。

由于加载器 API 不依赖文件系统，文件路径仅能使用虚拟路径，例如 `file.mdx` 和 `content/file.mdx`；`./file.mdx` 和 `D://content/file.mdx` 则不允许使用。

```ts twoslash
import type { StaticSource } from 'fumadocs-core/source';

export function createMySource(): StaticSource<{
  metaData: { title: string; pages: string[] }; // 你的自定义类型
  pageData: { title: string; description?: string }; // 你的自定义类型
}> {
  return {
    files: [
      {
        type: 'page',
        path: 'folder/index.mdx',
        data: {
          title: 'Hello World',
          // ...
        },
      },
      {
        type: 'meta',
        path: 'meta.json',
        data: {
          title: 'Docs',
          pages: ['folder'],
          // ...
        },
      },
    ],
  };
}
```

激活 [i18n](/docs/headless/internationalization/config) 时，除非文件有指定 `locale`，否则文件的语言会从其路径解析而来。

### Dynamic 来源 [#dynamic-source]

若内容来源支持重新验证 (revalidation) ，请改为返回 `DynamicSource`：

```ts
import type { DynamicSource } from 'fumadocs-core/source';

export function createMySource(): DynamicSource<{
  metaData: { title: string; pages: string[] };
  pageData: { title: string; description?: string };
}> {
  return {
    async files() {
      return [
        {
          type: 'page',
          path: 'folder/index.mdx',
          data: {
            title: 'Hello World',
          },
        },
        {
          type: 'meta',
          path: 'meta.json',
          data: {
            title: 'Docs',
            pages: ['folder'],
          },
        },
      ];
    },
    configure(loader) {
      // 你可以在来源中重新验证加载器，例如：
      onMyEvent(() => {
        void loader.revalidate();
      });
    },
  };
}
```

Dynamic 来源只能交由 [`dynamicLoader()`](/docs/headless/source-api#dynamic-loader) 使用。

## 路径参数 [#path-params]

若要在你的来源中支持[路径参数](/docs/headless/page-conventions#path-params)，请将 `[framework]/deploy.mdx` 这类文件作为单一虚拟文件传入。加载器会为每个值各生成一个页面，数据来自 `dataAt()`；若未提供 `dataAt()`，则使用 `data`。Meta 文件的运作方式也相同：

```ts twoslash
import type { StaticSource } from 'fumadocs-core/source';

const files: StaticSource['files'] = [
  {
    type: 'page',
    path: '[framework]/deploy.mdx',
    data: { title: 'Deploy' },
    dataAt: (params) => ({ title: `Deploy on ${params.framework}` }),
  },
  {
    type: 'meta',
    path: '[framework]/meta.json',
    data: { staticParams: [{ framework: 'waku' }, { framework: 'astro' }] },
    dataAt: (params) => ({ title: params.framework }),
  },
];
```

### 列出参数 [#listing-params]

为了在加载器之前先解析每个值的数据 (例如代码中的 frontmatter) ，`getStaticParams()` 会依照相同规则列出参数。它会依据不含扩展名的路径，从你的保存空间读取 meta 文件中的 `staticParams`：

```ts twoslash
import { getStaticParams, type Params } from 'fumadocs-core/source';

declare const frontmatter: { staticParams?: Params[] };
declare const metaFiles: Map<string, { staticParams?: Params[] }>;
// ---cut---
const params = getStaticParams('[framework]/deploy.mdx', {
  staticParams: frontmatter.staticParams,
  readStaticParams: (path) => metaFiles.get(path)?.staticParams,
});
```

若没有任何地方列出这些值，它会返回 `undefined`，此时该文件会以其字面路径生成单一页面。

### 自定义 Props [#custom-props]

为了支持[自定义 props](/docs/headless/source-api#custom-props)，`dataAt()` 会将它们作为第二个参数接收，同时传入经重载入器插件处理后的页面数据。请返回依据参数与自定义 props 渲染后的数据：

```tsx twoslash
import type { StaticSource } from 'fumadocs-core/source';

declare function pageAt(props: object): { title: string };
// ---cut---
const files: StaticSource['files'] = [
  {
    type: 'page',
    path: '[framework]/deploy.mdx',
    data: pageAt({}),
    dataAt: (params, custom) =>
      custom ? { ...custom.data, ...pageAt({ ...params, ...custom.props }) } : pageAt(params),
  },
];
```

未使用 `dataAt()` 的页面会忽略自定义 props。

### 运行时输出 [#runtime-outputs]

若你的来源会编译 MDX，请将每个文件只编译一次，并将页面 props 传入其内容。若要以相同的 props 生成目录、搜索记录与 Markdown：

* 在要编译的文件数据中设置 `unstable_runtimeOutputs: true`。若使用 Sätteri，请在编译选项的 `data` 中设置。
* 将 `rehypeHeading` 加为最后一个 rehype 插件，以便根据渲染后的文字生成[标题 ID](/docs/headless/mdx/headings#headings-with-expressions)。

```ts
import { VFile } from 'vfile';

const file = new VFile({
  path: '[framework]/deploy.mdx',
  value: source,
  data: { unstable_runtimeOutputs: true },
});
```

此时插件导出的会是函数而非值，例如 [Rehype 目录](/docs/headless/mdx/headings#rehype-toc) 的 `toc`，以及 [Remark LLMs](/docs/headless/mdx/remark-llms) 的 `_markdown` 组件。请传入各页面的 props 来调用它们：

```tsx twoslash
import type { StaticSource } from 'fumadocs-core/source';
import type { StructuredData } from 'fumadocs-core/mdx-plugins/remark-structure';
import type { TOCItemType } from 'fumadocs-core/toc';
import { renderToMarkdown } from 'fumadocs-core/server';
import type { MDXContent, MDXProps } from 'mdx/types';

declare const compiled: {
  default: MDXContent;
  toc: (props: object) => TOCItemType[];
  _markdown: MDXContent;
};
declare const file: { data: { structuredData: StructuredData } };
// ---cut---
const { default: Content, toc, _markdown: Markdown } = compiled;

function pageAt(props: object) {
  return {
    title: 'Deploy',
    body: (own: MDXProps) => <Content {...props} {...own} />,
    toc: toc(props),
    getMarkdown: () => renderToMarkdown(<Markdown {...props} />),
    structuredData: file.data.structuredData,
  };
}

const files: StaticSource['files'] = [
  {
    type: 'page',
    path: '[framework]/deploy.mdx',
    data: pageAt({}),
    dataAt: (params) => pageAt(params),
  },
];
```

若要用于搜索，请从 `file.data.structuredData` 读取 [Remark Structure](/docs/headless/mdx/structure) 的记录，而非从导出内容读取。这些记录涵盖每个 `<show>` 分支，而表达式也会保留其原始文字。

`unstable_` 前缀表示此 API 日后可能变更。若未启用此标志，在运行 Rehype 目录、Remark Structure 或 Remark LLMs 时，含有 [`<show>`](/docs/markdown#show) 的文档将无法编译。
