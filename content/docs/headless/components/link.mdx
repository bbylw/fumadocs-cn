title: Link

---

此组件包装了你所用 React 框架的 Link 组件 (例如 `next/link`) ，并会自动处理文档中的外部链接。~
侦测到外部 URL 时，会改用 `<a>` 取代 Link 组件。

`rel` 属性会自动生成。

## 使用方式 [#usage]

用法与 `<a>` 相同。

```mdx
import Link from 'fumadocs-core/link';

<Link href="/docs/components">Click Me</Link>
```

### 外部链接 [#external]

你可以传入 `external` prop，强制将 URL 视为外部链接。

### 动态 href [#dynamic-hrefs]

你可以导入 `dynamic-link` 来启用动态 href。

```mdx
import { DynamicLink } from 'fumadocs-core/dynamic-link';

<DynamicLink href="/[lang]/components">Click Me</DynamicLink>
```
