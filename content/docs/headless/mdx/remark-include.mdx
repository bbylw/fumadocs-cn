## 使用方式 [#usage]

Remark 引入是一个 remark 插件。Fumadocs MDX 在 unified 与 Sätteri 上皆默认启用此插件。语法请参阅[引入](/docs/mdx/include)。

路径以编译中的文件为基准。在 unified 上，除非你传入 `getProcessor`，否则被引入的 Markdown 与 MDX 文件会交由当前的处理器解析。Fumadocs MDX 会传入此选项，因此每个文件都会依其本身的格式解析。
