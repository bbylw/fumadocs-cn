## 使用方式 [#usage]

```package-install
fumadocs-docgen
```

`remarkInstall` 是 remark 插件，目前没有 Sätteri 版本。请加入此插件，并禁用会抢先处理 `package-install` 代码块的 Remark NPM：

```ts title="source.config.ts"
import { remarkInstall } from 'fumadocs-docgen';
import { defineConfig } from 'fumadocs-mdx/config';

export default defineConfig({
  mdxOptions: {
    remarkNpmOptions: false,
    remarkPlugins: [remarkInstall],
  },
});
```

定义所需的组件。

```tsx title="components/mdx.tsx"
import { Tab, Tabs } from 'fumadocs-ui/components/tabs';
import defaultComponents from 'fumadocs-ui/mdx';
import type { MDXComponents } from 'mdx/types';

export function getMDXComponents(components?: MDXComponents) {
  return {
    ...defaultComponents,
    // [!code ++:2]
    Tab,
    Tabs,
    ...components,
  } satisfies MDXComponents;
}
```

创建语言设为 `package-install` 的代码块。

````mdx
```package-install
my-package
```

```package-install
npm i my-package -D
```
````

### 输出 [#output]

```mdx
<Tabs items={['npm', 'pnpm', 'yarn', 'bun']}>
  <Tab value="npm">...</Tab>
  <Tab value="pnpm">...</Tab>
  <Tab value="yarn">...</Tab>
  <Tab value="bun">...</Tab>
</Tabs>
```

## 选项 [#options]

### 持久保存 [#persistent]

搭配 Fumadocs UI 使用时，你可以通过 `persist` 选项启用持久化。

```ts title="source.config.ts"
import { remarkInstall } from 'fumadocs-docgen';
import { defineConfig } from 'fumadocs-mdx/config';

export default defineConfig({
  mdxOptions: {
    remarkNpmOptions: false,
    remarkPlugins: [[remarkInstall, { persist: { id: 'some-id' } }]],
  },
});
```

这样则会改为生成：

```mdx
<Tabs groupId="some-id" persist items={[...]}>
  ...
</Tabs>
```
