title: Remark LLMs
description: 导出文档的 Markdown，供 LLM 使用。
---

`remarkLLMs` 插件会将文档的 Markdown 导出为 `_markdown`，供 LLM 使用，并保留你原本撰写的 Markdown。生成方式请参阅[字符串化](/docs/headless/mdx/stringification)。

```mdx tab="Input"
import { Callout } from 'fumadocs-ui/components/callout';

## Getting Started

<Callout>Hello **world**.</Callout>
```

```md tab="Output"
## Getting Started [#getting-started]

<Callout>Hello **world**.</Callout>
```

ESM 会被移除，标题会加上各自的 ID (请参阅 `headingIds`) ，而通过 Fumadocs MDX 引入的内容也会展开。

## 使用方式 [#usage]

`remarkLLMs` 是一个 remark 插件。你可以在 Fumadocs MDX 中通过 `includeProcessedMarkdown` 启用它，unified 与 Sätteri 皆适用：

```ts title="source.config.ts"
import { defineDocs } from 'fumadocs-mdx/config';

export const docs = defineDocs({
  docs: {
    postprocess: {
      // `true`，或 `remarkLLMs` 的选项
      includeProcessedMarkdown: true,
    },
  },
});
```

在页面中使用 `getText('processed')` 读取内容，它会搭配页面的 props 渲染 Markdown：

```ts
const markdown = await page.data.getText('processed');
```

## 图片 [#images]

与页面放在一起、由 [Remark Image](/docs/headless/mdx/remark-image) 导入的图片，会使用打包工具提供这些图片时的 URL：

```md tab="Input"
![How a calculation flows](./flow.png)
```

```md tab="Output"
![How a calculation flows](/assets/flow-Dxg6sAyC.png)
```

public 目录中的图片会保留原本的地址。小于 [`build.assetsInlineLimit`](https://vite.dev/config/build-options#build-assetsinlinelimit) 的图片会由 Vite 内嵌为 `data:` URL。

## 输出 [#output]

`output` 选项用于设置 `_markdown` 的形式：

* `function`：`_markdown` 是一个组件，请使用 [`renderToMarkdown()`](/docs/headless/utils/markdown) 加以渲染。Markdown 会依据页面 props 生成：[`<show>`](/docs/markdown#show) 中未渲染的内容会被省略，表达式会替换为其值，JSX 元素则会替换为对应的 [Markdown 形式](#jsx-elements)。
* `string`：`_markdown` 是一个字符串。表达式与 JSX 元素会以原始文字保留，而包含 `<show>` 的文档则会编译失败。

在 Fumadocs MDX 与 `@fumadocs/astro` 中，默认值为 `function`，其他情况则为 `string`。自定义内容来源若使用[运行时输出](/docs/headless/source-api/source#runtime-outputs)，则会得到 `function`。

## JSX 元素 [#jsx-elements]

使用 [`output: 'function'`](#output) 时，组件的查找方式与 MDX 相同：先查找文件中的导入与声明，再查找[页面 props](/docs/headless/source-api#custom-props) 中的 MDX 组件。请通过 `getPage()` 将 MDX 组件传入页面：

```ts
const page = source.getPage(slugs, { props: { components } });
```

组件可通过 [`asMarkdown()`](/docs/headless/utils/markdown#asmarkdown) 定义其 Markdown 形式，未定义的组件则会保留为 JSX。若要移除元素，或改以其子元素取代，请使用 `filterElement` (Sätteri 不支持) 。

### 预留位置 [#placeholders]

若要自行渲染 JSX 元素，请将它们列为预留位置：

```ts
import type { LLMsOptions } from 'fumadocs-core/mdx-plugins/remark-llms';

const llmsOptions: LLMsOptions = {
  mdxAsPlaceholder: ['Callout'],
};
```

接着将它们渲染出来，必要时可使用运行时的数据：

```ts
import { renderPlaceholder } from 'fumadocs-core/mdx-plugins/remark-llms.runtime';

const markdown = await renderPlaceholder(await page.data.getText('processed'), {
  // `children` 为元素内容的 Markdown
  Callout: ({ attributes, children }) => `> **${attributes.title}**\n>\n> ${children}`,
});
```

使用 Sätteri 时，无法使用 `mdxAsPlaceholder`。
