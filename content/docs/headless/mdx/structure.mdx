`remarkStructure` 插件会将文档的标题与内容截取为记录，供[搜索](/docs/headless/search)使用。记录会保留你原本撰写的 Markdown。生成方式请参阅[字符串化](/docs/headless/mdx/stringification)。

```mdx tab="Input"
## Installation

Run the [command](/docs/cli) below.

<Callout>Restart the **server** after it.</Callout>

| Option | Default |
| ------ | ------- |
| `dir`  | `docs`  |
```

```json tab="Output"
{
  "headings": [{ "id": "installation", "content": "Installation" }],
  "contents": [
    { "heading": "installation", "content": "Run the command below." },
    { "heading": "installation", "content": "<Callout>Restart the **server** after it.</Callout>" },
    {
      "heading": "installation",
      "content": "| Option | Default |\n| --- | --- |\n| `dir` | `docs` |",
      "table": "table-0"
    }
  ]
}
```

## 使用方式 [#usage]

Remark Structure 是一个 remark 插件。Fumadocs MDX 默认会启用它，并将记录导出为 `structuredData`。你可以通过 `remarkStructureOptions` 传入选项。

在 Fumadocs MDX 中，记录会依据页面的 props 生成：[`<show>`](/docs/markdown#show) 中未被渲染的内容会被排除，表达式则会替换为其求值结果。在 Fumadocs MDX 以外，表达式会保留为源代码文字。

## 记录 [#records]

标题、段落、引用块、表格与 JSX 元素都会被记录 (请参阅 `types`) ：

* 链接会替换为其文字，图片则会移除。
* 表格的每一列各为一笔记录，内容是由表头与该列组成的表格。这些列共用同一个 `table` 字段。
* JSX 元素会替换为其内容，但 `filterElement` 保留的元素除外 (请参阅[组件](#components)) 。
* JSX 元素若没有子元素 (请参阅 `mdxTypes`) ，或可以写在一行内，即为一笔记录。
* 记录内的内容不会重复记录。

在 Fumadocs MDX 中，此插件默认会保留组件的元素，例如 `<Callout>`，但不包含 `<div>`。在 Fumadocs MDX 之外，则会保留 `File`、`TypeTable`、`Callout` 与 `Card`。你可以通过 `filterElement` 变更此行为：

```ts tab="unified" title="source.config.ts"
import { defineConfig } from 'fumadocs-mdx/config';

export default defineConfig({
  mdxOptions: {
    remarkStructureOptions: {
      filterElement: (node) => node.name === 'Callout' || node.name === 'Banner',
    },
  },
});
```

```ts tab="Sätteri" title="source.config.ts"
import { defineConfig, defineDocs } from 'fumadocs-mdx/config';

export const docs = defineDocs({
  docs: { compiler: 'satteri' },
});

export default defineConfig({
  satteriOptions: {
    remarkStructureOptions: {
      filterElement: (node) => node.name === 'Callout' || node.name === 'Banner',
    },
  },
});
```

## 组件 [#components]

在 Fumadocs MDX 中，保留下来的 JSX 元素会依你读取记录的方式，以下列两种形式之一记录：

* `page.data.structuredData`：不会渲染组件。该元素会保留为 HTML 标签，再由搜索对话框将其作为组件渲染。若使用 `async` 或 `dynamic` 集合，请从已加载的页面读取。
* `await page.data.structuredData()`：会针对 [`search` 目标](/docs/headless/utils/markdown#targets)渲染组件，并将该元素替换为对应的 Markdown 形式。只有 `async` 与 `dynamic` 集合提供此函数。

渲染时，组件的查找方式与 MDX 相同：先查找文件中的导入与声明，再查找[页面 props](/docs/headless/source-api#custom-props) 中的 MDX 组件。

搜索会从 `getPages()` 读取页面，而这些页面不含自定义 props。若希望搜索时能渲染某个组件，请在文件中导入或声明该组件。

组件可通过 [`asMarkdown()`](/docs/headless/utils/markdown#asmarkdown) 定义供搜索使用的文字：

```tsx
import { asMarkdown } from 'fumadocs-core/server';

export function ProductName() {
  if (asMarkdown()) return 'Fumadocs';
  return <span className="font-semibold">Fumadocs</span>;
}
```

没有对应 Markdown 形式的组件会保留为 JSX 语法，与页面 props 中缺少的 MDX 组件处理方式相同。

## 插件 [#plugins]

插件插入的节点不会被记录。插件需通过 `data.structuredData` 自行加入其节点的记录：

```ts
node.data = {
  ...node.data,
  structuredData: {
    // `heading` 默认为当前的标题
    contents: [{ heading: undefined, content: 'Generated **content**' }],
  },
};
```

若只想变更记录中所撰写内容的 Markdown，请使用 [`replaceSource()`](/docs/headless/mdx/stringification#editing-the-output) 编辑 `search` 命名空间。

## 作为函数使用 [#as-a-function]

在 unified 中，`structure()` 会从字符串截取记录：

```ts
import { structure } from 'fumadocs-core/mdx-plugins';
import remarkMath from 'remark-math';

// 传入你的内容所需的 remark 插件
const data = structure(content, [remarkMath], options);
```
