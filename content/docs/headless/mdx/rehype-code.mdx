Fumadocs 所使用的语法高亮器，为 [`@shikijs/rehype`](https://shiki.style/packages/rehype) 的包装。

它会将原始的 `<pre />` 代码块转换成已语法高亮的代码块：

````md tab="Input"
```ts
console.log('Hello World');
```
````

```html tab="Output"
<pre>
  <code>
    <span class="line">
      <span style="--shiki-light: #4C4F69; --shiki-dark: #CDD6F4;">console</span>...
    </span>
  </code>
</pre>
```

## 使用方式 [#usage]

Rehype Code 是一个 rehype 插件，Fumadocs MDX 默认会启用它。你可以通过 `rehypeCodeOptions` 传入选项：

```ts tab="unified" title="source.config.ts"
import { defineConfig } from 'fumadocs-mdx/config';

export default defineConfig({
  mdxOptions: {
    rehypeCodeOptions: {
      themes: {
        light: 'github-light',
        dark: 'github-dark',
      },
    },
  },
});
```

```ts tab="Sätteri" title="source.config.ts"
import { defineConfig, defineDocs } from 'fumadocs-mdx/config';

export const docs = defineDocs({
  docs: { compiler: 'satteri' },
});

export default defineConfig({
  satteriOptions: {
    rehypeCodeOptions: {
      themes: {
        light: 'github-light',
        dark: 'github-dark',
      },
    },
  },
});
```

### 语法高亮器 [#highlighter]

此插件使用 Shiki。`rehypeCodeFromHighlighter` 则可改用其他[语法高亮器](/docs/headless/utils/shiki) (例如 Highlights) ，并接受 Shiki 以外的选项。请传入一个函数，搭配此插件的 transformer 创建语法高亮器。

请禁用默认插件，再加入此插件：

```ts tab="unified" title="source.config.ts"
import { defineConfig } from 'fumadocs-mdx/config';
import { rehypeCodeFromHighlighter } from 'fumadocs-core/mdx-plugins/rehype-code.core';
import { highlighter } from './lib/highlighter';

export default defineConfig({
  mdxOptions: {
    rehypeCodeOptions: false,
    rehypePlugins: [
      () =>
        rehypeCodeFromHighlighter(({ transformers }) =>
          highlighter.override({ shikiTransformers: transformers }),
        ),
    ],
  },
});
```

```ts tab="Sätteri" title="source.config.ts"
import { defineConfig, defineDocs } from 'fumadocs-mdx/config';
import { rehypeCodeFromHighlighter } from '@fumadocs/satteri/rehype-code';
import { highlighter } from './lib/highlighter';

export const docs = defineDocs({
  docs: { compiler: 'satteri' },
});

export default defineConfig({
  satteriOptions: {
    rehypeCodeOptions: false,
    hastPlugins: [
      rehypeCodeFromHighlighter(({ transformers }) =>
        highlighter.override({ shikiTransformers: transformers }),
      ),
    ],
  },
});
```

### Meta [#meta]

它会解析 `title` meta 字符串，并以属性的形式加到 `pre` 元素上。

````mdx tab="Input"
```js title="Title"
console.log('Hello');
```
````

```jsx tab="Output"
<pre title="Title">...</pre>
```

你可以通过 `filterMetaString` 选项，在处理 meta 字符串之前先进行过滤。

### 行内代码 [#inline-code]

你可以通过 `inline` 选项启用此功能：

```ts
import { type RehypeCodeOptions } from 'fumadocs-core/mdx-plugins';

const rehypeCodeOptions: RehypeCodeOptions = {
  // [!code ++]
  inline: 'tailing-curly-colon',
};
```

```md title="Syntax"
这是经过语法高亮的行内代码： `console.log("hello world"){:js}`.
```

这是一段经过语法高亮的行内代码：`console.log("hello world"){:js}`。

### 图标 [#icon]

此插件会根据语言的 meta 字符串，自动加入 `icon` 属性。
其值为 HTML 字符串，你可以通过 React 的 `dangerouslySetInnerHTML` 加以渲染。

````md tab="Input"
```ts
console.log('This should shows the logo of TypeScript');
```
````

```jsx tab="Output"
<pre icon="<svg />">...</pre>
```

你可以通过 `icon` 选项禁用或自定义图标。
