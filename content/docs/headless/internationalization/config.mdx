## 定义设定 [#define-config]

Fumadocs core 提供了支援 i18n 所需的中介软体与工具函式。

您可以定义一份设定，让各个工具函式共用。




```ts title="lib/i18n.ts"
import { defineI18n } from 'fumadocs-core/i18n';

export const i18n = defineI18n({
  defaultLanguage: 'en',
  languages: ['en', 'cn'],
});
```




### 隐藏语系前缀 [#hide-locale-prefix]

若要隐藏语系前缀 (例如 `/en/page` -&gt; `/page`) ，请使用 `hideLocale` 选项。

```ts
import { defineI18n } from 'fumadocs-core/i18n';

export const i18n = defineI18n({
  defaultLanguage: 'en',
  languages: ['en', 'cn'],
  hideLocale: 'default-locale',
});
```

| 模式               | 说明                    |
| ---------------- | --------------------- |
| `always`         | 一律隐藏前缀，并从 cookie 侦测语系 |
| `default-locale` | 仅隐藏预设语系的前缀            |
| `never`          | 一律不隐藏前缀 (预设)          |

<Callout type="warn" title={<>使用 <code>always</code></>}>
  在 `always` 模式下，语系会以 cookie 的形式储存 (由中介软体设定) ，这对静态网站来说并非理想做法。

  这可能会导致非预期的快取问题，且需要特别留意 SEO，以确保搜寻引擎能正确索引您的页面。
</Callout>

### 备用语言 [#fallback-language]

当档案缺少翻译时所使用的备用语言，预设为您的 `defaultLanguage`。

其值须为您 `languages` 阵列中的其中一个语言。

```ts
import { defineI18n } from 'fumadocs-core/i18n';

export const i18n = defineI18n({
  languages: ['en', 'cn'],
  defaultLanguage: 'en',
  // 若档案缺少英文版本，则使用中文版本
  fallbackLanguage: 'cn',
});
```

若要停用备用机制，请将其设为 `null`：

```ts
import { defineI18n } from 'fumadocs-core/i18n';

export const i18n = defineI18n({
  languages: ['en', 'cn'],
  defaultLanguage: 'en',
  fallbackLanguage: null,
});
```

停用后将不会使用任何备用内容 (包括 `meta.json`) 。您仍可透过 `$` 建立所有语系共用的档案：

<Files>
  <File name="my-page.$.md" />

  <File name="meta.$.json" />
</Files>
