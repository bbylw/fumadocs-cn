[Content Collections](https://www.content-collections.dev) 是一个函数库，能将你的内容转换成类型安全的数据集合。

## 设置 [#setup]

请依照 Content Collections 的[官方指南](https://content-collections.dev/docs)，在你的 React 框架中设置 Content Collections。

请确认你已设置好 MDX：

```npm
npm i @content-collections/mdx
```

若要与 Fumadocs 集成，请在你的 `content-collections.ts` 中加入以下内容。

```ts title="content-collections.ts"
import { defineCollection, defineConfig } from '@content-collections/core';
import { transformMDX } from '@fumadocs/content-collections/configuration';
import { metaSchema, pageSchema } from 'fumadocs-core/source/schema';

const docs = defineCollection({
  name: 'docs',
  directory: 'content/docs',
  include: '**/*.mdx',
  schema: pageSchema,
  transform: transformMDX,
});

const metas = defineCollection({
  name: 'meta',
  directory: 'content/docs',
  include: '**/meta.json',
  parser: 'json',
  schema: metaSchema,
});

export default defineConfig({
  collections: [docs, metas],
});
```

接着将它传入 `loader()`。

```ts title="lib/source.ts"
import { allDocs, allMetas } from 'content-collections';
import { loader } from 'fumadocs-core/source';
import { createMDXSource } from '@fumadocs/content-collections';

export const source = loader({
  baseUrl: '/docs',
  source: createMDXSource(allDocs, allMetas),
});
```

大功告成！你现在可以通过 Source API 访问页面及生成的页面树。

```ts
import { getPage } from '@/lib/source';

const page = getPage(slugs);

// MDX 输出
page?.data.body;

// 目录
page?.data.toc;

// 结构化数据，供 Search API 使用
page?.data.structuredData;
```

### MDX 选项 [#mdx-options]

你可以在 `transformMDX` 函数中自定义 MDX 选项。

```ts
import { defineCollection } from '@content-collections/core';
import { transformMDX } from '@fumadocs/content-collections/configuration';

const docs = defineCollection({
  transform: (document, context) =>
    transformMDX(document, context, {
      // 在此填入选项
    }),
});
```

### 导入组件 [#import-components]

若要使用其他包 (例如 Fumadocs UI) 提供的组件，请将这些组件传入你的 `<MDXContent />` 组件。

```tsx
import { MDXContent } from '@content-collections/mdx/react';
import { getMDXComponents } from '@/components/mdx';

return <MDXContent code={page.data.body} components={getMDXComponents()} />;
```

你也可以在 MDX 文件中导入它们，但不建议这么做。

<Callout title="深入探讨：为什么？">
  Content Collections 使用 `mdx-bundler` 来打包 MDX 文件。

  为了支持从 node modules 导入包，Fumadocs 为 MDX Bundler 的 `cwd` 选项加入了默认值。
  虽然这样运作良好，但我们仍然**不**建议在 MDX 文件中导入组件。

  原因如下：

  * 这需要通过 esbuild 打包这些组件，但这项工作理应由框架的打包工具 (例如 Vite 或 Turbopack) 负责
  * 你可以重构组件的导入路径，而无须修改 MDX 文件。
  * 使用远程来源 (Remote Sources) 时，在 MDX 文件中加入导入并没有意义。
</Callout>
