## 设置 [#setup]

### 安装依赖包 [#install-dependencies]

```package-install
typesense typesense-fumadocs-adapter
```

### 启动 Typesense 服务器 [#start-typesense-server]

你可以自行架设 Typesense 服务器，或使用其云端服务。请依照官方的[入门指南](https://typesense.org/docs/guide/install-typesense.html)设置服务器，并将认证信息保存在 `.env.local` 中 (在 Vite 框架中请将 `NEXT_PUBLIC_` 改为 `VITE_`，在 Astro 中则改为 `PUBLIC_`) ：

```dotenv
NEXT_PUBLIC_TYPESENSE_URL="server URL"
NEXT_PUBLIC_TYPESENSE_SEARCH_KEY="search-only API key"
TYPESENSE_API_KEY="API key with write access"
```

### 同步数据集 [#sync-dataset]

通过预先渲染的 `static.json` 路由导出搜索索引，并在每次构建后以脚本将其同步至 Typesense：

<feature>search/typesense</feature>

`build` 脚本会在每次构建时运行同步，因此请在你的部署平台上设置相同的变量。

### 搜索 UI [#search-ui]

若要实现搜索 UI，你可以：

* 使用 [Fumadocs UI 搜索对话框](/docs/search/typesense)。
* 使用 Typesense 搜索客户端 hook，自行打造搜索 UI。

  ```ts
  import { Client } from 'typesense';
  import { useTypesenseSearch } from 'typesense-fumadocs-adapter/client';

  const client = new Client({
    nodes: [{ url: 'YOUR_TYPESENSE_SERVER_URL' }],
    apiKey: 'YOUR_TYPESENSE_SEARCH_ONLY_API_KEY',
  });

  const { search, setSearch, query } = useTypesenseSearch({
    typesenseCollectionName: 'docs',
    client,
  });
  ```

## 选项 [#options]

### 标签筛选 [#tag-filter]

若要设置标签筛选，请在 `static.json` 路由中为各份文档加上 `tag` 值：

```ts
documents.push({
  // 其他字段……
  // [!code ++]
  tag: '<your value>',
});
```

接着更新你的搜索客户端：

* **Fumadocs UI**：在搜索 UI 中启用[标签筛选](/docs/search/typesense#tag-filter)。
* **搜索客户端**：你可以依下列方式加入标签筛选：

  ```ts
  import { useTypesenseSearch } from 'typesense-fumadocs-adapter/client';
  const { search, setSearch, query } = useTypesenseSearch({
    tag: '<your tag value>',
    // ...
  });
  ```

### 国际化 (i18n)  [#internationalization-i18n]

文档会包含所属页面的 `locale`，请将 `locale` 传入搜索客户端：

```ts
import { useI18n } from 'fumadocs-ui/contexts/i18n';
import { useTypesenseSearch } from 'typesense-fumadocs-adapter/client';

const { locale } = useI18n();
const { search, setSearch, query } = useTypesenseSearch({
  // [!code ++]
  locale,
  // 其他字段...
});
```

在底层，Typesense 会为每个语系分别创建集合，集合名称会加上 `_{locale}` 后缀 (例如 `docs_en`、`docs_fr`) 。
