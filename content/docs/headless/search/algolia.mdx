## 设置 [#setup]

安装依赖包：

```package-install
algoliasearch
```

### 注册 Algolia [#sign-up-on-algolia]

请注册帐号并取得搜索用的应用 ID 与 API 密钥，然后将它们存放在 `.env.local` 中 (在 Vite 框架中，`NEXT_PUBLIC_` 应改为 `VITE_`；在 Astro 中则改为 `PUBLIC_`) ：

```dotenv
NEXT_PUBLIC_ALGOLIA_APP_ID="app ID"
NEXT_PUBLIC_ALGOLIA_SEARCH_KEY="search-only API key"
ALGOLIA_WRITE_KEY="write API key"
```

### 同步搜索索引 [#sync-search-indexes]

预先渲染 `static.json` 路由，在构建时导出搜索索引，并于每次构建后通过脚本将索引同步至 Algolia：

<feature>search/algolia</feature>

`sync()` 会更新索引设置并取代所有记录。`build` 脚本会在每次构建时运行同步，因此请在你的部署平台上设置相同的变量。

### 搜索 UI [#search-ui]

你可以考虑以下几种实现 UI 的方式：

* 使用 [Fumadocs UI 搜索对话框](/docs/search/algolia)。

* 通过内置的搜索客户端 hook 自行构建：

  ```ts twoslash
  // @noErrors
  import { liteClient } from 'algoliasearch/lite';
  import { useAlgoliaSearch } from 'fumadocs-core/search/client';

  const algolia = liteClient('id', 'key');

  const { search, onSearchChange, isLoading, data } = useAlgoliaSearch({
    indexName: 'document',
    client: algolia,
  });
  ```

* 直接使用 Algolia 的官方客户端。

## 高级 [#advanced]

### 标签筛选 [#tag-filter]

若要设置标签筛选，请在 `static.json` 路由中将 `tag` 传入 `toDocuments()`：

```ts
toDocuments(source, { tag: (page) => page.slugs[0] });
```

接着更新你的搜索客户端：

* **Fumadocs UI**：在搜索 UI 中启用[标签筛选](/docs/search/algolia#tag-filter)。
* **搜索客户端**：你可以用以下方式加入标签筛选：

  ```ts
  import { useAlgoliaSearch } from 'fumadocs-core/search/client';

  const { search, onSearchChange, isLoading, data } = useAlgoliaSearch({
    tag: '<your tag value>',
    // ...
  });
  ```

`tag` 字段是用于分面搜索 (faceting) 的属性。你也可以在 Algolia 搜索客户端中使用 `tag:value` 筛选条件。

### 底层运作原理 [#under-the-hood]

Algolia 集成会自动设置 Algolia Search，用于文档搜索。

它会为文档中的**每个段落**各创建一笔记录，这也是 Algolia 建议的做法。

每笔记录都包含以下可搜索的属性：

| 属性        | 说明               |
| --------- | ---------------- |
| `title`   | 页面标题             |
| `section` | 标题 ID (可为 null)  |
| `content` | 段落内容             |

只有位于标题下方的段落才会有 `section` 字段。标题与
段落会分别索引为独立的记录，并依页面 ID 分组。

请注意，页面的 `url` 属性必须是唯一的，请勿让两个页面使用相同的
URL。
