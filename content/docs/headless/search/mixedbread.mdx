[Mixedbread](https://www.mixedbread.com) 提供语意搜索功能，让用户能以自然语言搜索，依照语意而非关键字找到内容。

## 设置 [#setup]

安装依赖包：

```package-install
@mixedbread/sdk
```

### API 密钥 [#api-key]

请先在 [Mixedbread](https://platform.mixedbread.com) 注册，并为你的文档创建一组 [API 密钥](https://platform.mixedbread.com/platform?next=api-keys)和一个[保存区](https://platform.mixedbread.com/platform?next=stores)，再将两者存放到 `.env.local` 中：

```dotenv
MXBAI_API_KEY="your API key"
MIXEDBREAD_STORE_ID="your store ID"
```

搜索会在你的服务器上运行，因此 API 密钥绝不会暴露给浏览器。

### 同步文档 [#sync-documents]

预先渲染 `static.json` 路由，以便在构建时导出搜索文档，并在每次构建后通过脚本将这些文档同步至你的保存区：

<feature>search/mixedbread</feature>

`sync()` 会为每个页面上传一个文件，并略过自上次同步后未变更的页面。已移除页面的文件也会一并删除，因此请使用专供你的文档使用的保存区。`build` 脚本会在每次构建时进行同步，请在你的部署平台上设置相同的变量。

### 搜索 API [#search-api]

创建用来搜索你保存区的路由：

```ts tab="Next.js" title="app/api/search/route.ts"
import { createMixedbreadSearchAPI } from 'fumadocs-core/search/mixedbread';
import Mixedbread from '@mixedbread/sdk';

export const { GET } = createMixedbreadSearchAPI({
  client: new Mixedbread(), // 会读取 `MXBAI_API_KEY`
  storeIdentifier: process.env.MIXEDBREAD_STORE_ID!,
});
```

```ts tab="React Router" title="app/routes/search.ts"
import type { Route } from './+types/search';
import { createMixedbreadSearchAPI } from 'fumadocs-core/search/mixedbread';
import Mixedbread from '@mixedbread/sdk';

const server = createMixedbreadSearchAPI({
  client: new Mixedbread(), // 会读取 `MXBAI_API_KEY`
  storeIdentifier: process.env.MIXEDBREAD_STORE_ID!,
});

export async function loader({ request }: Route.LoaderArgs) {
  return server.GET(request);
}
```

```ts tab="TanStack Start" title="src/routes/api/search.ts"
import { createFileRoute } from '@tanstack/react-router';
import { createMixedbreadSearchAPI } from 'fumadocs-core/search/mixedbread';

const server = createMixedbreadSearchAPI({
  client: new Mixedbread(), // 会读取 `MXBAI_API_KEY`
  storeIdentifier: process.env.MIXEDBREAD_STORE_ID!,
});

export const Route = createFileRoute('/api/search')({
  server: {
    handlers: {
      GET: async ({ request }) => server.GET(request),
    },

});
```


```ts tab="Astro" title="src/pages/api/search.ts"
import type { APIRoute } from 'astro';
import { createMixedbreadSearchAPI } from 'fumadocs-core/search/mixedbread';
import Mixedbread from '@mixedbread/sdk';
import { getSecret } from 'astro:env/server';

// 于每次请求时渲染，需要适配器
export const prerender = false;

const server = createMixedbreadSearchAPI({
  client: new Mixedbread({ apiKey: getSecret('MXBAI_API_KEY') }),
  storeIdentifier: getSecret('MIXEDBREAD_STORE_ID')!,
});

export const GET: APIRoute = ({ request }) => server.GET(request);
```

### 搜索 UI [#search-ui]

你可以考虑以下几种实现 UI 的方式：

* 使用 [Fumadocs UI 搜索对话框](/docs/search/mixedbread)。
* 通过内置的搜索客户端 hook 自行打造：

  ```ts twoslash
  import { useFetchSearch } from 'fumadocs-core/search/client';

  const { search, onSearchChange, isLoading, data } = useFetchSearch({
    api: '/api/search',
    // 每次搜索都会向 Mixedbread 发送一次请求
    delayMs: 300,
  });
  ```

## 选项 [#options]

### 标签筛选 [#tag-filter]

若要设置标签筛选，请在 `static.json` 路由中将 `tag` 传入 `toDocuments()`：

```ts
toDocuments(source, { tag: (page) => page.slugs[0] });
```

接着更新你的搜索客户端：

* **Fumadocs UI**：在搜索 UI 中启用[标签筛选](/docs/search/mixedbread#tag-filter)。
* **搜索客户端**：将标签传入 `useFetchSearch()`。

  ```ts
  import { useFetchSearch } from 'fumadocs-core/search/client';

  const { search, onSearchChange, isLoading, data } = useFetchSearch({
    tag: '<your tag value>', // [!code ++]
    // ...
  });
  ```

### 国际化 [#internationalization]

文档会包含所属页面的语系，传入 `locale` 即可搜索特定语言的内容：

```ts
import { useI18n } from 'fumadocs-ui/contexts/i18n';
import { useFetchSearch } from 'fumadocs-core/search/client';

const { locale } = useI18n();
const { search, onSearchChange, isLoading, data } = useFetchSearch({
  locale, // [!code ++]
  // ...
});
```

## 运作原理 [#under-the-hood]

每个页面都是一个以 URL 为键的文件，并以页面标题、URL、Breadcrumb、标签和语系作为元数据。页面的块 (chunk) 包括页面标题、各个标题与段落，而每笔搜索结果都是一个块：

| 块元数据    | 说明                        |
| --------- | ------------------------- |
| `kind`    | `page`、`heading` 或 `text` |
| `heading` | 所属标题的 ID (可选)             |
| `table`   | 表格列所属的表格 (可选)             |
