[Meilisearch](https://www.meilisearch.com) 是一款开源搜索引擎，支持错字容忍度与筛选功能。你可以自行架设，也可以使用 Meilisearch Cloud。

## 设置 [#setup]

安装依赖包：

```package-install
meilisearch
```

### API 密钥 [#api-keys]

请通过[自行架设](https://www.meilisearch.com/docs/learn/self_hosted/getting_started_with_self_hosted_meilisearch)或使用 [Meilisearch Cloud](https://www.meilisearch.com/cloud) 启动 Meilisearch 运行个体，并将其认证信息保存在 `.env.local` 中 (在 Vite 框架中请将 `NEXT_PUBLIC_` 改为 `VITE_`，在 Astro 中则改为 `PUBLIC_`) ：

```dotenv
NEXT_PUBLIC_MEILISEARCH_HOST="URL of your instance"
NEXT_PUBLIC_MEILISEARCH_SEARCH_KEY="search API key"
MEILISEARCH_ADMIN_KEY="Default Admin API Key"
```

搜索密钥会暴露在浏览器中，因此请[创建一组](https://www.meilisearch.com/docs/learn/security/basic_security)只能搜索 `docs` 索引的密钥。管理员密钥则请妥善保管，切勿公开。

### 同步文档 [#sync-documents]

预先渲染 `static.json` 路由，在构建时导出搜索文档，并于每次构建后通过脚本将其同步至 Meilisearch：

<feature>search/meilisearch</feature>

`sync()` 会设置索引并取代其中的文档；在新文档完成索引前，旧文档仍可供搜索。`build` 脚本会在每次构建时同步，请在你的部署平台上设置相同的变量。

### 搜索 UI [#search-ui]

实现 UI 时，你可以考虑以下几种方式：

* 使用 [Fumadocs UI 搜索对话框](/docs/search/meilisearch)。

* 使用内置的搜索客户端 hook 自行打造：

  ```ts twoslash
  // @noErrors
  import { Meilisearch } from 'meilisearch';
  import { useMeilisearch } from 'fumadocs-core/search/client';

  const client = new Meilisearch({
    host: 'host url',
    apiKey: 'search api key',
  });

  const { search, onSearchChange, isLoading, data } = useMeilisearch({
    client,
    indexName: 'docs',
  });
  ```

* 直接使用 Meilisearch 的官方客户端。

## 选项 [#options]

### 标签筛选 [#tag-filter]

若要设置标签筛选，请在 `static.json` 路由中将 `tag` 传入 `toDocuments()`：

```ts
toDocuments(source, { tag: (page) => page.slugs[0] });
```

接着更新你的搜索客户端：

* **Fumadocs UI**：在搜索 UI 中启用[标签筛选](/docs/search/meilisearch#tag-filter)。
* **搜索客户端**：将标签传入 `useMeilisearch()`。

  ```ts
  import { useMeilisearch } from 'fumadocs-core/search/client';

  const { search, onSearchChange, isLoading, data } = useMeilisearch({
    tag: '<your tag value>', // [!code ++]
    // ...
  });
  ```

### 国际化 [#internationalization]

文档会包含所属页面的语系，传入 `locale` 即可搜索特定语言：

```ts
import { useI18n } from 'fumadocs-ui/contexts/i18n';
import { useMeilisearch } from 'fumadocs-core/search/client';

const { locale } = useI18n();
const { search, onSearchChange, isLoading, data } = useMeilisearch({
  locale, // [!code ++]
  // ...
});
```

### 索引设置 [#index-settings]

`sync()` 只会设置 `searchableAttributes` 和 `filterableAttributes`，其他设置 (例如同义词与错字容忍度) 则会维持不变。你可以通过 Meilisearch 仪表板或 `meilisearch` 客户端调整这些设置。

## 运作原理 [#under-the-hood]

每个标题与段落都是一篇文档，并附带页面标题、URL 与 Breadcrumb。只有 `content` 可供搜索，搜索客户端会依页面将结果分组。

| 属性        | 说明                        |
| --------- | ------------------------- |
| `type`    | `page`、`heading` 或 `text` |
| `content` | 页面标题、标题或段落                |
| `heading` | 所属标题的 ID (可选)             |
| `tag`     | 用于筛选结果的标签 (可选)            |
| `locale`  | 页面的语系 (可选)                |
