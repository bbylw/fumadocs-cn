## 简介 [#introduction]

Trieve 集成会自动设置 Trieve Search，用于网站搜索。

默认情况下，它会为文档中的**每个段落**各创建一个 chunk，这也是
Trieve 官方建议的做法。

## 设置 [#setup]

### 安装依赖包 [#install-dependencies]

```package-install
trieve-ts-sdk trieve-fumadocs-adapter
```

### 注册 Trieve [#sign-up-on-trieve]

请先注册并创建一个数据集 (dataset) ，接着取得 2 组 API 密钥：一组仅有读取权限，另一组则具备管理员权限，可用来创建及删除 chunk。
请将数据集 ID 与管理员密钥存放在 `.env.local` 中，以便进行同步：

```dotenv
TRIEVE_DATASET_ID="dataset ID"
TRIEVE_ADMIN_API_KEY="admin API key"
```

<Callout title="注意">
  其中一组 API Key 应仅具备只读权限，供对外公开的搜索使用；另一组则需具备
  管理员权限，用于创建及删除 chunk。
</Callout>

### 同步数据集 [#sync-dataset]

Trieve 会沿用 [Algolia 集成](/docs/headless/search/algolia)的记录。请通过预先渲染的 `static.json` 路由导出这些记录，并在每次构建后以脚本将其同步至 Trieve：

<feature>search/trieve</feature>

`build` 脚本会在每次构建时进行同步，因此请在你的部署平台上设置相同的变量。

### 搜索 UI [#search-ui]

你可以使用对方提供的 `SearchDialog` 组件：

```tsx title="components/search.tsx"
'use client';
import type { SharedProps } from 'fumadocs-ui/components/dialog/search';
import SearchDialog from 'trieve-fumadocs-adapter/components/dialog/search';
import { TrieveSDK } from 'trieve-ts-sdk';

const trieveClient = new TrieveSDK({
  apiKey: 'readOnlyApiKey',
  datasetId: 'datasetId',
});

export default function CustomSearchDialog(props: SharedProps) {
  return <SearchDialog trieveClient={trieveClient} {...props} />;
}
```

1. 将 `apiKey` 和 `datasetId` 替换为你要使用的值。

2. 将默认的搜索对话框替换为你新创建的版本。

### 搜索客户端 [#search-client]

加入 `useTrieveSearch` hook：

```ts
import { TrieveSDK } from 'trieve-ts-sdk';
import { useTrieveSearch } from 'trieve-fumadocs-adapter/search/trieve';

const client = new TrieveSDK({
  apiKey: 'readOnlyApiKey',
  datasetId: 'datasetId',
});

const { search, setSearch, query } = useTrieveSearch(client);
```

## 选项 [#options]

### 标签筛选 [#tag-filter]

若要设置标签筛选，请在索引中加入 `tag` 值。

```js
import { sync } from 'trieve-fumadocs-adapter/search/sync';
import { TrieveSDK } from 'trieve-ts-sdk';

const client = new TrieveSDK({
  apiKey: 'adminApiKey',
  datasetId: 'datasetId',
});

const documents = records.map((index) => ({
  ...index,
  tag: 'value', // [!code highlight]
}));

sync(client, documents);
```

#### 搜索 UI [#search-ui-1]

启用标签筛选。

```tsx title="components/search.tsx"
import SearchDialog from 'trieve-fumadocs-adapter/components/dialog/search';

<SearchDialog
  defaultTag="value"
  tags={[
    {
      name: 'Tag Name',
      value: 'value',
    },
  ]}
/>;
```

#### 搜索客户端 [#search-client-1]

`tag_set` 字段是用于筛选的属性。若要依标签筛选索引，请在 Trieve 搜索客户端中使用筛选功能。

```json
{
  "must": [
    {
      "field": "tag_set",
      "match": ["value"]
    }
  ]
}
```

或使用 `useTrieveSearch` hook：

```ts
import { TrieveSDK } from 'trieve-ts-sdk';
import { useTrieveSearch } from 'trieve-fumadocs-adapter/search/trieve';

const client = new TrieveSDK({
  apiKey: 'readOnlyApiKey',
  datasetId: 'datasetId',
});

const { search, setSearch, query } = useTrieveSearch(client, undefined, '<your tag value>');
```
