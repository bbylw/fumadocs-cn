首先，请在 Orama Cloud 上创建帐号。

## REST API [#rest-api]

使用 REST API 集成时，你的文档网站需要自行上传索引。

1. 在 Orama Cloud 控制台创建一个以 **REST API** 作为数据源的新项目。

   将你的认证信息保存在 `.env.local` 中，例如 (在 Vite 框架上 `NEXT_PUBLIC_` 改为 `VITE_`，在 Astro 上则为 `PUBLIC_`) ：

   ```dotenv
   NEXT_PUBLIC_ORAMA_DATASOURCE_ID="Rest API data source ID"
   NEXT_PUBLIC_ORAMA_PROJECT_ID="project ID"
   NEXT_PUBLIC_ORAMA_API_KEY="public API key"

   ORAMA_PRIVATE_API_KEY="private API key"
   ```

2. 预先渲染 `static.json` 路由，以便在构建时导出搜索索引，并在每次构建后通过脚本将索引同步至 Orama Cloud：

   <feature>search/orama-cloud</feature>

   `build` 脚本会在每次构建时进行同步，因此请在你的部署平台上设置相同的变量。

### 搜索客户端 [#search-client]

若要在客户端搜索文档，可以考虑以下方式：

* 使用 [Fumadocs UI 搜索对话框](/docs/search/orama-cloud)。

* 使用 Fumadocs 内置的 hook 自定义搜索 UI：

  ```ts
  import { useOramaCloudSearch } from 'fumadocs-core/search/client';
  import { OramaCloud } from '@orama/core';

  const orama = new OramaCloud({
    projectId: process.env.NEXT_PUBLIC_ORAMA_PROJECT_ID,
    apiKey: process.env.NEXT_PUBLIC_ORAMA_API_KEY,
  });

  const params = {
    // 可选的搜索参数
  };

  const { search, onSearchChange, isLoading, data } = useOramaCloudSearch({
    client: orama,
    params,
  });
  ```

* 直接使用 Orama 提供的搜索客户端。

## 网络爬虫 [#web-crawler]

1. 在控制台中创建 Crawler 数据源，并应用「Documentation」默认模板，完成正确设置。
2. 从控制台复制认证信息。

### 搜索客户端 [#search-client-1]

设置方式与 REST API 集成相同，但请务必将 `index` 设为 `crawler`。

```ts
import { useOramaCloudSearch } from 'fumadocs-core/search/client';
import { OramaCloud } from '@orama/core';

const orama = new OramaCloud({
  projectId: '<project id>',
  apiKey: '<read only api key>',
});

const params = {
  // 可选的搜索参数
};

const { search, onSearchChange, isLoading, data } = useOramaCloudSearch({
  index: 'crawler',
  client: orama,
  params,
});
```

Fumadocs UI 也是如此。
