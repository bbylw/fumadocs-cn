## 概览 [#overview]

在 Fumadocs MDX 中，**工作区**指的是拥有独立设置与内容的项目。

<Files>
  <Folder name="my-workspace" defaultOpen>
    <Folder name="content/docs" defaultOpen>
      <File name="index.mdx" />

      <File name="test.mdx" />
    </Folder>

    <File name="source.config.ts" />
  </Folder>

  <Folder name="content/docs" defaultOpen>
    <File name="welcome.mdx" />
  </Folder>

  <File name="source.config.ts" />
</Files>

<Callout title="小提醒">
  Fumadocs MDX 的工作区并不局限于包管理工具中传统意义上的工作区。

  工作区不需要拥有自己的 `package.json`，只需要一个配置文件即可。
</Callout>

若要定义工作区，请加入：

```ts title="source.config.ts"
import { defineConfig } from 'fumadocs-mdx/config';

export default defineConfig({
  workspaces: {
    'my-workspace': {
      dir: 'my-workspace',
      config: await import('./my-workspace/source.config.ts'),
    },
  },
});
```

在工作区中撰写内容时，请注意：

* `cwd` 指的是**当前工作区目录**。
* 设置不会继承，各个工作区一律彼此独立。

运行 dev 或 build 服务器后，你应该会看到所有工作区的集合项目都已生成。

### 访问集合 [#accessing-collections]

你可以通过 `.source/{workspace}/*` 访问工作区生成的文件。例如：

```ts title="lib/source.ts"
import { docs } from 'collections/my-workspace/server';
```

> 根工作区的输出位置维持不变。

若要在 Fumadocs 中集成[多个来源](/docs/headless/source-api/source#multiple-sources)：

```ts title="lib/source.ts"
import { loader } from 'fumadocs-core/source';
import { docs } from 'collections/server';
import * as MyWorkspace from 'collections/my-workspace/server';

export const source = loader(
  {
    root: docs.toFumadocsSource(),
    'my-workspace': MyWorkspace.docs.toFumadocsSource(),
  },
  {
    baseUrl: '/docs',
  },
);
```

## 使用时机 [#when-to-use]

在某些架构中，你可能会有多个 Fumadocs MDX 设置，各自拥有自己的内容目录。

通过工作区，你可以将它们集成到同一个 Fumadocs MDX 设置中，并访问每个工作区的所有集合。

这对于将内容分散存放在多个保存库等使用情境来说至关重要，简化后的架构如下：

* 将你的主要文档保存库设为 $A$，其他保存库设为 $T&#95;n$
* 对于每个保存库 $T&#95;n$：
  * $T&#95;n$ 将 $A$ 加入为 git submodule。
  * $T&#95;n$ 定义自己的设置 `source.config.ts`，并独立运作。
  * 当 $T&#95;n$ 的内容有新的 commit 时，会触发 GitHub Action (或 CI) ，在 $A$ 上创建新的部署。
* 当 $A$ 触发部署时：
  * Fumadocs MDX 会将每个 $T&#95;n$ 视为一个工作区来处理。
  * 每个工作区会生成各自的集合项目，例如 `collections/{repo}/server`。
  * Fumadocs `loader()` 会将多个来源集成为一个。
