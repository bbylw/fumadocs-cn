## 简介 [#introduction]

默认情况下，所有 Markdown 与 MDX 文件都必须先经过预先编译，开发服务器也同样受此限制。

对于大型文档网站而言，这可能会拉长开发服务器的启动时间。你可以在 doc 集合上启用 Async 或 Dynamic 模式来改善这个问题。

## Async 模式 [#async-mode]

Async 模式会通过异步导入来生成集合的输出。

```ts tab="Docs Collection"
import { defineDocs } from 'fumadocs-mdx/config';

export const docs = defineDocs({
  dir: 'content/docs',
  docs: {
    // [!code ++]
    async: true,
  },
});
```

```ts tab="Doc Collection"
import { defineCollections } from 'fumadocs-mdx/config';

export const doc = defineCollections({
  type: 'doc',
  dir: 'content/docs',
  // [!code ++]
  async: true,
});
```

视你使用的打包工具而定，这可能会大幅缩短开发服务器的编译时间。

<Callout title="Next.js 用户">
  Turbopack 目前不支持延迟打包，因此 Async 模式只会提升服务器
  性能。
</Callout>

## Dynamic 模式 [#dynamic-mode]

Dynamic 模式会进行**随需编译**，并在运行时运行编译后的输出结果。

建议你安装 `shiki` 并将其设为外部依赖包 (externalize) ：

```npm
npm i shiki
```

在集合中启用 Dynamic 模式，方式如下：

```ts tab="Docs Collection"
import { defineDocs } from 'fumadocs-mdx/config';

export const docs = defineDocs({
  dir: 'content/docs',
  docs: {
    // [!code ++]
    dynamic: true,
  },
});
```

```ts tab="Doc Collection"
import { defineCollections } from 'fumadocs-mdx/config';

export const doc = defineCollections({
  type: 'doc',
  dir: 'content/docs',
  // [!code ++]
  dynamic: true,
});
```

接着，请依照 [Dynamic Entry](/docs/mdx/entry/dynamic) 的说明，改从 dynamic entry 访问集合。

<Callout title="限制" type="warn">
  Dynamic 模式对部分 MDX 功能有所限制。

  * **MDX 文件中不可使用 import/export。** 若要使用 MDX 组件，请改由 `components` prop 传入。
  * **图片必须以 URL 参照 (例如 `/images/test.png`) 。** 请勿使用 `./image.png` 这类**文件路径**。请将图片放在 `public` 文件夹中，并以 URL 参照。
</Callout>

## 使用方式 [#usage]

你仍可在 `page` 对象上访问 frontmatter 属性，但必须调用异步函数 `load()`，才能加载编译后的内容 (及其导出项目) 。

例如：

```tsx title="page.tsx"
import { source } from '@/lib/source';
import { getMDXComponents } from '@/components/mdx';

const page = source.getPage(['...']);

if (page) {
  // 可直接使用 frontmatter 属性
  console.log(page.data);

  // Markdown 内容需要使用 await 加载
  const { body: MdxContent, toc } = await page.data.load();

  console.log(toc);

  return <MdxContent components={getMDXComponents()} />;
}
```

使用 Async 或 Dynamic 模式时，强烈建议你改用第三方服务实现搜索功能，这类服务通常更擅长为大量内容创建索引。
