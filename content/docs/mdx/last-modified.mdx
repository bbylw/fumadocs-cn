## 使用方式 [#usage]

你可以在配置文件中加入此插件。

<Callout type="warning" title="默认使用 Git">
  请确认你的电脑已安装 Git，且**保存库并非通过浅层复制 (shallow
  clone) 取得**，因为此功能需要读取你本地的 Git 历史记录。
</Callout>

```ts title="source.config.ts"
import { defineConfig } from 'fumadocs-mdx/config';
import lastModified from 'fumadocs-mdx/plugins/last-modified';

export default defineConfig({
  // [!code ++]
  plugins: [lastModified()],
});
```

### 访问属性 [#access-the-property]

完成后，每份文档都会导出 `lastModified` 属性 (类型为 `Date`) 。

```ts
import { source } from '@/lib/source';

const page = source.getPage(['...']);

console.log(page.data.lastModified);
// 或使用延迟加载
const { lastModified } = await page.data.load();
console.log(lastModified);
```

你可以通过 [`<DocsPage />`](/docs/ui/layouts/page#last-updated-time) 等 UI 组件来显示此信息
