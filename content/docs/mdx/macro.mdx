## 概览 [#overview]

通过 `fumadocs-mdx/macro`，你可以直接在应用模块中声明集合。

打包工具 (或运行时加载器) 会将 `defineDocs` / `defineCollections` 编译为内容文件的导入语句。

* 无需生成代码。
* 无需 `source.config.ts`。

## 使用方式 [#usage]

```ts tab="lib/source.ts"
import { defineDocs } from 'fumadocs-mdx/macro';
import { loader } from 'fumadocs-core/source';

export const docs = defineDocs({
  dir: 'content/docs',
});

export const source = loader({
  baseUrl: '/docs',
  source: docs.toFumadocsSource(),
});
```

```ts tab="lib/blog.ts"
import { defineCollections } from 'fumadocs-mdx/macro';
import { loader } from 'fumadocs-core/source';

const blog = defineCollections({
  type: 'doc',
  dir: 'content/blog',
});

export const blogSource = loader({
  baseUrl: '/blog',
  source: blog.toFumadocsSource(),
});
```

集合选项与 [config API](/docs/mdx/collections) 大致相同。

使用宏定义集合时，你仍可保留 `source.config.ts`，用来设置[全域选项](/docs/mdx/global)与插件。

### 浏览器 [#browser]

宏集合也能在浏览器中使用。只要在客户端组件中导入集合，再通过 `body` 渲染项目即可，不需要[客户端加载器](/docs/mdx/entry/browser)。

```tsx
import { docs } from '@/lib/source';

export default function Page({ path }: { path: string }) {
  const page = docs.getPage(path);
  if (!page) return <div>Not Found</div>;

  const MDX = page.body;

  return (
    <div className="prose">
      <h1>{page.title}</h1>
      <MDX />
    </div>
  );
}
```

若页面使用[路径参数](/docs/page-conventions#path-params)，请从加载器传入其参数：`docs.getPage(page.path, page.params)`。

<Callout type="warn">
  浏览器会运行你导入 `docs` 的来源模块的完整内容。若你的 `loader()` 包含仅限服务端的
  来源 (例如 `openapi.staticSource()`) ，请将集合定义在另一个模块中 (例如
  `lib/collections.ts`) ，再从该模块导入。
</Callout>

#### Async 集合 [#async-collections]

激活 [`async`](/docs/mdx/async) 后，只有 frontmatter 会预先打包，内容则会随需截取。

`body` 的运作方式相同，只是它会暂停 (suspend) ，直到内容可用为止。以下两个额外的方法可控制此行为：

* `preload()` 会在渲染前先加载内容，让 `body` 渲染时无须暂停。请在你的路由加载器中调用它。
* `load()` 会返回已加载的内容，例如 `toc`。它的 promise 会被缓存，因此你可以在渲染期间调用它。

```tsx
import { use } from 'react';
import { docs } from '@/lib/source';

// 在你的路由加载器中（React Router、TanStack Start）
export async function loader({ path }: { path: string }) {
  await docs.getPage(path)?.preload();
  return { path };
}

export default function Page({ path }: { path: string }) {
  const page = docs.getPage(path);
  if (!page) return <div>Not Found</div>;

  const { toc } = use(page.load());
  const MDX = page.body;

  return (
    <div className="prose">
      <h1>{page.title}</h1>
      <MDX />
    </div>
  );
}
```

由于内容采用延迟加载，除非你已预先加载，否则请用 `<Suspense>` 边界包住页面。

## 设置 [#configuration]

Macro API 默认为启用。传入 `macro` 可限制哪些模块能使用它，传入 `false` 则可禁用。若使用 React Router 或 TanStack Start，请将其传给 Vite 插件。

```js tab="Next.js" title="next.config.mjs"
import { createMDX } from 'fumadocs-mdx/next';

const withMDX = createMDX({
  macro: {
    // 相对于项目根目录的 glob 模式
    include: ['lib/**/*.ts', 'lib/**/*.tsx'],
  },
  // 或完全禁用：
  // macro: false,
});
```

```ts tab="Vite" title="vite.config.ts"
import { fumadocsMdx } from 'fumadocs-mdx/vite';

export default {
  plugins: [
    fumadocsMdx({
      macro: {
        include: ['src/**/*.ts', 'src/**/*.tsx'],
      },
    }),
  ],
};
```

```ts tab="Waku" title="waku.config.ts"
import { defineConfig } from 'waku/config';
import { fumadocsMdx } from 'fumadocs-mdx/vite';

export default defineConfig({
  vite: {
    plugins: [
      fumadocsMdx({
        macro: {
          include: ['src/**/*.ts', 'src/**/*.tsx'],
        },
      }),
    ],
  },
});
```

```js tab="Node.js"
import { register } from 'fumadocs-mdx/node';

register({
  macro: {
    include: ['lib/**/*.ts'],
  },
});
```

默认情况下，所有 JS/TS 模块都会纳入处理 (`node_modules` 一律排除) 。若你希望转换只应用于特定路径，请缩小 `include` 的范围。

### 限制 [#constraints]

宏调用会以静态方式编译，请留意以下规则：

* 每个调用都必须指派给顶层的 `const` (变量名称用来识别集合) ：

  ```ts
  // ✓
  const docs = defineDocs({ dir: 'content/docs' });

  // ✗ 不支持
  export function create() {
    return defineDocs({ dir: 'content/docs' });
  }
  ```

* 会影响内容打包方式的选项 (`dir`、`files`、`async`) 必须能被静态分析 (即字符串／布尔值字面值) 。动态逻辑请改放在 `schema` 或 `mdxOptions` 等选项中。

* Macro API 目前尚不支持 [`dynamic`](/docs/mdx/async#dynamic-mode) 集合。如需延迟加载，建议改用 [`async`](/docs/mdx/async)。

* 不支持从 `fumadocs-mdx/macro` 重新导出。
