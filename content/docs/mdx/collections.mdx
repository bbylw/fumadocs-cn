## 定义集合 [#define-collections]

你可以定义集合来解析特定的一组文件。本页示例会在 `source.config.ts` 中定义集合，而 [Macro API](/docs/mdx/macro) 则是在 `lib/source.ts` 中定义，两者的选项大致相同。

```ts
import { defineCollections } from 'fumadocs-mdx/config';
import { z } from 'zod';

export const blog = defineCollections({
  type: 'doc',
  dir: './content/blog',
  schema: z.object({
    // schema
  }),
  // 其他选项
});
```

### `type` [#type]

集合可接受的类型。

```ts
import { defineCollections } from 'fumadocs-mdx/config';

// 仅扫描 meta 文档
export const metaFiles = defineCollections({
  type: 'meta',
  // 选项
});
```

* `type: meta`

  接受 JSON/YAML 文件，以及具有默认导出 (default export) 的代码模块 (`meta.ts` 或 `meta.js`) 。请参阅 [Meta](/docs/page-conventions#meta)。可用选项：

  <auto-type-table path="./props.ts" name="MetaCollection" />

* `type: doc`

  Markdown/MDX 文档。可用选项：

  <auto-type-table path="./props.ts" name="DocCollection" />

### `schema` [#schema]

用来验证文件数据的 schema (`doc` 类型验证的是 frontmatter，`meta` 类型验证的是文件内容) 。

```ts
import { defineCollections } from 'fumadocs-mdx/config';
import { z } from 'zod';

export const blog = defineCollections({
  type: 'doc',
  dir: './content/blog',
  schema: z.object({
    name: z.string(),
  }),
});
```

> 支持与 [Standard Schema](https://standardschema.dev) 兼容的函数库，包括 Zod。

请注意，验证是在构建时进行，因此输出必须可序列化。
你也可以传入一个函数，该函数会接收转换上下文 (transform context) 。

```ts
import { defineCollections } from 'fumadocs-mdx/config';
import { z } from 'zod';

export const blog = defineCollections({
  type: 'doc',
  dir: './content/blog',
  schema: (ctx) => {
    return z.object({
      name: z.string(),
      testPath: z.string().default(
        // 文档的绝对路径
        ctx.path,
      ),
    });
  },
});
```

### `mdxOptions` [#mdxoptions]

针对以 unified 编译的集合，在集合层级自定义 MDX 选项。

> 此 API 仅适用于 `doc` 类型。

```ts title="source.config.ts"
import { defineCollections } from 'fumadocs-mdx/config';

export const blog = defineCollections({
  type: 'doc',
  dir: './content/blog',
  mdxOptions: {
    // MDX 选项
  },
});
```

这是刻意的设计：此设置会移除你的全域设置与 Fumadocs MDX 所应用的所有默认设置，让你完全掌控 MDX 选项。

你可以使用 [`applyMdxPreset`](/docs/mdx/mdx) 应用默认的 MDX 设置组合。

```ts title="source.config.ts"
import { applyMdxPreset, defineCollections } from 'fumadocs-mdx/config';

export const blog = defineCollections({
  type: 'doc',
  dir: './content/blog',
  mdxOptions: applyMdxPreset({
    // 扩展默认组合
  }),
});
```

### `compiler` [#compiler]

> 此 API 仅适用于 `doc` 类型。

改用 [Sätteri](/docs/mdx/mdx#satteri) 而非 unified 来编译此集合，并改为传入 `satteriOptions` 以取代 `mdxOptions`。

```ts title="source.config.ts"
import { defineCollections } from 'fumadocs-mdx/config';

export const blog = defineCollections({
  type: 'doc',
  dir: './content/blog',
  compiler: 'satteri',
  // 可选，默认为全域的 `satteriOptions`
  satteriOptions: {
    // Sätteri 选项
  },
});
```

与 `mdxOptions` 不同，除非你传入 `preset: 'minimal'`，否则集合层级的 `satteriOptions` 仍会沿用内置的默认组合。此外，它会直接取代全域的 `satteriOptions`，而不会与其合并。

### `postprocess` [#postprocess]

> 此 API 仅适用于 `doc` 类型。

你可以使用 `postprocess` API 将构建阶段的信息传递至运行时。

* #### `includeProcessedMarkdown` [#includeprocessedmarkdown]

  导出由 [Remark LLMs](/docs/headless/mdx/remark-llms) 生成的文档 Markdown。可传入 `true` 或其选项。

  ```ts tab="docs"
  import { defineDocs } from 'fumadocs-mdx/config';

  export default defineDocs({
    docs: {
      postprocess: {
        // [!code ++]
        includeProcessedMarkdown: true,
      },
    },
  });
  ```

  ```ts tab="doc"
  import { defineCollections } from 'fumadocs-mdx/config';

  export const blog = defineCollections({
    type: 'doc',
    postprocess: {
      // [!code ++]
      includeProcessedMarkdown: true,
    },
  });
  ```

  请使用 `getText('processed')` 读取，例如通过 `loader()`：

  ```ts
  import { source } from '@/lib/source';

  const page = source.getPage('...');
  console.log(await page.data.getText('processed'));
  ```

* #### `valueToExport` [#valuetoexport]

  部分 remark 插件会将输出保存在 `vfile.data` (编译阶段的内存) 中，你的代码无法访问这些数据。

  你可以指定要纳入的属性名称，这些属性会转换为 ESM 导出，让你在导入 MDX 文件时即可访问。

  ```ts tab="docs"
  import { defineDocs } from 'fumadocs-mdx/config';

  export default defineDocs({
    docs: {
      postprocess: {
        // [!code ++]
        valueToExport: ['dataName'],
      },
    },
  });
  ```

  ```ts tab="doc"
  import { defineCollections } from 'fumadocs-mdx/config';

  export const blog = defineCollections({
    type: 'doc',
    postprocess: {
      // [!code ++]
      valueToExport: ['dataName'],
    },
  });
  ```

## 定义 Docs [#define-docs]

为 Fumadocs 定义集合。

```ts
import { defineDocs } from 'fumadocs-mdx/config';

export const docs = defineDocs({
  dir: '/my/content/dir',
  docs: {
    // 选填，`doc` 集合的选项
  },
  meta: {
    // 选填，`meta` 集合的选项
  },
});
```

### `dir` [#dir]

请通过 `defineDocs` 自定义内容目录，而不是在个别集合中分别设置：

```ts
import { defineDocs } from 'fumadocs-mdx/config';

export const docs = defineDocs({
  dir: 'content/guides',
});
```

### `schema` [#schema-1]

你可以扩展 `docs` 与 `meta` 默认的 Zod 4 schema。

```ts
import { defineDocs } from 'fumadocs-mdx/config';
import { metaSchema, pageSchema } from 'fumadocs-core/source/schema';
import { z } from 'zod';

export const docs = defineDocs({
  docs: {
    schema: pageSchema.extend({
      index: z.boolean().default(false),
    }),
  },
  meta: {
    schema: metaSchema.extend({
      // 其他属性
    }),
  },
});
```
