---
title: MDX 默认组合
description: 自定义 MDX 处理器的默认设置。
---

Fumadocs MDX 提供 MDX 默认组合，可简化**语法高亮**等功能的设置。

它默认使用 unified 进行编译。你也可以让集合改用 [Sätteri](#satteri) 编译，Sätteri 同样提供包含相同插件的默认组合。

## 默认组合 (Default Preset)  [#default-preset]

这是专为文档网站设计的默认组合，在全域 MDX 选项中默认为启用。

如需覆盖默认值，可传入一个继承自 [`ProcessorOptions`](https://mdxjs.com/packages/mdx/#processoroptions) 的界面：

### Remark 插件 [#remark-plugins]

以下插件会默认应用：

* Remark GFM - [GitHub Flavored Markdown](https://github.github.com/gfm)。
* [Remark Heading](/docs/headless/mdx/headings) - 截取目录。
* [Remark Image](/docs/headless/mdx/remark-image) - 处理图片。
* [Remark Code Tab](/docs/markdown#tab-groups) - 代码块的选项卡分组。
* [Remark NPM](/docs/headless/mdx/remark-npm) - 包管理器指令。
* [Remark Structure](/docs/headless/mdx/structure) - 生成搜索索引。

[引入](/docs/mdx/include)功能一律启用，即使未使用此默认集也是如此。

你可以通过以下方式添加其他 remark 插件：

```ts tab="Global Config"
import { defineConfig } from 'fumadocs-mdx/config';
import { myPlugin } from './remark-plugin';

export default defineConfig({
  mdxOptions: {
    remarkPlugins: [myPlugin],
    // 你也可以传入函数来控制 remark 插件的顺序。
    remarkPlugins: (v) => [myPlugin, ...v],
  },
});
```

```ts tab="Collection Config"
import { defineCollections, applyMdxPreset } from 'fumadocs-mdx/config';
import { myPlugin } from './remark-plugin';

export const blog = defineCollections({
  type: 'doc',
  mdxOptions: applyMdxPreset({
    remarkPlugins: [myPlugin],
    // 你也可以传入函数来控制 remark 插件的顺序。
    remarkPlugins: (v) => [myPlugin, ...v],
  }),
});
```

### Rehype 插件 [#rehype-plugins]

默认会应用以下插件：

* [Rehype Code](/docs/headless/mdx/rehype-code) - 语法高亮。
* [Rehype 目录](/docs/headless/mdx/headings#rehype-toc) - 导出目录。

如同 remark 插件，你可以传入数组或函数来添加其他 rehype 插件。

```ts tab="Global Config"
import { defineConfig } from 'fumadocs-mdx/config';
import { myPlugin } from './rehype-plugin';

export default defineConfig({
  mdxOptions: {
    rehypePlugins: (v) => [myPlugin, ...v],
  },
});
```

```ts tab="Collection Config"
import { defineCollections, applyMdxPreset } from 'fumadocs-mdx/config';
import { myPlugin } from './rehype-plugin';

export const blog = defineCollections({
  type: 'doc',
  mdxOptions: applyMdxPreset({
    rehypePlugins: (v) => [myPlugin, ...v],
  }),
});
```

### 自定义内置插件 [#customize-built-in-plugins]

你可以自定义内置插件的选项，例如：

```ts tab="Global Config"
import { defineConfig } from 'fumadocs-mdx/config';

export default defineConfig({
  mdxOptions: {
    rehypeCodeOptions: {
      // 选项
    },
    remarkImageOptions: {
      // 将图片占位效果设为 `blur`（仅适用于 Next.js）
      placeholder: 'blur',
    },
    remarkHeadingOptions: {
      // 选项
    },
  },
});
```

```ts tab="Collection Config"
import { defineCollections, applyMdxPreset } from 'fumadocs-mdx/config';

export const blog = defineCollections({
  type: 'doc',
  mdxOptions: applyMdxPreset({
    rehypeCodeOptions: {
      // 选项
    },
    remarkImageOptions: {
      // 选项
    },
    remarkHeadingOptions: {
      // 选项
    },
  }),
});
```

## Sätteri [#satteri]

[Sätteri](https://github.com/bruits/satteri) 是一款具备独立插件模型的编译器。请先安装：

```package-install
@fumadocs/satteri satteri
```

在[集合](/docs/mdx/collections#compiler)中设置 `compiler: 'satteri'`。该集合会读取全域的 `satteriOptions`，而非 `mdxOptions`：

```ts title="source.config.ts"
import { defineConfig, defineDocs } from 'fumadocs-mdx/config';
import { remarkSteps } from '@fumadocs/satteri/remark-steps';

export const docs = defineDocs({
  docs: {
    compiler: 'satteri',
  },
});

export default defineConfig({
  satteriOptions: {
    // 用来取代 remark 插件；`hastPlugins` 则用来取代 rehype 插件
    mdastPlugins: [remarkSteps()],
    // 内置插件的选项与 `mdxOptions` 中的相同
    rehypeCodeOptions: {
      themes: { light: 'github-light', dark: 'github-dark' },
    },
  },
});
```

Remark 与 rehype 插件无法在 Sätteri 上运行。Fumadocs 已将自家插件移植至 `@fumadocs/satteri/<name>`，例如 `@fumadocs/satteri/remark-steps`。这两个插件选项都可接受数组或函数，用法与 `mdxOptions` 相同。

默认组合会应用与 unified 相同的插件。GFM 与 directives 是默认启用的解析器 `features`，而设置 `features: { math: true }` 也会使用 KaTeX 渲染[数学公式](/docs/markdown/math)。

全域的 `compiler` 选项仅用于选择集合以外 MDX 文件的编译器。

## Source Map [#source-map]

由于生成 source map 会拖慢编译速度，unified 默认会禁用此功能。

若要激活，请安装 `source-map`，并将其生成器传入 MDX 选项：

```npm
npm i -D source-map
```

```ts tab="Global Config" title="source.config.ts"
import { defineConfig } from 'fumadocs-mdx/config';
import { SourceMapGenerator } from 'source-map';

export default defineConfig({
  mdxOptions: {
    SourceMapGenerator,
  },
});
```

```ts tab="Collection Config"
import { defineCollections, applyMdxPreset } from 'fumadocs-mdx/config';
import { SourceMapGenerator } from 'source-map';

export const blog = defineCollections({
  type: 'doc',
  mdxOptions: applyMdxPreset({
    SourceMapGenerator,
  }),
});
```

编译后内容所抛出的错误，现在可以追溯回原始的 Markdown 文件。
