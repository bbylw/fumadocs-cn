## 概览 [#overview]

在配置文件中定义集合后，集合项目会编译成应用可访问的 JavaScript 文件。

编译工作虽然由 Fumadocs MDX 的打包工具／运行时插件负责，但它也会生成**进入点文件**，让你访问集合的输出内容。

如果你偏好在应用模块中定义集合，请参阅 [Macro API](/docs/mdx/macro)。

### 进入点文件 [#entry-files]

集合的输出会生成在输出目录中，你可以通过进入点文件访问。
