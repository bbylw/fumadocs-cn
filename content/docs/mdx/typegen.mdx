---
title: 产生型别
description: 不必执行 dev/build 伺服器即可产生型别
---

您可以执行 `fumadocs-mdx`，为 `source.config.ts` 中定义的集合产生型别与进入点档案 (即 `.source` 资料夹) 。使用 [Macro API](/docs/mdx/macro) 的集合则不需要产生任何档案。

您也可以选择在 postinstall 阶段执行此指令，确保专案初始化时就会产生型别。

```json title="package.json"
{
  "scripts": {
    "postinstall": "fumadocs-mdx"
  }
}
```

如果您的专案为设定档或输出目录使用自订路径，可以透过命令引数指定：

```npm
npx fumadocs-mdx "config-path" "output-dir"
```

* `config-path`：Fumadocs MDX 设定档，预设为 `source.config.ts`。
* `output-dir`：产生的档案所在目录，预设为 `.source`。
