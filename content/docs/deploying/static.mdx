---
title: 静态建置
description: 使用 Fumadocs 输出静态网站。
---

静态建置没有伺服器，因此下列功能无法运作：

* 搜寻伺服器。请改用[静态搜寻](#search)。
* [询问 AI](/docs/integrations/llms#ask-ai)，因为其聊天路由需要呼叫 AI 模型。
* [MCP 伺服器](/docs/integrations/llms#mcp-server)。

### 搜寻 [step] [#search]

#### 内建搜寻 [#built-in-search]

1. [设定搜寻伺服器](/docs/headless/search/orama#static-export)。
2. [设定搜寻 UI／用户端](/docs/search/orama#static)。

完成设定后，您的应用程式会以静态方式储存搜寻索引，并改在浏览器端执行搜寻运算。

#### 云端解决方案 [#cloud-solutions]

由于搜寻功能由远端伺服器提供，静态汇出无需额外设定即可运作。

### 部署 [step] [#deployment]


  启用静态汇出，即可输出不需 Node.js 伺服器也能执行的静态 HTML 网站：

  ```js title="next.config.mjs"
  /**
   * @type {import('next').NextConfig}
   */
  const nextConfig = {
    output: 'export',

    // 选用：将连结 `/me` 改为 `/me/`，并将输出的 `/me.html` 改为 `/me/index.html`
    // trailingSlash: true,

    // 选用：避免自动将 `/me` 导向 `/me/`，改为保留原本的 `href`
    // skipTrailingSlashRedirect: true,
  };
  ```

  限制与详细资讯请参阅 [Next.js 文件](https://nextjs.org/docs/app/guides/static-exports)。



  使用 SPA 模式时，您可以将 `build/client` 目录当作静态网站部署。

  <Callout type="warning" title="别忘了预先算绘">
    在 SPA 模式下，所有伺服器端载入器都必须预先算绘。

    详细资讯请参阅 [React Router 文件](https://reactrouter.com/how-to/spa)。
  </Callout>

  ```ts title="react-router.config.ts"
  import type { Config } from '@react-router/dev/config';
  import { glob } from 'node:fs/promises';
  import { createGetUrl, getSlugs } from 'fumadocs-core/source';

  const getUrl = createGetUrl('/docs');

  export default {
    // 停用 SSR [!code highlight:2]
    ssr: false,

    // [!code ++:9]
    async prerender({ getStaticPaths }) {
      const paths: string[] = [...getStaticPaths()];

      for await (const entry of glob('**/*.{md,mdx}', { cwd: 'content/docs' })) {
        paths.push(getUrl(getSlugs(entry)));
      }

      return paths;
    },
  } satisfies Config;
  ```



  设定 SPA 模式与预先算绘。详细资讯请参阅 [SPA Mode](https://tanstack.com/start/latest/docs/framework/react/guide/spa-mode)。

  ```ts title="vite.config.ts"
  import { tanstackStart } from '@tanstack/react-start/plugin/vite';
  import { defineConfig } from 'vite';

  export default defineConfig({
    plugins: [
      // ...其他外挂
      tanstackStart({
        spa: {
          enabled: true,
          // TanStack Router 会自动爬取您的页面 [!code ++:4]
          prerender: {
            enabled: true,
          },
          // 若有未显示在 UI 上的隐藏路径，可以手动明确加入。 [!code highlight:6]
          pages: [
            {
              path: '/docs/test',
            },
          ],
        },
      }),
    ],
  });
  ```
