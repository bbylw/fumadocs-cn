title: 本机 Markdown（Sätteri）
description: 适用于本机 Markdown 内容的内容来源，以 Sätteri 编译。
---

`@fumadocs/satteri/local-md` 是适用于本机 Markdown/MDX 档案的内容来源，改用 [Sätteri](https://github.com/bruits/satteri) 编译，而非 unified/remark 管线。

它与 [`@fumadocs/local-md`](/docs/integrations/content/local-md) 的 API 相同，同样无需打包，因此可直接在执行阶段运作，不需要型别产生或打包步骤。

若您想使用 Sätteri 编译器、它的外挂模型，以及 Fumadocs Sätteri 预设组合，请选用此内容来源。

### 差异 [#differences]

* 编译结果一律为 JavaScript，因此不提供虚拟 JavaScript 引擎选项，算绘时会使用原生引擎。
* 外挂为 Sätteri 外挂，需透过 `satteriOptions` 设定，而非 remark/rehype 外挂。

<Callout type="warn">
  请勿将不受信任的 Markdown/MDX 档案放在 `dir` 中，因为这些档案可能会以 JavaScript 形式执行，或参照伺服器端的档案。
</Callout>

## 安装设定 [#setup]

```package-install
@fumadocs/satteri shiki
```

> 之所以需要安装 `shiki`，是因为打包工具必须将它外部化 (externalize) 。

建立 `localMd` 实例，并将它连接到 Fumadocs：

```ts title="lib/source.ts"
import { dynamicLoader } from 'fumadocs-core/source';
import { localMd } from '@fumadocs/satteri/local-md';

const docs = localMd({
  dir: 'content/docs',
});

const docsLoader = dynamicLoader(docs.dynamicSource(), {
  baseUrl: '/docs',
});

export async function getSource() {
  return docsLoader.get();
}
```
传入 `frontmatterSchema` 与 `metaSchema`，即可自订验证用的 schema：

```ts title="lib/source.ts"
import { localMd } from '@fumadocs/satteri/local-md';
import { pageSchema, metaSchema } from 'fumadocs-core/source/schema';

const docs = localMd({
  dir: 'content/docs',
  frontmatterSchema: pageSchema.extend({
    // ...
  }),
  metaSchema: metaSchema.extend({
    // ...
  }),
});
```
`satteriOptions` 会经由 Fumadocs Sätteri 预设集传入，因此外挂及其选项的设定方式与 Fumadocs MDX 相同：

```ts title="lib/source.ts"
const docs = localMd({
  dir: 'content/docs',
  satteriOptions: {
    rehypeCodeOptions: {
      themes: { light: 'github-light', dark: 'github-dark' },
    },
    mdastPlugins: [myPlugin()],
  },
});
```

传入函式即可延迟建立选项。

## 使用方式 [#usage]

`getSource()` 会回传一个[内容载入器](/docs/headless/source-api)。算绘页面的方式与 [`@fumadocs/local-md`](/docs/integrations/content/local-md#usage) 相同，只是改从 `@fumadocs/satteri/local-md` 汇入。

每个页面都有 `load()`，可编译该页面并回传算绘器：

```tsx
const page = source.getPage(slugs);
const { body, toc } = await (await page.data.load()).render();
```

算绘器也提供 `structuredData` 与 `exports`，可用来取得文件或其外挂所汇出的值。

  

  ```tsx
  const serialized = (await page.data.load()).serialize();
  ```

  ```tsx title="components/content.tsx"
  'use client';
  import {
    rendererFromSerialized,
    type MarkdownRendererSerializedOptions,
  } from '@fumadocs/satteri/local-md/client';

  export function Content({ serialized }: { serialized: MarkdownRendererSerializedOptions }) {
    return rendererFromSerialized(serialized).renderSync().body;
  }
  ```


### 引入 [#include]

[`<include>`](/docs/mdx/include) 与 `::include` 指令皆已预设启用：

```mdx title="content/docs/page.mdx"
<include>../shared/note.md</include>
```
来源会在执行阶段读取档案，因此预设不会监看这些档案。


  在开发期间，请在执行应用程式的同时，执行 `@fumadocs/local-md` 的开发伺服器：

  ```json title="package.json"
  {
    "scripts": {
      "dev": "local-md dev -- next dev"
    }
  }
  ```

  将来源连接至该伺服器：

  ```ts title="lib/source.ts"
  import { watchWithDevServer } from '@fumadocs/satteri/local-md/dev/ws';

  if (process.env.NODE_ENV === 'development') {
    void watchWithDevServer(docs);
  }
  ```

  这会让伺服器上的来源失效，但 Next.js 仍会在浏览器中保留已算绘的页面。请在根版面配置中算绘 ``，让页面也一并重新整理：

  ```tsx title="app/layout.tsx"
  import { DevClient } from '@fumadocs/satteri/local-md/dev/react-client';

  export function RootLayout({ children }) {
    return (
      <RootProvider>
        {/* [!code ++] */}
        <DevClient />
        {children}
      </RootProvider>
    );
  }
  ```



  在开发期间，Vite 外挂会透过 Vite 的档案监看器让来源失效。请将外挂加入设定，并连接来源：

  
    ```ts tab="vite.config.ts"
    import { defineConfig } from 'vite';
    import { localContentPlugin } from '@fumadocs/satteri/local-md/dev/vite';

    export default defineConfig({
      plugins: [localContentPlugin()],
    });
    ```
  

  
    ```ts tab="waku.config.ts"
    import { defineConfig } from 'waku/config';
    import { localContentPlugin } from '@fumadocs/satteri/local-md/dev/vite';

    export default defineConfig({
      vite: {
        plugins: [localContentPlugin()],
      },
    });
    ```
  

  
    ```js tab="astro.config.mjs"
    import { defineConfig } from 'astro/config';
    import { localContentPlugin } from '@fumadocs/satteri/local-md/dev/vite';

    export default defineConfig({
      vite: {
        plugins: [localContentPlugin()],
      },
    });
    ```
  

  ```ts tab="lib/source.ts"
  import { watchWithVite } from '@fumadocs/satteri/local-md/dev/vite';

  if (import.meta.env.DEV) {
    watchWithVite(docs);
  }
  ```


引入的档案也会受到监看。若要自行串接监看器，请监看 `docs.dir` 以及传入 `docs.onDependency()` 的档案，并在档案变更时呼叫 `docs.invalidateFile(path)`。

### 停用重新验证 [#disable-revalidation]

若您只需要一次性的快照，请使用 `staticSource()`，如此一来，一般的 `loader()` 即可正常运作：

```ts title="lib/source.ts"
import { loader } from 'fumadocs-core/source';

export const source = loader(await docs.staticSource(), {
  baseUrl: '/docs',
});
```
