## 简介 [#introduction]

`fumadocs-python` 会根据 Python 套件的原始码与 docstring 产生文件。透过一个 Python 指令将套件内容收集成 JSON 档案后，您可以直接将它作为执行阶段的内容来源提供，或将其转换为 MDX 档案。

每个模组与类别都会产生一个页面，其中的函式、属性与参数则由内附的元件负责算绘。

## 设定 [#setup]

请安装套件：

```package-install
fumadocs-python shiki
```
请安装 Python 指令，它会从您的 Python 套件收集文件：

```bash
pip install ./node_modules/fumadocs-python
```

产生套件的 JSON 档案：

```bash
fumapy-generate httpx
```

此指令会将 `httpx.json` 写入目前目录，若要变更位置，请传入 `--dir`。

`Parameters:` 和 `Returns:` 等 docstring 区段会以 Google 风格解析；若要使用其他风格，请传入 `--docstring-style numpy` 或 `--docstring-style sphinx`。不属于这些风格的 docstring 则会以 Markdown 算绘。

### 样式 [#styles]

这些元件以 Tailwind CSS 撰写样式，请加入预设集 (preset) ：

```css title="Tailwind CSS"
@import 'tailwindcss';
@import 'fumadocs-ui/css/neutral.css';
@import 'fumadocs-ui/css/preset.css';
/* [!code ++] */
@import 'fumadocs-python/preset.css';
```
从 JSON 档案建立来源，并将它传入 `loader()`：

```ts title="lib/source.ts"
import { loader } from 'fumadocs-core/source';
import { createPython } from 'fumadocs-python';

const python = createPython({
  file: './httpx.json',
  // 页面会依根模组名称分组到同名目录中，例如 `httpx._client.Client` 的网址为 `/docs/httpx/_client/Client`。
  // 设为 "none" 则会改将页面放在来源的根层级。
  groupBy: 'module',
});

export const source = loader(await python.staticSource(), {
  baseUrl: '/docs',
  // 为产生的页面加上 `module` 或 `class` 徽章
  plugins: [python.loaderPlugin()],
});
```

接著载入并算绘页面：


  ```tsx title="app/docs/[[...slug]]/page.tsx"
  import { source } from '@/lib/source';
  import { notFound } from 'next/navigation';
  import { DocsBody, DocsPage, DocsTitle } from 'fumadocs-ui/layouts/docs/page';

  export default async function Page({ params }: PageProps<'/docs/[[...slug]]'>) {
    const page = source.getPage((await params).slug);
    if (!page) notFound();

    const data = await page.data.load();
    const { body, toc } = await data.render();

    return (
      <DocsPage toc={toc}>
        <DocsTitle>{page.data.title}</DocsTitle>
        <DocsBody>{body}</DocsBody>
      </DocsPage>
    );
  }
  ```



  ```tsx title="src/pages/docs/[...slugs].tsx"
  import type { PageProps } from 'waku/router';
  import { unstable_notFound } from 'waku/router/server';
  import { DocsBody, DocsPage, DocsTitle } from 'fumadocs-ui/layouts/docs/page';
  import { source } from '@/lib/source';

  export default async function Page({ slugs }: PageProps<'/docs/[...slugs]'>) {
    const page = source.getPage(slugs);
    if (!page) unstable_notFound();

    const data = await page.data.load();
    const { body, toc } = await data.render();

    return (
      <DocsPage toc={toc}>
        <DocsTitle>{page.data.title}</DocsTitle>
        <DocsBody>{body}</DocsBody>
      </DocsPage>
    );
  }

  export async function getConfig() {
    return {
      render: 'static',
      staticPaths: source.generateParams().map((item) => item.slug),
    } as const;
  }
  ```


### Dynamic 来源 [#dynamic-source]

`staticSource()` 只会读取 JSON 档案一次。若想在不重新启动的情况下套用重新产生的档案，请改用 `dynamicSource()` 搭配 `dynamicLoader()`：

```ts title="lib/source.ts"
import { dynamicLoader } from 'fumadocs-core/source';
import { createPython } from 'fumadocs-python';

const python = createPython({
  file: './httpx.json',
});

const pythonLoader = dynamicLoader(python.dynamicSource(), {
  baseUrl: '/docs',
});

export function getSource() {
  return pythonLoader.get();
}
```

呼叫 `pythonLoader.invalidate()` 后会重新读取档案；在此之前，`getSource()` 都会回传同一个[内容载入器](/docs/headless/source-api)实例。

### 编译器 [#compiler]

原始码与 docstring 范例会使用 [Shiki](https://shiki.style) 进行语法突显，可透过 `rehypeCodeOptions` 调整相关设定。您也可以传入 remark/rehype 外挂：

```ts title="lib/source.ts"
import { createPython } from 'fumadocs-python';
import remarkMath from 'remark-math';
import rehypeKatex from 'rehype-katex';

const python = createPython({
  file: './httpx.json',
  rehypeCodeOptions: {
    themes: {
      light: 'github-light',
      dark: 'github-dark',
    },
  },
  remarkPlugins: [remarkMath],
  rehypePlugins: [rehypeKatex],
});
```
您也可以改为将 JSON 转换成 MDX 档案，并与其他内容放在一起。模组与类别之间的连结会直接写入档案，因此 `baseUrl` 必须与输出目录实际对外提供的路径一致：

```js tab="scripts/generate-docs.mjs"
import { rimraf } from 'rimraf';
import * as Python from 'fumadocs-python';
import * as fs from 'node:fs/promises';

const content = JSON.parse(await fs.readFile('./httpx.json', 'utf-8'));
// 清除先前的输出
await rimraf('content/docs/httpx');

await Python.write(Python.convert(content, { baseUrl: '/docs' }), 'content/docs');
```

```tsx tab="components/mdx.tsx"
import defaultMdxComponents from 'fumadocs-ui/mdx';
import type { MDXComponents } from 'mdx/types';
import * as Python from 'fumadocs-python/components';

const { createPythonComponents, ...PythonComponents } = Python;

export function getMDXComponents(components?: MDXComponents): MDXComponents {
  return {
    ...defaultMdxComponents,
    ...PythonComponents,
    ...components,
  };
}
```
