---
title: 本机 HTML
description: 适用于本机 HTML 档案的内容来源。
---

`@fumadocs/local-html` 是用于本机 HTML 档案的内容来源。它在设计上就不需要打包，因此能完全在执行阶段运作。

它专为以 HTML 形式取得、而非由您自行撰写的页面而设计，例如汇出的简报、报告，以及其他工具产生的输出。每个档案都会依照您的文件主题进行调整，而不是照原样算绘。

与[本机 Markdown](/docs/integrations/content/local-md) 不同，HTML 在这里被视为需要调整的资料，而非用来撰写内容的文件格式。

### 限制 [#limitations]

* 指令码会被移除，原始页面的互动行为不会保留。
* 内容中无法使用 MDX 元件，但您可以在算绘阶段将 HTML 标签对应到元件。
* 处理过程只是转换，而非净化 (sanitization) 。所有可执行的内容都会被移除，但其余标记会原封不动地算绘，而其中引用的资源 (尤其是图片) 会在每位使用者开启页面时被载入。请确保内容目录中只放您信任的档案，例如您自己的 Markdown 内容。

## 设定 [#setup]

请安装此套件：

```package-install
@fumadocs/local-html
```

建立 `localHtml` 实例，并将它串接到 Fumadocs：

```ts title="lib/source.ts"
import { dynamicLoader } from 'fumadocs-core/source';
import { localHtml } from '@fumadocs/local-html';

const pages = localHtml({
  dir: 'content/pages',
  // 选项
});

const pagesLoader = dynamicLoader(pages.dynamicSource(), {
  baseUrl: '/docs',
});

export async function getSource() {
  return pagesLoader.get();
}
```

`pagesLoader.get()` 回传的来源是一般的[内容载入器](/docs/headless/source-api)实例。

## 使用方式 [#usage]

`page.data.load()` 会回传已处理内容的算绘器。


  ```tsx tab="app/docs/layout.tsx"
  import { getSource } from '@/lib/source';
  import { DocsLayout } from 'fumadocs-ui/layouts/docs';

  export default async function Layout({ children }: LayoutProps<'/docs'>) {
    const source = await getSource();

    return <DocsLayout tree={source.getPageTree()}>{children}</DocsLayout>;
  }
  ```

  ```tsx tab="app/docs/[[...slug]]/page.tsx"
  import { notFound } from 'next/navigation';
  import { DocsBody, DocsDescription, DocsPage, DocsTitle } from 'fumadocs-ui/layouts/docs/page';
  import { getSource } from '@/lib/source';

  export default async function Page(props: PageProps<'/docs/[[...slug]]'>) {
    const params = await props.params;
    const source = await getSource();
    const page = source.getPage(params.slug);
    if (!page) notFound();

    const renderer = await page.data.load();
    const { body, toc } = await renderer.render();

    return (
      <DocsPage toc={toc}>
        <DocsTitle>{page.data.title}</DocsTitle>
        <DocsDescription>{page.data.description}</DocsDescription>
        <DocsBody>{body}</DocsBody>
      </DocsPage>
    );
  }
  ```



  ```tsx title="app/routes/docs.tsx"
  import type { Route } from './+types/docs';
  import { useMemo } from 'react';
  import { DocsLayout } from 'fumadocs-ui/layouts/docs';
  import { DocsBody, DocsDescription, DocsPage, DocsTitle } from 'fumadocs-ui/layouts/docs/page';
  import { useFumadocsLoader } from 'fumadocs-core/source/client';
  import { rendererFromSerialized } from '@fumadocs/local-html/client';
  import { getSource } from '@/lib/source';

  export async function loader({ params }: Route.LoaderArgs) {
    const source = await getSource();
    const page = source.getPage(params['*'].split('/').filter((v) => v.length > 0));
    if (!page) throw new Response('Not found', { status: 404 });

    const renderer = await page.data.load();
    return {
      title: page.data.title,
      description: page.data.description,
      // 语法树，于用户端算绘
      render: renderer.serialize(),
      pageTree: await source.serializePageTree(source.getPageTree()),
    };
  }

  export default function Page({ loaderData }: Route.ComponentProps) {
    const { title, description, render, pageTree } = useFumadocsLoader(loaderData);
    const renderer = useMemo(() => rendererFromSerialized(render), [render]);
    const { body, toc } = renderer.renderSync();

    return (
      <DocsLayout tree={pageTree}>
        <DocsPage toc={toc}>
          <DocsTitle>{title}</DocsTitle>
          <DocsDescription>{description}</DocsDescription>
          <DocsBody>{body}</DocsBody>
        </DocsPage>
      </DocsLayout>
    );
  }
  ```



  ```tsx title="src/routes/docs/$.tsx"
  import { createFileRoute, notFound } from '@tanstack/react-router';
  import { createServerFn } from '@tanstack/react-start';
  import { useMemo } from 'react';
  import { DocsLayout } from 'fumadocs-ui/layouts/docs';
  import { DocsBody, DocsDescription, DocsPage, DocsTitle } from 'fumadocs-ui/layouts/docs/page';
  import { useFumadocsLoader } from 'fumadocs-core/source/client';
  import { rendererFromSerialized } from '@fumadocs/local-html/client';
  import type { HtmlRendererOptions } from '@fumadocs/local-html';
  import { getSource } from '@/lib/source';

  // server function 结果的型别层级检查无法验证语法树，
  // 因此需将其注册为可序列化（若无法解析 `@tanstack/router-core`，请先安装）
  declare module '@tanstack/router-core' {
    interface SerializableExtensions {
      fumadocsHtmlRenderer: HtmlRendererOptions;
    }
  }

  export const Route = createFileRoute('/docs/$')({
    component: Page,
    loader: ({ params }) => serverLoader({ data: params._splat?.split('/') ?? [] }),
  });

  const serverLoader = createServerFn({
    method: 'GET',
  })
    .validator((slugs: string[]) => slugs)
    .handler(async ({ data: slugs }) => {
      const source = await getSource();
      const page = source.getPage(slugs);
      if (!page) throw notFound();

      const renderer = await page.data.load();
      return {
        title: page.data.title,
        description: page.data.description,
        // 语法树，会在用户端算绘
        render: renderer.serialize(),
        pageTree: await source.serializePageTree(source.getPageTree()),
      };
    });

  function Page() {
    const { title, description, render, pageTree } = useFumadocsLoader(Route.useLoaderData());
    const renderer = useMemo(() => rendererFromSerialized(render), [render]);
    const { body, toc } = renderer.renderSync();

    return (
      <DocsLayout tree={pageTree}>
        <DocsPage toc={toc}>
          <DocsTitle>{title}</DocsTitle>
          <DocsDescription>{description}</DocsDescription>
          <DocsBody>{body}</DocsBody>
        </DocsPage>
      </DocsLayout>
    );
  }
  ```

  ```tsx tab="src/components/docs.tsx"
  import { useMemo } from 'react';
  import { type SerializedPageTree, useFumadocsLoader } from 'fumadocs-core/source/client';
  import { DocsLayout } from 'fumadocs-ui/layouts/docs';
  import { DocsBody, DocsDescription, DocsPage, DocsTitle } from 'fumadocs-ui/layouts/docs/page';
  import { rendererFromSerialized } from '@fumadocs/local-html/client';
  import type { HtmlRendererOptions } from '@fumadocs/local-html';
  import { Provider, type ProviderProps } from '@/components/provider';

  export interface DocsProps extends ProviderProps {
    tree: SerializedPageTree;
    title: string;
    description?: string;
    // 语法树，在 island 中算绘
    render: HtmlRendererOptions;
  }

  export function Docs({ tree, title, description, render, ...props }: DocsProps) {
    const data = useFumadocsLoader({ tree });
    const renderer = useMemo(() => rendererFromSerialized(render), [render]);
    const { body, toc } = renderer.renderSync();

    return (
      <Provider {...props}>
        <DocsLayout tree={data.tree}>
          <DocsPage toc={toc}>
            <DocsTitle>{title}</DocsTitle>
            <DocsDescription>{description}</DocsDescription>
            <DocsBody>{body}</DocsBody>
          </DocsPage>
        </DocsLayout>
      </Provider>
    );
  }
  ```



  将元件传入 `render()`，即可将 HTML 标签对应到您自订的元件，例如带有锚点的标题：

  ```tsx
  import { getMDXComponents } from '@/components/mdx';

  const { body, toc } = await renderer.render(getMDXComponents());
  ```



  将元件传入 `renderSync()`，即可将 HTML 标签对应到您自订的元件，例如带有锚点的标题：

  ```tsx
  import { getMDXComponents } from '@/components/mdx';

  const { body, toc } = renderer.renderSync(getMDXComponents());
  ```


### 页面中继资料 [#page-metadata]

每个页面的标题与描述会从该页面的 `<head>` 读取：

* `<title>` 会作为页面标题。
* `<meta name="description">` 会作为页面描述。

您可以使用 `fumadocs:` meta 标签覆写这些值 (也可以设定图示) ，而无须更动页面上显示的内容：

```html
<meta name="fumadocs:title" content="My Page" />
<meta name="fumadocs:description" content="A short description." />
<meta name="fumadocs:icon" content="SquareBookmark" />
```

文件中每一组 `<meta name>`/`content` 也都可以透过 `page.data.metadata` 取得。

与其他本机来源一样，`meta.json` 档案可用来自订页面树，并透过 `metaSchema` 进行验证。

### 内容选项 [#content-options]

页面只会保留其内容元素：优先使用唯一的 `<main>`，其次是唯一的 `<article>`，若都没有则退回使用 `<body>`，并移除 `<header>` 与 `<nav>` 等页面外框元素。该元素的 `class` 与 `style` 属性会被移除，改由您主题的 prose 样式接手；其中的标题则会加上 id，供目录与搜寻功能使用。

以上每个部分都可以设定：

```ts
import { localHtml } from '@fumadocs/local-html';

const pages = localHtml({
  dir: 'content/pages',
  // 保留原始的 class/style 属性，不配合您的主题调整样式
  adaptStyles: false,
  // 从内容中额外移除指定的标签
  exclude: ['aside'],
  // 自订挑选页面内容所在元素的逻辑
  selectContent: (root) => {
    // 回传 hast 元素，或回传 undefined 以使用预设行为
  },
});
```
`<pre><code>` 区块会使用 [Shiki](https://shiki.style) 进行语法突显，选项与[本机 Markdown](/docs/integrations/content/local-md) 相同：

```ts
const pages = localHtml({
  dir: 'content/pages',
  rehypeCodeOptions: {
    themes: {
      light: 'github-light',
      dark: 'github-dark',
    },
  },
});
```

语言会从程式码区块的 `language-*` class 读取，该 class 可位于 `<code>` 或其外层的 `<pre>` 上：

```html
<pre><code class="language-ts">const answer: number = 42;</code></pre>
```

未指定语言的区块会以纯文字呈现。若要停用语法突显，请传入 `rehypeCodeOptions: false`。

### 热重载 [#hot-reload]

`@fumadocs/local-html` 会在执行阶段读取档案，因此预设不会监看这些档案。


  开发期间，请与您的应用程式同时执行内建的开发伺服器。它会在单一行程中监看您的档案，并透过 websocket 广播变更，因此即使 Next.js 以多个 worker 执行，也能正常运作。

  ```json title="package.json"
  {
    "scripts": {
      "dev": "local-html dev -- next dev"
    }
  }
  ```

  将来源连接到开发伺服器：

  ```ts title="lib/source.ts"
  import { watchWithDevServer } from '@fumadocs/local-html/dev/ws';

  if (process.env.NODE_ENV === 'development') {
    void watchWithDevServer(pages);
  }
  ```

  此指令会透过环境变数提供其 URL，因此不需要任何设定。若您自行执行伺服器，请明确传入 URL，并使用 `-p` 变更连接埠：

  ```ts
  void watchWithDevServer(pages, { url: 'ws://127.0.0.1:8000/_fumadocs_local_md' });
  ```

  这只会让伺服器上的来源失效，Next.js 仍会在浏览器中保留已算绘的页面。请在根版面配置中算绘 ``，让页面也跟著重新整理：

  ```tsx title="app/layout.tsx"
  import { DevClient } from '@fumadocs/local-html/dev/react-client';

  export function RootLayout({ children }) {
    return (
      <RootProvider>
        {/* [!code ++] */}
        <DevClient />
        {children}
      </RootProvider>
    );
  }
  ```



  开发期间，Vite 外挂会透过 Vite 的档案监看器让来源失效，不需要额外的行程或连接埠。请将外挂加入您的设定，并连接来源：

  
    ```ts tab="vite.config.ts"
    import { defineConfig } from 'vite';
    import { localContentPlugin } from '@fumadocs/local-html/dev/vite';

    export default defineConfig({
      plugins: [localContentPlugin()],
    });
    ```
  

  
    ```ts tab="waku.config.ts"
    import { defineConfig } from 'waku/config';
    import { localContentPlugin } from '@fumadocs/local-html/dev/vite';

    export default defineConfig({
      vite: {
        plugins: [localContentPlugin()],
      },
    });
    ```
  

  
    ```js tab="astro.config.mjs"
    import { defineConfig } from 'astro/config';
    import { localContentPlugin } from '@fumadocs/local-html/dev/vite';

    export default defineConfig({
      vite: {
        plugins: [localContentPlugin()],
      },
    });
    ```
  

  ```ts tab="lib/source.ts"
  import { watchWithVite } from '@fumadocs/local-html/dev/vite';

  if (import.meta.env.DEV) {
    watchWithVite(pages);
  }
  ```


若想改用您自己的监看器，请在档案变更时呼叫 `pages.invalidateFile(path)`。

### 停用重新验证 [#disable-revalidation]

若您只需要一次性的快照，不需要重新验证，可以使用 `staticSource()`。

它可搭配一般的 `loader()` 使用，不必局限于 `dynamicLoader()`：

```ts title="lib/source.ts"
import { loader } from 'fumadocs-core/source';
import { localHtml } from '@fumadocs/local-html';

const pages = localHtml({
  dir: 'content/pages',
});

export const source = loader(await pages.staticSource(), {
  baseUrl: '/docs',
});
```
