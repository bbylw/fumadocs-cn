---
title: 自行建置
description: 为 Fumadocs 打造您专属的内容来源。
---

实作自订内容来源的方式有两种：

### 使用载入器 API [#using-loader-api]

载入器 API 提供类似档案系统的介面，方便整合各种不同的内容来源。

详情请参阅[载入器 API `source`](/docs/headless/source-api/source)。

### 使用低阶 API [#using-low-level-api]

若需要更灵活的控制，您可以直接使用较低阶的 API。

#### 页面树 [step] [#page-tree]

您可以将页面树直接写死在程式码中，也可以撰写程式码来产生。
请参阅[页面树的定义](/docs/headless/page-tree)。

在您的文件版面配置中，将页面树传给 `DocsLayout`：

```tsx title="layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/docs';
import type { ReactNode } from 'react';

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <DocsLayout
      // [!code ++:5]
      tree={
        {
          // 您自己的页面树
        }
      }
    >
      {children}
    </DocsLayout>
  );
}
```

页面树就像是更聪明的「侧边栏项目」，UI 中各处的导览元素 (例如页尾) 都会参照它。

#### 页面内容 [step] [#page-content]

文件页面的逻辑也相同：

* 定义路径参数 (`slugs`) 。
* 依据路径参数取得页面内容。
* 算绘内容 (在 `DocsPage` 元件内) 。

您可能还需要目录，可以自行产生，或使用 [`getTableOfContents`](/docs/headless/utils/get-toc) 工具函式 (仅限 Markdown/MDX) 。

在您所用框架的文件路由中算绘内容：

```tsx title="components/docs-page.tsx"
import { DocsPage, DocsBody } from 'fumadocs-ui/layouts/docs/page';
import { getPage } from './my-content-source';

export function Page({ slugs }: { slugs: string[] }) {
  const page = getPage(slugs);
  // 使用框架提供的 API 回应 404
  if (!page) return null;

  return (
    <DocsPage toc={page.tableOfContents}>
      <DocsBody>{page.render()}</DocsBody>
    </DocsPage>
  );
}
```
预先算绘页面 (尤其是经常造访的页面) ，以缩短初始载入时间。

从远端来源预先算绘页面时，请务必最佳化建置阶段的重复读取。
例如，若您透过 GitHub API 撷取内容，建议先将储存库内容复制 (clone) 到本机，再进行预先算绘。

```text tab="Before"
/docs/* -> GET github.com
/docs/introduction -> GET github.com
/docs/my-page -> GET github.com
Error: API Ratelimit
```

```text tab="After"
开始 -> git clone
/docs/* -> ls
/docs/introduction -> 读取档案
/docs/my-page -> 读取档案
```
由于您的内容不一定是 Markdown/MDX，这部分可能较为棘手。
若是 Markdown 与 MDX，内建的 [Search API](/docs/headless/search/orama) 搭配搜寻索引即可满足大多数使用情境。
若非如此，您就需要自行实作。

我们推荐使用 Orama 或 Algolia Search 等第三方解决方案，它们比内建的 Search API 更具弹性，也更容易与远端来源整合。
Fumadocs 提供了多种[搜寻整合](/docs/headless/search)。
