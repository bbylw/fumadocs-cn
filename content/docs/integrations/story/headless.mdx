title: 无头式
description: 替换 stories 的 UI，或基于无头式层自行建构 UI。
---

`@fumadocs/story` 汇出了 ``、`useStory()` 与 `useStoryArgs()`，可在不含 UI 的情况下提供元件情境的状态：

* 所选的变体，以及其对应的预设组合
* 已渲染元件的引数，并经过防抖 (debounce) 处理，因此输入时不会每按一个键就重新算绘元件

内建面板就是以这些 API 建构而成，您也可以改用自己实作的面板。

## 自订面板 [#your-own-panel]

`defineStoryFactory()` 可接受一个 `WithControl` 元件，并以它取代内建面板进行算绘。


  ```tsx title="lib/story.tsx"
  import { defineStoryFactory } from '@fumadocs/story/next/client';
  import { StoryPanel } from '@/components/story-panel';

  export const { defineStory } = defineStoryFactory({ WithControl: StoryPanel });
  ```



  ```tsx title="lib/story.tsx"
  import { defineStoryFactory } from '@fumadocs/story/vite/client';
  import { StoryPanel } from '@/components/story-panel';

  export const { defineStory } = defineStoryFactory({ WithControl: StoryPanel });
  ```


此元件会接收元件情境的预设组合，以及要算绘的元件。

```tsx title="components/story-panel.tsx"
'use client';
import { StoryProvider, useStory, useStoryArgs, type WithControlProps } from '@fumadocs/story';

export function StoryPanel(props: WithControlProps) {
  return (
    <StoryProvider {...props}>
      <Content />
    </StoryProvider>
  );
}

function Content() {
  const { presets, variant, setVariant, preset, Component } = useStory();
  const args = useStoryArgs();

  return (
    <div>
      <select value={variant} onChange={(e) => setVariant(e.target.value)}>
        {presets.map((item) => (
          <option key={item.variant} value={item.variant}>
            {item.variant}
          </option>
        ))}
      </select>
      <Component {...args} />
      <pre>{JSON.stringify(preset?.controls, null, 2)}</pre>
    </div>
  );
}
```

| Hook              | 说明                                                                           |
| ----------------- | ---------------------------------------------------------------------------- |
| `useStory()`      | 预设组合、目前选取的 `variant` 与 `setVariant`，以及 `Component` 和 `frame`。                |
| `useStoryArgs()`  | 已渲染元件的引数，会随控制项同步更新。                                                          |
| `useStoryFrame()` | [`frame`](/docs/integrations/story#frame) 的 iframe 所用的 ref，负责将引数传送给该 iframe。 |

控制项透过 [`@fumari/stf`](https://github.com/fuma-nama/fumadocs/tree/dev/packages/stf) 编辑，也就是 `` 所设定的表单引擎。`preset.controls` 是元件 props 的[型别树](/docs/integrations/story#controls)。

<Callout title="从内建面板开始">
  要撰写完整的控制面板，就必须处理型别树中的每一种节点。建议您安装下方的内建
  面板，再加以修改。
</Callout>

## 安装 UI [#install-the-ui]

整个面板，包括其中的引数控制项：

```npm
npx @fumadocs/cli add story/controls
```


  ```tsx title="lib/story.tsx"
  import { defineStoryFactory } from '@fumadocs/story/next/client';
  import { WithControl } from '@/components/story';

  export const { defineStory } = defineStoryFactory({ WithControl });
  ```



  ```tsx title="lib/story.tsx"
  import { defineStoryFactory } from '@fumadocs/story/vite/client';
  import { WithControl } from '@/components/story';

  export const { defineStory } = defineStoryFactory({ WithControl });
  ```
