---
title: 意见回馈
description: 收集使用者的意见回馈
---

透过意见回馈，您可以了解读者对文件的看法，以及哪些页面需要改进。
Fumadocs 提供多种元件，可针对页面及内容区块收集意见回馈。

## 安装 [#installation]

请使用 **Fumadocs CLI** 安装。若侦测到您的文件页面，CLI 也会自动将此元件加入该页面：

```npm
npx @fumadocs/cli feature feedback
```

或者，您也可以只安装此元件：

```npm
npx @fumadocs/cli@latest add feedback
```
在文件页面底部加入 ``。读者送出意见回馈时，会执行 `onSendAction` 回呼函式。


  请在 server action 中处理意见回馈。例如，以 `on_rate_docs` 事件回报至 PostHog：

  ```tsx
  import { DocsPage } from 'fumadocs-ui/layouts/docs/page';
  import { Feedback } from '@/components/feedback/client';

  export default async function Page() {
    return (
      <DocsPage>
        {/* 放在页面底部 */}
        <Feedback
          onSendAction={async (feedback) => {
            'use server';

            console.log(feedback);
            return {};
          }}
        />
      </DocsPage>
    );
  }
  ```



  请在 server function 中处理意见回馈。例如，以 `on_rate_docs` 事件回报至 PostHog：

  ```tsx
  import { createServerFn } from '@tanstack/react-start';
  import { DocsPage } from 'fumadocs-ui/layouts/docs/page';
  import { Feedback } from '@/components/feedback/client';
  import { type PageFeedback, pageFeedback } from '@/components/feedback/schema';

  const sendFeedback = createServerFn({ method: 'POST' })
    .validator((feedback: PageFeedback) => pageFeedback.parse(feedback))
    .handler(async ({ data: feedback }) => {
      console.log(feedback);
      return {};
    });

  function Content() {
    return (
      <DocsPage>
        {/* 放在页面底部 */}
        <Feedback onSendAction={(feedback) => sendFeedback({ data: feedback })} />
      </DocsPage>
    );
  }
  ```



  将意见回馈传送至您应用程式中的端点：

  ```tsx
  import { DocsPage } from 'fumadocs-ui/layouts/docs/page';
  import { Feedback } from '@/components/feedback/client';

  function Content() {
    return (
      <DocsPage>
        {/* 放在页面底部 */}
        <Feedback
          onSendAction={async (feedback) => {
            const res = await fetch('/api/feedback', {
              method: 'POST',
              body: JSON.stringify(feedback),
            });

            return res.json();
          }}
        />
      </DocsPage>
    );
  }
  ```



  请在 [resource route](https://reactrouter.com/how-to/resource-routes) 中处理意见回馈。例如，以 `on_rate_docs` 事件回报至 PostHog：

  ```ts tab="app/routes/api.feedback.ts"
  import type { Route } from './+types/api.feedback';
  import { pageFeedback } from '@/components/feedback/schema';

  export async function action({ request }: Route.ActionArgs) {
    const feedback = pageFeedback.parse(await request.json());

    console.log(feedback);
    return Response.json({});
  }
  ```

  ```ts tab="app/routes.ts"
  import { route, type RouteConfig } from '@react-router/dev/routes';

  export default [
    // [!code ++]
    route('api/feedback', 'routes/api.feedback.ts'),
  ] satisfies RouteConfig;
  ```



  请在端点中处理意见回馈。例如，以 `on_rate_docs` 事件回报至 PostHog。此端点会在收到请求时才算绘，因此您的专案需要设定[转接器](https://docs.astro.build/en/guides/on-demand-rendering/)。

  ```ts title="src/pages/api/feedback.ts"
  import type { APIRoute } from 'astro';
  import { pageFeedback } from '@/components/feedback/schema';

  export const prerender = false;

  export const POST: APIRoute = async ({ request }) => {
    const feedback = pageFeedback.parse(await request.json());

    console.log(feedback);
    return Response.json({});
  };
  ```


### 区块意见回馈 [#feedback-block]

区块意见回馈可让读者针对特定内容区块提供意见：读者选取文字时，会开启一个弹出视窗。

加入 `remarkBlockId`，这是一个为每个区块指定 ID 的 remark 外挂：


  ```ts tab="unified" title="source.config.ts"
  import {
    remarkBlockId,
    type RemarkBlockIdOptions,
  } from 'fumadocs-core/mdx-plugins/remark-block-id';
  import { defineConfig } from 'fumadocs-mdx/config';

  const blockIdOptions: RemarkBlockIdOptions = {
    addDataAttribute: 'feedback',
  };

  export default defineConfig({
    mdxOptions: {
      remarkPlugins: [
        // [!code ++]
        [remarkBlockId, blockIdOptions],
      ],
    },
  });
  ```

  ```ts tab="Sätteri" title="source.config.ts"
  import { remarkBlockId } from '@fumadocs/satteri/remark-block-id';
  import { defineConfig, defineDocs } from 'fumadocs-mdx/config';

  export const docs = defineDocs({
    docs: {
      compiler: 'satteri',
    },
  });

  export default defineConfig({
    satteriOptions: {
      mdastPlugins: [
        // [!code ++]
        remarkBlockId({ addDataAttribute: 'feedback' }),
      ],
    },
  });
  ```



  ```js title="astro.config.mjs"
  import { defineConfig } from 'astro/config';
  import fumadocs from '@fumadocs/astro';
  import { remarkBlockId } from '@fumadocs/satteri/remark-block-id';

  export default defineConfig({
    integrations: [
      fumadocs({
        // [!code ++]
        mdastPlugins: [remarkBlockId({ addDataAttribute: 'feedback' })],
      }),
    ],
  });
  ```


接著用 `` 包住您的页面内容。读者针对某个区块送出意见回馈时，便会执行 `onSendAction` 回呼函式。





  ```tsx
  import { DocsPage } from 'fumadocs-ui/layouts/docs/page';
  import { FeedbackText } from '@/components/feedback/client';

  function Content() {
    return (
      <DocsPage>
        <FeedbackText
          onSendAction={async (feedback) => {
            const res = await fetch('/api/feedback/block', {
              method: 'POST',
              body: JSON.stringify(feedback),

          }}
        >
          {/* 页面内容 */}
  ```

<Callout type="info" title="小提示">
  `remark-block-id` 会根据区块的内容及其在页面中的顺序产生区块 ID，因此第三方服务也能追踪这些区块。
</Callout>

### 与 GitHub Discussion 整合 [#integrating-with-github-discussion]

若要将意见回馈回报至 GitHub Discussion，您可以复制此档案作为起点：




```ts title="lib/github.ts"
import { App, Octokit } from 'octokit';
import {
  blockFeedback,
  BlockFeedback,
  pageFeedback,
  type ActionResponse,
  type PageFeedback,
} from '@/components/feedback/schema';

export const repo = 'fumadocs';
export const owner = 'fuma-nama';
export const DocsCategory = 'Docs Feedback';

let instance: Octokit | undefined;

async function getOctokit(): Promise<Octokit> {
  if (instance) return instance;
  const appId = process.env.GITHUB_APP_ID;
  const privateKey = process.env.GITHUB_APP_PRIVATE_KEY;

  if (!appId || !privateKey) {
    throw new Error('No GitHub keys provided for Github app, docs feedback feature will not work.');
  }

  const app = new App({
    appId,
    privateKey,
  });

  const { data } = await app.octokit.request('GET /repos/{owner}/{repo}/installation', {
    owner,
    repo,
    headers: {
      'X-GitHub-Api-Version': '2022-11-28',
    },
  });

  instance = await app.getInstallationOctokit(data.id);
  return instance;
}

interface RepositoryInfo {
  id: string;
  discussionCategories: {
    nodes: {
      id: string;
      name: string;
    }[];
  };
}

let cachedDestination: RepositoryInfo | undefined;
async function getFeedbackDestination() {
  if (cachedDestination) return cachedDestination;
  const octokit = await getOctokit();

  const {
    repository,
  }: {
    repository: RepositoryInfo;
  } = await octokit.graphql(`
  query {
    repository(owner: "${owner}", name: "${repo}") {
      id
      discussionCategories(first: 25) {
        nodes { id name }
      }
    }
  }
`);

  return (cachedDestination = repository);
}

export async function onPageFeedbackAction(feedback: PageFeedback): Promise<ActionResponse> {
  'use server';
  feedback = pageFeedback.parse(feedback);
  const url = new URL(feedback.url);

  return createDiscussionThread(
    url.pathname,
    `[${feedback.opinion}] ${feedback.message}\n\n> Forwarded from user feedback.`,
  );
}

export async function onBlockFeedbackAction(feedback: BlockFeedback): Promise<ActionResponse> {
  'use server';
  feedback = blockFeedback.parse(feedback);
  const url = new URL(feedback.url);
  url.hash = feedback.blockId;

  return createDiscussionThread(
    url.pathname,
    `> ${feedback.blockBody}\n\n${feedback.message}\n\n> [Forwarded from user feedback](${url.href}).`,
  );
}

async function createDiscussionThread(pageId: string, body: string) {
  const octokit = await getOctokit();
  const destination = await getFeedbackDestination();
  const category = destination.discussionCategories.nodes.find(
    (category) => category.name === DocsCategory,
  );

  if (!category) throw new Error(`Please create a "${DocsCategory}" category in GitHub Discussion`);

  const title = `Feedback for ${pageId}`;
  const queryResult: {
    search: {
      nodes: { id: string; title: string; url: string }[];
    };
  } = await octokit.graphql(`
          query {
            search(type: DISCUSSION, query: ${JSON.stringify(`"${title}" in:title repo:${owner}/${repo} author:@me`)}, first: 10) {
              nodes {
                ... on Discussion { id, title, url }
              }
            }
          }`);

  const discussion = queryResult.search.nodes.find((item) => item.title === title);

  if (discussion) {
    const result: {
      addDiscussionComment: {
        comment: { id: string; url: string };
      };
    } = await octokit.graphql(`
            mutation {
              addDiscussionComment(input: { body: ${JSON.stringify(body)}, discussionId: "${discussion.id}" }) {
                comment { id, url }
              }
            }`);

    return {
      githubUrl: result.addDiscussionComment.comment.url,
    };
  } else {
    const result: {
      createDiscussion: {
        discussion: { id: string; url: string };
      };
    } = await octokit.graphql(`
            mutation {
              createDiscussion(input: { repositoryId: "${destination.id}", categoryId: "${category.id}", body: ${JSON.stringify(body)}, title: ${JSON.stringify(title)} }) {
                discussion { id, url }
              }
            }`);

    return {
      githubUrl: result.createDiscussion.discussion.url,
    };
  }
}
```
