Fumadocs OpenAPI 的主要设定。

> 请勿在浏览器环境中引用此设定。

### `input` [#input]

要读取的 OpenAPI schema。

* 档案路径
* 外部 URL
* 函式 (见下文) 

只有列在此处的 schema 才能载入；若传入 `getSchema()` 或由页面预先载入的是其他 ID，则会抛出错误。

<Callout type="warn">
  请勿将不受信任的 schema 传入 `input`，因为其中的 `$ref` 可以读取本机档案并撷取 URL，私有主机也包含在内。
</Callout>

```ts tab="Basic"
import { createOpenAPI } from 'fumadocs-openapi/server';

export const openapi = createOpenAPI({
  input: ['./unkey.json'],
});
```

```ts tab="Functions"
import { createOpenAPI } from 'fumadocs-openapi/server';

export const openapi = createOpenAPI({
  input: {
    // [id]：已下载的 OpenAPI schema
    my_schema: async () => {
      const res = await fetch('https://registry.scalar.com/@scalar/apis/galaxy/latest?format=json');
      return res.json();
    },
  },
});
```
页面会透过 props 接收完整的文件，因此每次载入页面、切换页面与预先撷取时，都会重新传送整份文件。若文件较大，建议将其排除：

```ts title="lib/openapi.ts"
import { createOpenAPI } from 'fumadocs-openapi/server';

export const openapi = createOpenAPI({
  // ID 最后会出现在 URL 中，请确保可安全用于 URL
  input: { museum: './museum.yaml' },
  includeDocument: false, // [!code ++]
});
```

  ```tsx title="components/api-page.tsx"
  'use client';
  import { preload } from 'react-dom';
  import { createOpenAPIPage } from 'fumadocs-openapi/ui';

  export const OpenAPIPage = createOpenAPIPage({
    async loadDocument(id) {
      if (typeof window === 'undefined') {
        // 浏览器会在载入页面的同时开始下载它
        preload(`/api/openapi/${id}`, { as: 'fetch', crossOrigin: 'anonymous' });
        const { openapi } = await import('@/lib/openapi');
        return (await openapi.getSchema(id)).bundled;
      }
      return (await fetch(`/api/openapi/${id}`)).json();
    },
  });
  ```

  TanStack Start 的路由载入器会同时在伺服器与浏览器上执行，因此您的文件路由不需要 `loadDocument` 就能载入文件。只有在浏览器尚未取得文件时，才需要呼叫 server function：

  ```tsx title="src/routes/docs/$.tsx"
  import { createServerFn } from '@tanstack/react-start';
  import type { Document } from 'fumadocs-openapi';
  import { openapi } from '@/lib/openapi';

  // 浏览器已载入的文件
  const documents = new Map<string, Document>();

  const getDocument = createServerFn({ method: 'GET' })
    .validator((id: string) => id)
    .handler(async ({ data: id }) => (await openapi.getSchema(id)).bundled);

  export const Route = createFileRoute('/docs/$')({
    component: Page,
    loader: async ({ params }) => {
      const data = await serverLoader({ data: params._splat?.split('/') ?? [] });
      if (data.type === 'openapi') {
        const { document: id, payload } = data.props;
        payload.bundled = documents.get(id) ?? (await getDocument({ data: id }));
      }
      return data;
    },
  });

  function Page() {
    const page = useFumadocsLoader(Route.useLoaderData());
    // 第一个页面的文件也一并记录
    if (page.type === 'openapi' && typeof window !== 'undefined')
      documents.set(page.props.document, page.props.payload.bundled!);
    // ...
  }
  ```


## 建立代理伺服器 [#creating-proxy]

代理伺服器传送 HTTP 请求时不受浏览器的 CORS 限制。API 互动测试区会在以下情况使用它：

* 请求未透过 CORS 允许您的来源的 API 端点。
* 机密用户端 (具有 client secret) 的 OAuth 请求，以及装置授权流程。

<Callout type="warn">
  代理伺服器是公开的，无须验证即可存取。它会转送请求的标头与 body，包括 `Authorization`。请使用 [`allowedOrigins`](#allowed-origins) 与 `filterRequest` 限制其存取。
</Callout>

### 设定 [#setup]

为代理伺服器建立路由处理常式：


  ```ts title="app/api/proxy/route.ts"
  import { openapi } from '@/lib/openapi';

  export const { GET, HEAD, PUT, POST, PATCH, DELETE } = openapi.createProxy();
  ```



  ```ts tab="app/routes/proxy.ts"
  import type { Route } from './+types/proxy';
  import { openapi } from '@/lib/openapi';

  const proxy = openapi.createProxy();

  export const loader = ({ request }: Route.LoaderArgs) => proxy.handle(request);
  export const action = ({ request }: Route.ActionArgs) => proxy.handle(request);
  ```

  ```ts tab="app/routes.ts"
  import { route, type RouteConfig } from '@react-router/dev/routes';

  export default [
    // [!code ++]
    route('api/proxy', 'routes/proxy.ts'),
    // ...
  ] satisfies RouteConfig;
  ```



  ```ts title="src/routes/api/proxy.ts"
  import { openapi } from '@/lib/openapi';
  import { createFileRoute } from '@tanstack/react-router';

  const proxy = openapi.createProxy();

  export const Route = createFileRoute('/api/proxy')({
    server: {
      handlers: {
        // 预设处理所有方法，也可以个别指定方法（GET、POST 等）
        ANY: async ({ request }) => {
          return proxy.handle(request);
        },
      },
    },
  });
  ```



  ```ts title="src/pages/_api/api/proxy.ts"
  import { openapi } from '@/lib/openapi';

  export const { GET, HEAD, PUT, POST, PATCH, DELETE } = openapi.createProxy();
  ```



  ```ts title="src/pages/api/proxy.ts"
  import type { APIRoute } from 'astro';
  import { openapi } from '@/lib/openapi';

  export const prerender = false;

  const proxy = openapi.createProxy();

  // 处理所有方法
  export const ALL: APIRoute = ({ request }) => proxy.handle(request);
  ```

  此路由为随需执行，因此您的专案需要安装[转接器](https://docs.astro.build/en/guides/on-demand-rendering/)。


接著在 `createOpenAPI()` 中设定其 URL：

```ts title="lib/openapi.ts"
import { createOpenAPI } from 'fumadocs-openapi/server';

export const openapi = createOpenAPI({
  proxyUrl: '/api/proxy', // [!code ++]
});
```
代理伺服器预设会接受任何公开来源，并拒绝私有网路上的主机 (例如 `localhost`) ，也不会转送您网站的 Cookie。
若要限制存取范围，或要代理私有 API，请在代理伺服器路由中列出允许的来源：

```ts
openapi.createProxy({
  // 字串或正规表示式
  allowedOrigins: ['https://api.example.com', 'http://localhost:8080'],
});
```

重新导向也会依照相同的规则进行检查。

<Callout type="warn">
  封锁私有网路的功能需要 Node.js 或 Deno。若使用其他执行阶段 (例如 Bun) ，请指定
  `allowedOrigins`。
</Callout>

您可以使用 `filterRequest` 拒绝请求，例如只允许读取操作：

```ts
openapi.createProxy({
  // 回传 false 的代理请求会被拒绝
  filterRequest: (request) => request.method === 'GET',
});
```
OAuth 提供者只接受已注册的重新导向 URI，但 API 互动测试区预设会重新导向至目前页面。
请建立一个路由处理常式，作为所有页面共用的重新导向 URI。它会将使用者导回发起流程的页面。


  ```ts title="app/api/oauth/route.ts"
  import { openapi } from '@/lib/openapi';

  export const GET = openapi.createOAuthHandler();
  ```



  ```ts tab="app/routes/oauth.ts"
  import type { Route } from './+types/oauth';
  import { openapi } from '@/lib/openapi';

  const handler = openapi.createOAuthHandler();

  export const loader = ({ request }: Route.LoaderArgs) => handler(request);
  ```

  ```ts tab="app/routes.ts"
  import { route, type RouteConfig } from '@react-router/dev/routes';

  export default [
    // [!code ++]
    route('api/oauth', 'routes/oauth.ts'),
    // ...
  ] satisfies RouteConfig;
  ```



  ```ts title="src/routes/api/oauth.ts"
  import { openapi } from '@/lib/openapi';
  import { createFileRoute } from '@tanstack/react-router';

  const handler = openapi.createOAuthHandler();

  export const Route = createFileRoute('/api/oauth')({
    server: {
      handlers: {
        GET: async ({ request }) => handler(request),
      },
    },
  });
  ```



  ```ts title="src/pages/_api/api/oauth.ts"
  import { openapi } from '@/lib/openapi';

  export const GET = openapi.createOAuthHandler();
  ```



  ```ts title="src/pages/api/oauth.ts"
  import type { APIRoute } from 'astro';
  import { openapi } from '@/lib/openapi';

  export const prerender = false;

  const handler = openapi.createOAuthHandler();

  export const GET: APIRoute = ({ request }) => handler(request);
  ```

  此路由采随需执行，因此您的专案需要设定[转接器](https://docs.astro.build/en/guides/on-demand-rendering/)。


请将此路由的 URL 传入 `createOpenAPIPage()`，并在 OAuth 提供者中注册完整 URL (例如 `https://docs.example.com/api/oauth`) ：

```tsx title="components/api-page.tsx"
export const OpenAPIPage = createOpenAPIPage({
  oauthRedirectUrl: '/api/oauth', // [!code ++]
});
```

<Callout title="内容安全政策（Content Security Policy）">
  处理常式会透过其自身路由提供的指令码将使用者导回。若该路由受 Content Security Policy 规范，该政策必须允许 `'self'` 指令码。使用 `'strict-dynamic'` 的政策会忽略 `'self'`，因此请改为将该路由排除在这类政策之外。
</Callout>

### 静态网站 [#static-sites]

在静态网站中，路由会预先算绘为档案。请传入 `inline: true` 将指令码内嵌于页面中，并让路径以 `.html` 结尾，让静态主机将该档案视为 HTML 提供。


  ```ts title="app/api/oauth.html/route.ts"
  import { openapi } from '@/lib/openapi';

  export const dynamic = 'force-static';

  export const GET = openapi.createOAuthHandler({ inline: true });
  ```



  ```ts tab="app/routes/oauth.ts"
  import type { Route } from './+types/oauth';
  import { openapi } from '@/lib/openapi';

  const handler = openapi.createOAuthHandler({ inline: true });

  export const loader = ({ request }: Route.LoaderArgs) => handler(request);
  ```

  ```ts tab="app/routes.ts"
  import { route, type RouteConfig } from '@react-router/dev/routes';

  export default [
    // [!code ++]
    route('api/oauth.html', 'routes/oauth.ts'),
    // ...

  ```

请使用 `.html` URL 作为重新导向 URI，例如 `oauthRedirectUrl: '/api/oauth.html'`。由于指令码内嵌于页面中，套用于此路由的内容安全政策 (Content Security Policy) 必须允许内嵌指令码。
