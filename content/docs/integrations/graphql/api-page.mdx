title: createGraphQLPage()
description: 用于算绘 GraphQL 文件内容的元件
---

Fumadocs GraphQL 使用 `` 元件来算绘页面内容，此元件应为用户端元件。

```tsx title="components/api-page.tsx"
'use client';
import { createGraphQLPage } from '@fumadocs/graphql/ui';

export const GraphQLPage = createGraphQLPage({
  // 设定
});
```
设定端点后，operation 页面会提供互动测试区：读者可以编辑 operation、透过表单或 JSON 填入变数，再附上自己的标头送出。

```tsx title="components/api-page.tsx"
'use client';
import { createGraphQLPage } from '@fumadocs/graphql/ui';

export const GraphQLPage = createGraphQLPage({
  playground: {
    url: 'https://api.example.com/graphql',
    // 允许使用者编辑端点 URL（预设：true）
    allowUrlEdit: false,
    // 互动测试区请求的预设标头
    headers: {
      'X-Client-Name': 'docs',
    },
  },
});
```

<Callout type="warn">
  请勿将密钥等机密资讯放入 `headers`，因为这些内容会传送至浏览器、显示在程式码范例中，并依端点来源保存在浏览器的本机储存空间 (local storage) 中。
</Callout>

查询 (query) 与变更 (mutation) 会透过 HTTP POST 传送，您可以替换其 fetcher，例如透过代理伺服器转送请求：

```tsx title="components/api-page.tsx"
'use client';
import { createGraphQLPage } from '@fumadocs/graphql/ui';

export const GraphQLPage = createGraphQLPage({
  playground: {
    async fetcher(request) {
      const start = performance.now();
      const res = await fetch('/api/proxy', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json', ...request.headers },
        body: JSON.stringify({ query: request.query, variables: request.variables }),
      });

      return {
        type: 'response',
        status: res.status,
        time: performance.now() - start,
        body: await res.text(),
        contentType: res.headers.get('Content-Type') ?? '',
        // 选填，会显示在 Headers 页签中
        headers: Array.from(res.headers),
      };
    },
  },
});
```

或者，您也可以使用 `render` 完全替换互动测试区的 UI，它会显示在原本签章列的位置：

```tsx title="components/api-page.tsx"
'use client';
import { createGraphQLPage } from '@fumadocs/graphql/ui';

export const GraphQLPage = createGraphQLPage({
  playground: {
    render({ kind, name, operation }) {
      return <div>my playground</div>;
    },
  },
});
```
在订阅页面上，互动测试区会订阅 `subscriptionUrl`，并记录收到的事件。预设值为将 `url` 的 scheme 改为 `ws(s)://` 后的网址。

| `subscriptionUrl`     | 协定                                          |
| --------------------- | ------------------------------------------- |
| `ws://`, `wss://`     | graphql-ws (`graphql-transport-ws`)         |
| `http://`, `https://` | GraphQL over SSE (distinct connections 模式)  |

```tsx title="components/api-page.tsx"
'use client';
import { createGraphQLPage } from '@fumadocs/graphql/ui';

export const GraphQLPage = createGraphQLPage({
  playground: {
    url: 'https://api.example.com/graphql',
    // 在同一个端点上透过 SSE 使用 GraphQL（GraphQL over SSE）
    subscriptionUrl: 'https://api.example.com/graphql',
  },
});
```

<Callout title="浏览器限制">
  浏览器无法设定 WebSocket 连线的标头，因此 graphql-ws 改将标头放在
  `connection_init` 的酬载中传送。
</Callout>

### 程式码范例 [#code-samples]

范例请求会以 GraphQL 呈现，或以 cURL、JavaScript、Go、Python、Java、C# 和 Rust 程式码呈现，这些程式码会带上 `playground.headers`，将请求传送至 `playground.url` (未设定时会使用预留位置) 。互动测试区也会针对正在编辑的请求显示相同的程式码。订阅页面的范例仅以 GraphQL 呈现。

您可以透过 `codeUsages` 新增产生器，或移除预设的产生器：

```tsx title="components/api-page.tsx"
'use client';
import {
  createCodeUsageGeneratorRegistry,
  createGraphQLPage,
  registerDefaultCodeUsages,
} from '@fumadocs/graphql/ui';

// 若要从零开始，请省略预设项目
const codeUsages = registerDefaultCodeUsages(createCodeUsageGeneratorRegistry());

// 预设项目：curl、js、go、python、java、csharp、rust
codeUsages.remove('java');
codeUsages.add('graphql-request', {
  label: 'graphql-request',
  lang: 'js',
  generate({ url, query, variables = {}, headers }) {
    return `import { request } from 'graphql-request';

const data = await request(${JSON.stringify(url)}, ${JSON.stringify(query)}, ${JSON.stringify(variables)}, ${JSON.stringify(headers)});`;
  },
});

export const GraphQLPage = createGraphQLPage({ codeUsages });
```

### 交互连结 [#cross-linking]

[型别页面](/docs/integrations/graphql/server#includeoperations--includetypes)会自动互相连结，也会连结至 operation。Operation 页面则会让读者留在原页面，其中的型别会在结构描述 UI 中开启。

您也可以自行解析这些连结：

```tsx title="components/api-page.tsx"
'use client';
import { createGraphQLPage } from '@fumadocs/graphql/ui';

export const GraphQLPage = createGraphQLPage({
  typeLinks(name) {
    return `/docs/types/${name}`;
  },
  operationLinks(kind, name) {
    return `/docs/${kind}/${name}`;
  },
});
```

若型别或 operation 没有独立页面，请回传 `undefined`。

### 自订版面配置 [#custom-layout]

您可以自订 operation 页面与型别页面的版面配置。

<Tabs items={['Operation', 'Type']}>
  <Tab>
    ```tsx title="components/api-page.tsx"
    'use client';
    import { createGraphQLPage } from '@fumadocs/graphql/ui';

    export const GraphQLPage = createGraphQLPage({
      content: {
        renderOperationLayout(slots) {
          return (
            <div className="flex flex-col gap-6">
              {slots.header}
              {slots.playground}
              {slots.description}
              {slots.deprecated}
              {slots.arguments}
              {slots.returns}
              {slots.example}
            </div>
          );
        },
      },
    });
    ```

    | Slot          | 算绘内容                                                     |
    | ------------- | -------------------------------------------------------- |
    | `header`      | 标题，仅在包含多个项目的页面上显示                                        |
    | `playground`  | 签章 (例如 `QUERY customer(id: ID!): Customer`) 、其指示词以及互动测试区 |
    | `description` | operation 的说明                                            |
    | `deprecated`  | 弃用原因                                                     |
    | `arguments`   | 引数                                                       |
    | `returns`     | 回传型别及其栏位                                                 |
    | `example`     | 范例请求与回应，在宽版页面上会显示于 operation 旁                           |
  </Tab>

  <Tab>
    ```tsx title="components/api-page.tsx"
    'use client';
    import { createGraphQLPage } from '@fumadocs/graphql/ui';

    export const GraphQLPage = createGraphQLPage({
      content: {
        renderTypeLayout(slots) {
          return (
            <div className="flex flex-col gap-6">
              {slots.header}
              {slots.definition}
              {slots.description}
              {slots.fields}
              {slots.values}
              {slots.usages}
              {slots.sdl}
            </div>
          );
        },
      },
    });
    ```

    | Slot          | 算绘内容                                            |
    | ------------- | ----------------------------------------------- |
    | `header`      | 名称，仅在包含多个项目的页面上显示                               |
    | `definition`  | SDL 的开头 (例如 `type Order implements Node`) 及其指示词 |
    | `description` | 型别的说明                                           |
    | `fields`      | 物件、介面与输入物件的栏位，或联集的成员                            |
    | `values`      | 列举的值                                            |
    | `usages`      | 实作、所属联集，以及使用此型别的 operation 与栏位                  |
    | `sdl`         | 型别的 SDL，在宽版页面上会显示于型别旁                           |
  </Tab>
</Tabs>

### 结构描述 UI [#schema-ui]

自订型别的算绘方式。

```tsx title="components/api-page.tsx"
'use client';
import { createGraphQLPage } from '@fumadocs/graphql/ui';

export const GraphQLPage = createGraphQLPage({
  schemaUI: {
    render(options, ctx) {
      // 完全自订的 schema 算绘器
      return <ctx.SchemaUI {...options} />;
    },
  },
});
```
假设您已在 UI 层级设定好[国际化](/docs/internationalization)：

```tsx title="layout.shared.tsx"
import { defineI18n } from 'fumadocs-core/i18n';
import { uiTranslations } from 'fumadocs-ui/i18n';
import { graphqlTranslations } from '@fumadocs/graphql/i18n';

const i18n = defineI18n({
  languages: ['en', 'cn'],
  defaultLanguage: 'en',
});

export const translations = i18n
  .translations()
  .extend(uiTranslations())
  // [!code ++]
  .extend(graphqlTranslations())
  .add({
    cn: {
      displayName: 'Chinese',
      // [!code ++]
      'Arguments(operation page)': '参数',
    },
  });
```

详细资讯请参阅[翻译](/docs/ui/translations)。

### 语法突显 [#syntax-highlighting]

GraphQL 页面会使用 Shiki 为程式码区块进行语法突显，若要自订，可以传入[语法突显器](/docs/headless/utils/shiki)。

```tsx title="components/api-page.tsx"
'use client';
import { createGraphQLPage } from '@fumadocs/graphql/ui';
import { highlighter } from '@/lib/highlighter';

export const GraphQLPage = createGraphQLPage({ highlighter });
```
覆写预设的标题、程式码区块及 Markdown 元件。

```tsx title="components/api-page.tsx"
'use client';
import { createGraphQLPage } from '@fumadocs/graphql/ui';

export const GraphQLPage = createGraphQLPage({
  components: {
    Heading({ id, depth, ...props }) {
      const Tag = `h${depth}` as const;
      return <Tag id={id} {...props} />;
    },
    CodeBlock({ lang, code }) {
      return <pre data-lang={lang}>{code}</pre>;
    },
  },
});
```
若现有选项无法满足您的自订需求，您可以透过 [Fumadocs CLI](/docs/cli) 将 UI 安装到您的程式码库中。

### 完整 UI [#full-ui]

GraphQL 页面的完整 UI，以[无头式层](/docs/integrations/graphql/headless)为基础建构而成。

```npm
npx @fumadocs/cli add graphql/page
```

它会自行安装 ``，因此不再需要 `components/api-page.tsx`。请更新 `` 的汇入路径：

```tsx
import { GraphQLPage } from '@/components/api-page'; // [!code --]
import { GraphQLPage } from '@/components/graphql/page'; // [!code ++]
```
只需安装您想编辑的部件，再透过 `components` 传回即可。`components` 中没有互动测试区的 slot：它会由已安装的 `graphql/operation` 算绘，您也可以从 [`playground.render`](#playground) 回传 ``。

| 元件                   | 内容                 |
| -------------------- | ------------------ |
| `graphql/operation`  | operation，包含其引数与范例 |
| `graphql/type-docs`  | 具名型别，包含其栏位与使用之处    |
| `graphql/schema-ui`  | 型别、引数与栏位的详细资讯      |
| `graphql/playground` | 互动测试区              |

```tsx title="components/api-page.tsx"
'use client';
import { createGraphQLPage } from '@fumadocs/graphql/ui';
import { Operation } from '@/components/graphql/operation';
import { TypeDocs } from '@/components/graphql/type-docs';

export const GraphQLPage = createGraphQLPage({
  components: {
    Operation,
    TypeDocs,
  },
});
```
