## 概览 [#overview]

Fumadocs UI 同时支持 [Base UI](https://base-ui.com) 与 [Radix UI](https://radix-ui.com/primitives)，默认使用 Base UI。

若你使用 Fumadocs CLI 自定义组件，设置方式可能会有所不同。

### Base UI [#base-ui]

Base UI 是默认的组件库。若你选择手动安装，请将 `fumadocs-ui` 设置为 `@fumadocs/base-ui` 包的别名：

```json title="package.json"
{
  "dependencies": {
    "fumadocs-ui": "npm:@fumadocs/base-ui@latest",
    // 请确认已安装 Base UI
    "@base-ui/react": "..."
  }
}
```

在 Fumadocs CLI 中，这是 `uiLibrary` 的默认值：

```json title="cli.json"
{
  "uiLibrary": "base-ui"
}
```

### Radix UI [#radix-ui]

若要改用 Radix UI，可以直接安装 `fumadocs-ui` 包：

```json title="package.json"
{
  "dependencies": {
    "fumadocs-ui": "latest"
  }
}
```

若使用 Fumadocs CLI，请在 `cli.json` 配置文件中进行设置：

```json title="cli.json"
{
  "uiLibrary": "radix-ui"
}
```
