---
title: 元件库
description: 底层所使用的无头式元件库。
---

Fumadocs UI 同时支援 [Base UI](https://base-ui.com) 与 [Radix UI](https://radix-ui.com/primitives)，预设使用 Base UI。

若您使用 Fumadocs CLI 自订元件，设定方式可能会有所不同。

### Base UI [#base-ui]

Base UI 是预设的元件库。若您选择手动安装，请将 `fumadocs-ui` 设定为 `@fumadocs/base-ui` 套件的别名：

```json title="package.json"
{
  "dependencies": {
    "fumadocs-ui": "npm:@fumadocs/base-ui@latest",
    // 请确认已安装 Base UI
    "@base-ui/react": "..."
  }
}
```

在 Fumadocs CLI 中，这是 `uiLibrary` 的预设值：

```json title="cli.json"
{
  "uiLibrary": "base-ui"
}
```
若要改用 Radix UI，可以直接安装 `fumadocs-ui` 套件：

```json title="package.json"
{
  "dependencies": {
    "fumadocs-ui": "latest"
  }
}
```

若使用 Fumadocs CLI，请在 `cli.json` 设定档中进行设定：

```json title="cli.json"
{
  "uiLibrary": "radix-ui"
}
```
