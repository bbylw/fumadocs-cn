Page 是文件页面的基本元素，其中包含目录、
页尾和 Breadcrumb。

## 使用方式 [#usage]

请根据您使用的版面配置汇入。

```tsx title="page.tsx" tab="Docs Layout"
import { DocsPage, DocsDescription, DocsTitle, DocsBody } from 'fumadocs-ui/layouts/docs/page';

<DocsPage>
  <DocsTitle>title</DocsTitle>
  <DocsDescription>description</DocsDescription>
  <DocsBody>
    <h2>This heading looks good!</h2>
    It applies the Typography styles, wrap your content here.
  </DocsBody>
</DocsPage>;
```

```tsx title="page.tsx" tab="Notebook Layout"
import { DocsPage, DocsDescription, DocsTitle, DocsBody } from 'fumadocs-ui/layouts/notebook/page';

<DocsPage>
  <DocsTitle>title</DocsTitle>
  <DocsDescription>description</DocsDescription>
  <DocsBody>
    <h2>This heading looks good!</h2>
    It applies the Typography styles, wrap your content here.
  </DocsBody>
</DocsPage>;
```

<Callout type="info" title="小提示">
  除了在 `page.tsx` 中使用 `DocsTitle` 算绘标题，您也可以直接将标题写在 MDX 档案中。
  如此一来，标题就会在 MDX 内文中算绘。
</Callout>

### 页面操作 [#page-actions]

显示 GitHub 连结，以及开启各 AI 工具的快捷连结。

```tsx
import { DocsPage, ViewOptionsPopover } from 'fumadocs-ui/layouts/<layout>/page';

const githubUrl = `https://github.com/fuma-nama/fumadocs/blob/main/content/docs/${encodeURI(page.path)}`

<DocsPage>
  <ViewOptionsPopover githubUrl={githubUrl} />
</DocsPage>;
```
显示页面的最后更新时间。

```tsx
import { DocsPage, PageLastUpdate } from 'fumadocs-ui/layouts/<layout>/page';

const lastModifiedTime: Date | undefined;

<DocsPage>
  {/* 其他内容 */}
  {lastModifiedTime && <PageLastUpdate date={lastModifiedTime} />}
</DocsPage>;
```

至于 `lastModifiedTime`，您可以视情况改用 GitHub 或 CMS 等不同的版本控制来源。

<Tabs items={['Fumadocs MDX', 'GitHub API']}>
  <Tab>
    您可以启用 [`lastModified`](/docs/mdx/last-modified)。

    ```tsx
    import { source } from '@/lib/source';
    const page = source.getPage(['...']);

    const lastModifiedTime = page.data.lastModified;
    ```
  </Tab>

  <Tab>
    若文件托管于 GitHub，您可以使用
    [`getGithubLastEdit`](/docs/headless/utils/git-last-edit) 工具函式。

    ```tsx
    import { getGithubLastEdit } from 'fumadocs-core/content/github';

    const lastModifiedTime = await getGithubLastEdit({
      owner: 'fuma-nama',
      repo: 'fumadocs',
      // Git 中的档案路径
      path: `content/docs/${page.path}`,
    });
    ```
  </Tab>
</Tabs>

## 设定 [#configurations]

### 全宽模式 [#full-mode]

若要让页面延展并填满所有可用空间，请将 `full` 传给页面元件。
这会强制以弹出视窗的形式显示目录。

```tsx
import { DocsPage } from 'fumadocs-ui/layouts/<layout>/page';

<DocsPage full>...</DocsPage>;
```
列出文章中所有标题的总览，需要传入一个标题阵列。

对于 Markdown 和 MDX 文件，您可以使用
[目录工具](/docs/headless/utils/get-toc)取得。Fumadocs MDX 等内容来源已内建此功能。

```tsx
import { DocsPage } from 'fumadocs-ui/layouts/<layout>/page';

<DocsPage toc={headings}>...</DocsPage>;
```

您可以透过 `tableOfContent` 自订目录；在较小的装置上，则可改用 `tableOfContentPopover`。

```tsx title="page.tsx"
import { DocsPage } from 'fumadocs-ui/layouts/<layout>/page';

return (
  <DocsPage tableOfContent={options} tableOfContentPopover={options}>
    ...
  </DocsPage>
);
```

#### 样式 [#style]

为目录选择其他样式：

  
轨道线搭配滑块，标示目前所在的标题 (预设) 。

    
      轨道线随标题层级转折，设计灵感来自 [Clerk](https://clerk.com)。
    

    不显示轨道线，改以区块在目前所在的标题后方滑动。


```tsx
import { DocsPage } from 'fumadocs-ui/layouts/<layout>/page';

<DocsPage
  tableOfContent={{
    style: 'clerk',
  }}
>
  ...
</DocsPage>;
```
若要替换此元件：

```tsx tab="page.tsx"
import { TOCProvider, TOC, TOCPopover } from './my-toc';

return (
  <DocsPage
    slots={{
      toc: {
        provider: TOCProvider,
        main: TOC,
        popover: TOCPopover,
      },
    }}
  >
    ...
  </DocsPage>
);
```

```tsx tab="my-toc.tsx"
'use client';
import type {
  TOCProps,
  TOCPopoverProps,
  TOCProviderProps,
} from 'fumadocs-ui/layouts/<layout>/page/slots/toc';

export function TOCProvider({ toc, children }: TOCProviderProps) {
  // 接收目录项目，可透过 React context 向下传递
  console.log(toc);
  return children;
}

export function TOC(props: TOCProps) {
  return <div>Hello World</div>;
}

export function TOCPopover(props: TOCPopoverProps) {
  return <div>Popover</div>;
}
```

您可以使用 Fumadocs CLI，以预设实作为基础开始修改：

```bash tab="Docs Layout"
npx @fumadocs/cli add slots/docs/page/toc
```

```bash tab="Notebook Layout"
npx @fumadocs/cli add slots/notebook/page/toc
```

```bash tab="Flux Layout"
npx @fumadocs/cli add slots/flux/page/toc
```
页尾是一种导览元素，提供两个按钮，可跳至上一页与下一页。若未指定，则会显示从页面树中找到的相邻页面。

您可以透过 `footer` prop 自订页尾：

```tsx
import { DocsPage } from 'fumadocs-ui/layouts/<layout>/page';

<DocsPage footer={options}>...</DocsPage>;
```

#### 替换页尾 [#replace-footer]

若要替换此元件：

```tsx tab="page.tsx"
import { DocsPage } from 'fumadocs-ui/layouts/<layout>/page';
import { Footer } from './my-footer';

<DocsPage
  slots={{
    footer: Footer,
  }}
/>;
```

```tsx tab="my-footer.tsx"
'use client';
import type { FooterProps } from 'fumadocs-ui/layouts/<layout>/page/slots/footer';

export function Footer(props: FooterProps) {
  return <div>Hello World</div>;
}
```

您可以使用 Fumadocs CLI，以预设实作为基础开始修改：

```bash tab="Docs Layout"
npx @fumadocs/cli add slots/docs/page/footer
```

```bash tab="Notebook Layout"
npx @fumadocs/cli add slots/notebook/page/footer
```

```bash tab="Flux Layout"
npx @fumadocs/cli add slots/flux/page/footer
```
一种导览元素，仅在使用者浏览资料夹内的页面时显示。

```tsx
import { DocsPage } from 'fumadocs-ui/layouts/<layout>/page';

<DocsPage breadcrumb={options}>...</DocsPage>;
```

#### 替换 Breadcrumb [#replace-breadcrumb]

若要替换此元件：

```tsx tab="page.tsx"
import { DocsPage } from 'fumadocs-ui/layouts/<layout>/page';
import { Breadcrumb } from './my-breadcrumb';

<DocsPage
  slots={{
    breadcrumb: Breadcrumb,
  }}
/>;
```

```tsx tab="my-breadcrumb.tsx"
'use client';
import type { BreadcrumbProps } from 'fumadocs-ui/layouts/<layout>/page/slots/breadcrumb';

export function Breadcrumb(props: BreadcrumbProps) {
  return <div>Hello World</div>;
}
```

您可以使用 Fumadocs CLI，以预设实作为基础开始修改：

```bash tab="Docs Layout"
npx @fumadocs/cli add slots/docs/page/breadcrumb
```

```bash tab="Notebook Layout"
npx @fumadocs/cli add slots/notebook/page/breadcrumb
```

```bash tab="Flux Layout"

```

```tsx tab="page.tsx"

  slots={{
```
