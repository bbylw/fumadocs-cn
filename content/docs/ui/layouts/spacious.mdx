这是 [`<DocsLayout />`](/docs/ui/layouts/docs) 较为宽松的版本：页面位于侧边栏旁的内嵌面板中，页面层级的操作则置于面板顶端。

<spacious.WithControl />

<Callout title="仅限 Base UI">
  Spacious 布局仅适用于 Base UI 版本的 Fumadocs UI (`@fumadocs/base-ui`) 。
</Callout>

<Customization />

## 使用方式 [#usage]

请通过 `fumadocs-ui/layouts/spacious` 激活 Spacious 布局。

```tsx title="layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/spacious'; // [!code highlight]
import { baseOptions } from '@/lib/layout.shared';
import { source } from '@/lib/source';
import type { ReactNode } from 'react';

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <DocsLayout {...baseOptions()} tree={source.getPageTree()}>
      {children}
    </DocsLayout>
  );
}
```

请记得一并更新页面中的导入：

```tsx title="page.tsx"
import { ... } from 'fumadocs-ui/layouts/docs/page'; // [!code --]
import { ... } from 'fumadocs-ui/layouts/spacious/page'; // [!code ++]
```

### 样式 [#styles]

与 Glass 布局相同，Spacious 布局的样式**不会**打包进 CSS 默认组合，因此只有在使用此布局时才会生成额外负担。请在你的 Tailwind CSS 文件中导入这些样式：

```css title="Tailwind CSS"
@import 'tailwindcss';
/* [!code ++] */
@import 'fumadocs-ui/css/generated/spacious.css';
@import 'fumadocs-ui/css/neutral.css';
@import 'fumadocs-ui/css/preset.css';
```

<Callout title="注意事项">
  * Spacious 布局是**客户端组件**，因此你无法从服务器组件传入无法序列化的 props。
  * 在桌面版中，页面会在面板内卷动，而不是整个窗口卷动。
</Callout>

## 设置 [#configurations]

这些选项继承自[文档布局](/docs/ui/layouts/docs)，但有些许差异：

* `sidebar` 选项仅接受 `defaultOpenLevel` 与 `prefetch`，且侧边栏一律可收合。
* 另有额外选项 (请见下方) 。

### 布局选项卡 [#layout-tabs]

使用 `tabs` prop 设置[布局选项卡](/docs/ui/layouts/docs#layout-tabs)，添加方式请参阅该链接文档。选项卡会以下拉菜单的形式显示在侧边栏顶端。

```tsx title="layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/spacious';
import { baseOptions } from '@/lib/layout.shared';
import { source } from '@/lib/source';
import type { ReactNode } from 'react';

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <DocsLayout
      {...baseOptions()}
      tabs={
        {
          // 自定义选项卡
        }
      }
      tree={source.getPageTree()}
    >
      {children}
    </DocsLayout>
  );
}
```

### AI 聊天 [#ai-chat]

传入包含打开状态与变更处理函数的 `aiChat` 对象，即可在布局中显示**询问 AI**。

使用 `panel` 选项时，布局会替你渲染聊天面板：在宽屏幕上，面板会固定在页面旁 (目录会移至页面的页眉) ；在较小的屏幕上，则会浮动显示于页面上方。

```tsx title="layout.tsx"
'use client';
import { DocsLayout } from 'fumadocs-ui/layouts/spacious';
import { useState } from 'react';

export function Layout({ children }) {
  const [open, setOpen] = useState(false);

  return (
    <DocsLayout
      // [!code ++:5]
      aiChat={{
        open,
        onOpenChange: setOpen,
        panel: <MyChat />,
      }}
      // ...
    >
      {children}
    </DocsLayout>
  );
}
```

### Slots [#slots]

除了共用的 slot (`navTitle`、`themeSwitch`、`searchTrigger`、`languageSelect`) 之外，Spacious 布局还提供 `slots` 选项，可用来覆盖版面的各个部分。

| Slot      | 说明                                               |
| --------- | ------------------------------------------------ |
| `header`  | 行动设备上的导航列。                                       |
| `sidebar` | 侧边栏系统：`provider`、`main` (桌面版) 及 `drawer` (行动版) 。 |
| `actions` | 页面右上角的操作按钮，例如语言切换器与选项菜单。                         |

```tsx title="layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/spacious';

<DocsLayout
  slots={{
    actions: MyActions, // [!code ++]
  }}
  // ...
/>;
```

## 文档页面 [#docs-page]

此页面组件与[文档页面](/docs/ui/layouts/page)类似，但有以下几点差异：

* 目录默认使用 `block` 样式。
* `tableOfContentPopover` 用于设置页面页眉中的目录下拉菜单，以及行动设备上的目录列。
* `slots.toc` 接受 `dropdown` 组件，作为页面页眉中的下拉菜单。
* 没有 `container` slot。
