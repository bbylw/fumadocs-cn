## 使用方式 [#usage]

通过 `fumadocs-ui/layouts/flux` 激活 Flux 布局。

```tsx title="layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/flux'; // [!code highlight]
import { baseOptions } from '@/lib/layout.shared';
import { source } from '@/lib/source';
import type { ReactNode } from 'react';

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <DocsLayout {...baseOptions()} tree={source.getPageTree()}>
      {children}
    </DocsLayout>
  );
}
```

请记得一并更新页面中的导入：

```tsx title="page.tsx"
import { ... } from 'fumadocs-ui/layouts/docs/page'; // [!code --]
import { ... } from 'fumadocs-ui/layouts/flux/page'; // [!code ++]
```

<Callout title="须知事项">
  * 建议搭配[静态／本地搜索](/docs/search/orama#static)使用，通过文档搜索来浏览会更有效率。
  * 它以主观美感为优先，而非用户体验。
  * 它的设计较为固定，若需要自定义，请改用 Fumadocs CLI。
</Callout>

## 设置 [#configurations]

选项继承自[文档布局](/docs/ui/layouts/docs)，但有些许差异：

* Flux 布局是客户端组件，因此你无法从服务器组件传入无法序列化的 props。
* 添加 `renderNavigationPanel` prop，可用来自定义底部的导航面板。
* 不提供 `tocPopover` 选项。
