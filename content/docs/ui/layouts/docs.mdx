文件页面的版面配置，包含侧边栏，以及**仅在行动装置上显示**的导览列／页首。

## 使用方式 [#usage]

将您的页面树传给此元件。

```tsx title="layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/docs';
import { baseOptions } from '@/lib/layout.shared';
import type { ReactNode } from 'react';

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <DocsLayout {...baseOptions()} tree={tree}>
      {children}
    </DocsLayout>
  );
}
```

有关 [`links`](/docs/ui/layouts/links) 与 [`nav`](/docs/ui/layouts/nav) 选项的详细说明，请参阅相关文件。

## 侧边栏 [#sidebar]

```tsx title="layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/docs';

<DocsLayout
  sidebar={{
    enabled: true,
  }}
/>;
```
自订侧边栏的导览连结。

<div className="flex justify-center items-center *:max-w-[200px] bg-linear-to-br from-fd-primary/10 rounded-xl border">
  ![侧边栏](/docs/sidebar.png)
</div>

侧边栏项目是根据您传入 `` 的页面树算绘而成。

若页面树来自 [`loader()`](/docs/headless/source-api)，则会依据您的档案结构产生，请参阅[可用的模式](/docs/page-conventions)。

```tsx title="layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/docs';
import { source } from '@/lib/source';
import type { ReactNode } from 'react';

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <DocsLayout
      tree={source.getPageTree()}
      // 其他 props
    >
      {children}
    </DocsLayout>
  );
}
```

您也可以直接写死在程式码中：

```tsx title="layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/docs';
import type { ReactNode } from 'react';

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <DocsLayout
      tree={{
        name: 'docs',
        children: [],
      }}
      // 其他 props
    >
      {children}
    </DocsLayout>
  );
}
```
版面配置页签是行为类似页签的资料夹，只会显示目前开启页签的内容。

<div className="flex justify-center items-center *:max-w-[360px] bg-linear-to-br from-fd-primary/10 rounded-xl border">
  ![版面配置页签](/docs/sidebar-tabs.png)
</div>

预设情况下，页签触发器会以**下拉选单**元件呈现 (只有在其中某个项目处于启用状态时才会显示) 。

页签是根据页面树产生的。您可以在资料夹中建立 `meta.json` 档案，将该资料夹标记为[根资料夹](/docs/page-conventions#root-folder)：

```json title="content/docs/my-folder/meta.json"
{
  "title": "Name of Folder",
  "description": "The description of root folder (optional)",
  "root": true
}
```

或是明确指定：

```tsx title="/app/docs/layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/docs';

<DocsLayout
  tabs={[
    {
      title: 'Components',
      description: 'Hello World!',
      // 在 `/docs/components` 及其子路由（例如 `/docs/components/button`）下启用
      url: '/docs/components',

      // 您也可以另外指定一组会启用此项目的 URL
      // urls: new Set(['/docs/test', '/docs/components']),
    },
  ]}
/>;
```

若要停用，请将其设为 `false`：

```tsx
import { DocsLayout } from 'fumadocs-ui/layouts/docs';

<DocsLayout tabs={false} />;
```

<Callout title="想要进一步自订吗？">
  您可以为[文件版面配置](/docs/ui/layouts/docs)元件指定 `banner`。

  ```tsx
  import { DocsLayout, type DocsLayoutProps } from 'fumadocs-ui/layouts/docs';
  import type { ReactNode } from 'react';
  import { baseOptions } from '@/lib/layout.shared';
  import { source } from '@/lib/source';

  export default function Layout({ children }: { children: ReactNode }) {
    return (
      <DocsLayout
        {...baseOptions()}
        tree={source.getPageTree()}
        sidebar={{
          // [!code ++]
          banner: <div>Hello World</div>,
        }}
      >
        {children}
      </DocsLayout>
    );
  }
  ```
</Callout>

#### 装饰 [#decoration]

变更版面配置页签的图示或样式。

```tsx
import { DocsLayout } from 'fumadocs-ui/layouts/docs';

<DocsLayout
  tabs={{
    transform: (option, node) => ({
      ...option,
      icon: <MyIcon />,
    }),
  }}
/>;
```
页签会依[根类型](/docs/page-conventions#root-type)分组，目前页面路径上的每个根资料夹各有一个下拉选单。

<Files>
  <Folder name="v2 (root: version)" defaultOpen>
    <Folder name="framework (root: true)" defaultOpen>
      <File name="quickstart.mdx" className="text-fd-primary! bg-fd-primary/10!" />
    </Folder>

    <Folder name="headless (root: true)">
      <File name="quickstart.mdx" />
    </Folder>
  </Folder>

  <Folder name="v1 (root: version)">
    <Folder name="framework (root: true)">
      <File name="quickstart.mdx" />
    </Folder>
  </Folder>
</Files>

在 `v2/framework/quickstart.mdx` 页面上，侧边栏会显示两个下拉选单，一个用来切换版本，另一个用来切换区段：

<div className="flex justify-center items-center *:max-w-[360px] bg-linear-to-br from-fd-primary/10 rounded-xl border">
  ![页签群组](/docs/sidebar-tabs-groups.png)

选择选项后，会前往该根资料夹中的同一页面；若该页面不存在，则前往该资料夹的索引页面。完整范例请参阅[版本控制](/docs/navigation#versioning)。

### 侧边栏元件 [#sidebar-components]

您可以替换部分用来算绘页面树的元件。

```tsx tab="layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/docs';
import { SidebarSeparator } from './layout.client';

<DocsLayout
  sidebar={{
    enabled: true,
    components: {
      Separator: SidebarSeparator,
    },
  }}
/>;
```

```tsx tab="layout.client.tsx"
'use client';
import * as Base from 'fumadocs-ui/components/sidebar/base';

export function SidebarSeparator({ className, style, children, ...props }: ComponentProps<'p'>) {
  const depth = Base.useFolderDepth();

  return (
    <Base.SidebarSeparator
      className={cn('[&_svg]:size-4 [&_svg]:shrink-0', className)}
      style={{
        paddingInlineStart: `calc(${2 + 3 * depth} * var(--spacing))`,
        ...style,
      }}
      {...props}
    >
      {children}
    </Base.SidebarSeparator>
  );
}
```

## AI 聊天 [#ai-chat]

请将您的聊天面板及其开启状态传入 `aiChat`，版面配置会在宽萤幕上将面板放在页面旁边，在较小的萤幕上则让它浮动于页面上方。

```tsx
<DocsLayout aiChat={{ open, onOpenChange: setOpen, panel: <MyChat />, trigger: true }} />
```

此版面配置本身不含「询问 AI」按钮，`trigger` 会加入一个浮动按钮。

如需现成的聊天介面，请参阅[询问 AI](/docs/integrations/llms#ask-ai)。

## 进阶 [#advanced]

### 预先载入 (Prefetching)  [#prefetching]

Fumadocs 使用您所用 React 框架的 `` 元件，并沿用其预设的预先载入行为。

在 Vercel 上，预先载入请求可能会增加 Serverless Functions 与 Data Cache 的用量，
在其他部分托管平台上也可能触及用量上限。

您可以停用预先载入以减少预先载入请求的数量，也可以明确启用：

```tsx
import { DocsLayout } from 'fumadocs-ui/layouts/docs';

<DocsLayout sidebar={{ prefetch: false }} />;
```
处理版面配置并不容易，Fumadocs UI 需要一套具备以下特性的做法：

* **可组合：** 版面配置元件应能轻松管理自身的位置与大小，最好能就地完成。
* **弹性：** 系统应避免依赖固定数值或高度，让外部元件 (例如 AI 聊天介面) 能无缝整合。
* **协调一致：** 元件应能回应其他元件的变化，例如以动画呈现侧边栏的收合。
* **可预测：** 版面配置属性应集中管理，让您能从原始码轻易预期最终结果。
* **相容：** 此解决方案应仅使用 Baseline Widely Available 的 CSS 功能，以便支援旧版浏览器。

Fumadocs UI 透过网格系统来达成这些目标：

```css
#nd-docs-layout {
  grid-template:
    'sidebar header toc'
    'sidebar toc-popover toc'
    'sidebar main toc' 1fr / minmax(var(--fd-sidebar-col), 1fr) minmax(0, var(--fd-page-col))
    minmax(min-content, 1fr);

  --fd-docs-row-1: var(--fd-banner-height, 0px);
  --fd-docs-row-2: calc(var(--fd-docs-row-1) + var(--fd-header-height));
  --fd-docs-row-3: calc(var(--fd-docs-row-2) + var(--fd-toc-popover-height));
  --fd-sidebar-col: var(--fd-sidebar-width);
  --fd-page-col: calc(
    var(--fd-layout-width, 97rem) - var(--fd-sidebar-width) - var(--fd-toc-width)
  );
  --fd-sidebar-width: 0px;
  --fd-toc-width: 0px;

  --fd-header-height: 0px;
  --fd-toc-popover-height: 0px;
}
```

* 版面配置容器采用 grid 排版，并设定 `grid-template` 以产生可预期的结果。
* `--fd-docs-row-*` 定义每一列的顶部偏移量，让带有 `position: sticky` 的元素能取得正确的顶部偏移量。
* `--fd-*-width` 与 `--fd-*-height` 由版面配置元件透过 CSS 设定，对于维持 grid 结构或计算 `--fd-docs-row-*` 而言不可或缺。
* `--fd-*-col` 为动态值，会随状态变化而更新 (例如侧边栏收合时，`--fd-sidebar-col` 会变为 `0px`) 。

预设版面配置与 Notebook 版面配置皆采用此系统。
