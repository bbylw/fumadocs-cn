以浮动、半透明 (类似玻璃) 面板为内核设计的文档布局：侧边栏与页眉并非固定的字段，而是以圆角、模糊效果的面板形式叠放在内容上方。

## 使用方式 [#usage]

通过 `fumadocs-ui/layouts/glass` 激活 Glass 布局。

```tsx title="layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/glass'; // [!code highlight]
import { baseOptions } from '@/lib/layout.shared';
import { source } from '@/lib/source';
import type { ReactNode } from 'react';

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <DocsLayout {...baseOptions()} tree={source.getPageTree()}>
      {children}
    </DocsLayout>
  );
}
```

请记得也要更新页面中的导入：

```tsx title="page.tsx"
import { ... } from 'fumadocs-ui/layouts/docs/page'; // [!code --]
import { ... } from 'fumadocs-ui/layouts/glass/page'; // [!code ++]
```

### 样式 [#styles]

与其他布局不同，Glass 布局的样式**并未**打包进 CSS 默认组合中，因此只有在你实际使用此布局时，才会增加额外负担。请在你的 Tailwind CSS 文件中导入这些样式：

```css title="Tailwind CSS"
@import 'tailwindcss';
/* [!code ++] */
@import 'fumadocs-ui/css/generated/glass.css';
@import 'fumadocs-ui/css/neutral.css';
@import 'fumadocs-ui/css/preset.css';
```

<Callout title="重要须知">
  * Glass 布局是**客户端组件**，你无法从服务器组件传入无法序列化的 props。
  * 此布局的设计较为固定：侧边栏与页眉的弹性不如默认布局，如需自定义，请使用 Fumadocs CLI 或 `slots` 选项。
</Callout>

## 设置 [#configurations]

选项继承自[文档布局](/docs/ui/layouts/docs)，但有些许差异：

* 没有 `sidebar` 选项，因为 Glass 布局的设计比默认布局更具既定风格。
* 提供额外的选项 (请见下文) 。

### 布局选项卡 [#layout-tabs]

请通过 `tabs` prop 设置[布局选项卡](/docs/ui/layouts/docs#layout-tabs)，添加方式请参阅链接的文档。选项卡会以下拉菜单的形式显示在侧边栏中。

```tsx title="layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/glass';
import { baseOptions } from '@/lib/layout.shared';
import { source } from '@/lib/source';
import type { ReactNode } from 'react';

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <DocsLayout
      {...baseOptions()}
      tabs={
        {
          // 自定义选项卡
        }
      }
      tree={source.getPageTree()}
    >
      {children}
    </DocsLayout>
  );
}
```

### AI 聊天 [#ai-chat]

浮动页眉可以渲染**询问 AI** 按钮。请传入含有打开状态与变更处理函数的 `aiChat` 对象，以控制你的 AI 搜索对话框。在宽屏幕上，布局会将你的聊天 `panel` 放在页面旁边；在较小的屏幕上，则会让它浮动于页面上方。

```tsx title="layout.tsx"
'use client';
import { DocsLayout } from 'fumadocs-ui/layouts/glass';
import { useState } from 'react';

export function Layout({ children }) {
  const [open, setOpen] = useState(false);

  return (
    <DocsLayout
      aiChat={{ open, onOpenChange: setOpen, panel: <MyChat /> }} // [!code ++]
      // ...
    >
      {children}
    </DocsLayout>
  );
}
```

### Slots [#slots]

与其他布局相同，Glass 布局提供 `slots` 选项，除了共用的 slot (`navTitle`、`themeSwitch`、`searchTrigger`、`languageSelect`) 之外，也可用来覆盖内置的 `header`、`sidebar` 和 `sidebarDrawer` (行动版) 组件。

```tsx title="layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/glass';

<DocsLayout
  slots={{
    header: MyHeader, // [!code ++]
  }}
  // ...
/>;
```
