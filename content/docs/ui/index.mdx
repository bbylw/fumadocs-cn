**Fumadocs UI** 为文档网站提供设计精美的主题。

它内置许多专为文档网站打造的交互式组件与布局，让你只需极低的代码维护成本，就能持续获得 UI 的定期改进。

你也可以使用 [Fumadocs CLI](/docs/cli) 将组件安装到本地，以取得完整的控制权。
