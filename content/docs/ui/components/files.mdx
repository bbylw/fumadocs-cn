## 使用方式 [#usage]

请用 `Files` 包裹文件组件。你可以在 MDX 内容中使用它，也可以把它当成一般的 React.js 组件使用。

```mdx title="content.mdx"
import { File, Folder, Files } from 'fumadocs-ui/components/files';

<Files>
  <Folder name="app" defaultOpen>
    <File name="layout.tsx" />
    <File name="page.tsx" />
    <File name="global.css" />
  </Folder>
  <Folder name="components">
    <File name="button.tsx" />
    <File name="tabs.tsx" />
    <File name="dialog.tsx" />
  </Folder>
  <File name="package.json" />
</Files>
```

## Remark 插件 [#remark-plugin]

[`remark-mdx-files`](/docs/headless/mdx/remark-mdx-files) 是一个 remark 插件，可提供额外的功能与语法。

```ts tab="unified" title="source.config.ts"
import { remarkMdxFiles } from 'fumadocs-core/mdx-plugins/remark-mdx-files';
import { defineConfig } from 'fumadocs-mdx/config';

export default defineConfig({
  mdxOptions: {
    // [!code ++]
    remarkPlugins: [remarkMdxFiles],
  },
});
```

```ts tab="Sätteri" title="source.config.ts"
import { remarkMdxFiles } from '@fumadocs/satteri/remark-mdx-files';
import { defineConfig, defineDocs } from 'fumadocs-mdx/config';

export const docs = defineDocs({
  docs: {
    compiler: 'satteri',
  },
});

export default defineConfig({
  satteriOptions: {
    // [!code ++]
    mdastPlugins: [remarkMdxFiles()],
  },
});
```

### 代码块语法 [#codeblock-syntax]

它会将 `files` 代码块转换为 `<Files />` 组件，例如：

````md title="content.md"
```files
project
├── src
│   ├── index.js
│   └── utils
│       └── helper.js
├── package.json
```
````

### `<auto-files>` [#auto-files]

根据 glob 模式生成 `<Files />` 组件。

```mdx title="content.mdx"
<auto-files dir="./my-dir" pattern="**/*.{ts,tsx}" />

<auto-files dir="./my-dir" pattern="**/*.{ts,tsx}" defaultOpenAll />
```

<Callout type="warn">
  请勿将不受信任的值传入 `dir`，因为它能列出你电脑上任何目录中的文件。
</Callout>
