## 使用方式 [#usage]

将此元素放在根布局的最上方，即可用来显示公告。

```tsx
import { Banner } from 'fumadocs-ui/components/banner';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        {/* [!code ++] */}
        <Banner>Hello World</Banner>
        {children}
      </body>
    </html>
  );
}
```

### 变体 [#variant]

变更默认变体。

```tsx
import { Banner } from 'fumadocs-ui/components/banner';

<Banner variant="rainbow">Hello World</Banner>;

// 自定义颜色
<Banner
  variant="rainbow"
  rainbowColors={[
    'rgba(255,100,0, 0.5)',
    'rgba(255,100,0, 0.5)',
    'transparent',
    'rgba(255,100,0, 0.5)',
    'transparent',
    'rgba(255,100,0, 0.5)',
    'transparent',
  ]}
>
  Hello World
</Banner>;
```

### 变更布局 [#change-layout]

默认情况下，横幅会使用 `style` 标签来调整 Fumadocs 的布局 (例如缩减侧边栏的高度) 。
你可以通过以下方式禁用此行为：

```tsx
import { Banner } from 'fumadocs-ui/components/banner';

<Banner changeLayout={false}>Hello World</Banner>;
```

### 关闭 [#close]

若要让用户可以关闭横幅，请为横幅设置一个 ID。

```tsx
import { Banner } from 'fumadocs-ui/components/banner';

<Banner id="hello-world">Hello World</Banner>;
```

状态会自动保存。
