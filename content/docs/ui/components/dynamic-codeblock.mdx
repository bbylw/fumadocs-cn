## 使用方式 [#usage]

### 客户端组件 [#client-component]

```tsx
import { DynamicCodeBlock } from 'fumadocs-ui/components/dynamic-codeblock';

export function MyComp() {
  const code = `console.log("Hello World")`;

  return <DynamicCodeBlock lang="ts" code={code} />;
}
```

与 MDX 的 [`CodeBlock`](/docs/ui/components/codeblock) 组件不同，这是一个客户端组件，不需要 MDX 也能使用。
它会使用 Shiki 对代码进行语法高亮，并通过默认组件进行渲染。

特色：

* 采用 React.js 19 Suspense。
* 可在服务端预先渲染。
* 在浏览器中延迟加载语言与主题。

#### 选项 [#options]

```tsx
import { DynamicCodeBlock } from 'fumadocs-ui/components/dynamic-codeblock';

<DynamicCodeBlock
  lang="ts"
  code='console.log("Hello World")'
  options={{
    themes: {
      light: 'github-light',
      dark: 'github-dark',
    },
    components: {
      // 覆盖组件（例如 `pre` 和 `code`）
    },
    // 其他 Shiki 选项
  }}
/>;
```

### 服务器组件 [#server-component]

若需要服务器组件的等效版本，你可以使用 RSC 版本：

```tsx
import { ServerCodeBlock } from 'fumadocs-ui/components/codeblock.rsc';

<ServerCodeBlock
  lang="ts"
  code='console.log("Hello World")'
  themes={{
    light: 'github-light',
    dark: 'github-dark',
  }}
  components={
    {
      // 覆盖组件（例如 `pre` 与 `code`）
    }
  }
  // 其他 Shiki 选项
/>;
```

若要改用你自己的语法高亮器，请参阅[语法高亮器](/docs/headless/utils/shiki#usage)。
