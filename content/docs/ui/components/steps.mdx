## 使用方式 [#usage]

请将步骤放入 `Steps` 容器中。

```mdx title="content.mdx"
import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>

### Hello World

</Step>

<Step>

### Hello World

</Step>
</Steps>
```

### 不使用导入 [#without-imports]

你可以直接使用 Tailwind CSS 工具类别，不需要另外导入。

```mdx
<div className="fd-steps">
  <div className="fd-step" />
</div>
```

它也支持通过任意变体 (arbitrary variants) ，只为标题应用步骤样式。

```mdx
<div className='fd-steps [&_h3]:fd-step'>

### Hello World

</div>
```

<div className="fd-steps [&_h3]:fd-step">
  ### Hello World [#hello-world]

  未使用 `<Step />` 组件即已渲染。
</div>
