此组件会根据 TypeScript 定义，为你的文档生成表格。

## 使用方式 [#usage]

```npm
npm i fumadocs-typescript
```

初始化 TypeScript 编译器，并将它加入为 MDX 组件。

```tsx title="components/mdx.tsx"
import defaultComponents from 'fumadocs-ui/mdx';
import type { MDXComponents } from 'mdx/types';
import { createGenerator, createFileSystemGeneratorCache } from 'fumadocs-typescript';
import { AutoTypeTable, type AutoTypeTableProps } from 'fumadocs-typescript/ui';

const generator = createGenerator({
  // 设置缓存，在 Vercel 等无服务器（serverless）平台上必须设置
  cache: createFileSystemGeneratorCache('.next/fumadocs-typescript'),
});

export function getMDXComponents(components?: MDXComponents) {
  return {
    ...defaultComponents,
    // [!code ++]
    AutoTypeTable: (props: Partial<AutoTypeTableProps>) => (
      <AutoTypeTable {...props} generator={generator} />
    ),
    ...components,
  } satisfies MDXComponents;
}
```

现在你可以在 MDX 内容中使用 `<AutoTypeTable />`。

更多用法请参阅 [TypeScript DocGen](/docs/markdown/typescript)。

### 从文件 [#from-file]

此组件接受 `path` prop，用来指向 TypeScript 文件，并以 `name` 指定要使用的导出类型名称。

```ts title="path/to/file.ts"
export interface MyInterface {
  name: string;
}
```

```mdx title="content.mdx"
<AutoTypeTable path="./path/to/file.ts" name="MyInterface" />
```

此路径是相对于你的项目目录 (`cwd`) 。由于 `AutoTypeTable` 是 React 服务器组件，因此无法访问 MDX 文件路径等构建时期的信息。

### 从类型生成 [#from-type]

你可以直接指定要生成的类型，不需要实际的 TypeScript 文件。

```mdx title="content.mdx"
<AutoTypeTable type="{ hello: string }" />
```

若有提供 `path`，它会与该 TypeScript 文件共用相同的上下文。

```ts title="file.ts"
export type A = { hello: string };
```

```mdx title="content.mdx"
<AutoTypeTable path="file.ts" type="A & { world: string }" />
```

当 `type` 有多行时，必须加上 export 语句并提供 `name` prop。

```mdx title="content.mdx"
<AutoTypeTable
  path="file.ts"
  name="B"
  type={`
import { ReactNode } from "react"
export type B = ReactNode | { world: string }
`}
/>
```

### 函数 [#functions]

请注意，这里仅允许对象类型。若要传入函数，请改为将其包装在对象中。

```ts
export interface MyInterface {
  myFn: (input: string) => void;
}
```

## TypeScript 编译器 [#typescript-compiler]

其底层使用 [Typescript Compiler API](https://github.com/microsoft/TypeScript/wiki/Using-the-Compiler-API) 截取类型信息，并会加载当前工作目录中的 `tsconfig.json` 文件。

你可以通过 [`createGenerator()`](/docs/markdown/typescript) 变更编译器设置。

```ts
import { createGenerator, createFileSystemGeneratorCache } from 'fumadocs-typescript';

const generator = createGenerator({
  tsconfigPath: './tsconfig.json',
  // 解析相对路径时的基准目录（通常为 cwd）
  basePath: './',
  // 其他选项……
});
```

### 文件系统 [#file-system]

由于它依赖文件系统，引用此组件的页面必须在**构建阶段**生成。在 serverless 运行时渲染此组件可能会发生问题。
