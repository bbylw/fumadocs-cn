这是一个 **MDX 组件**，需搭配 [Rehype Code](/docs/headless/mdx/rehype-code) 使用，用来显示经语法高亮的代码块。
代码块的撰写语法请参考 [Markdown](/docs/markdown#codeblock)。

支持的功能：

* 复制按钮
* 自定义标题与图标

> 如果你需要可在运行时进行语法高亮的对应组件，请参阅 [Dynamic Code Block](/docs/ui/components/dynamic-codeblock)。

## 使用方式 [#usage]

请将 pre 元素包在 `<CodeBlock />` 中，作为代码块的外层容器。

```tsx title="components/mdx.tsx"
import defaultComponents from 'fumadocs-ui/mdx';
import type { MDXComponents } from 'mdx/types';
import { CodeBlock, Pre } from 'fumadocs-ui/components/codeblock';

export function getMDXComponents(components?: MDXComponents) {
  return {
    ...defaultComponents,
    // HTML 的 `ref` 属性会与 `forwardRef` 冲突
    pre: ({ ref: _ref, ...props }) => (
      <CodeBlock {...props}>
        <Pre>{props.children}</Pre> {/* [!code highlight] */}
      </CodeBlock>
    ),
    ...components,
  } satisfies MDXComponents;
}
```

### 保留背景 [#keep-background]

使用 Shiki 生成的背景色。

```tsx
import { Pre, CodeBlock } from 'fumadocs-ui/components/codeblock';

<CodeBlock keepBackground {...props}>
  <Pre>{props.children}</Pre>
</CodeBlock>;
```

### 图标 [#icons]

若要指定自定义图标，请将 `icon` prop 传入 `CodeBlock` 组件。

默认情况下，图标会由自定义的 Shiki transformer 注入。
