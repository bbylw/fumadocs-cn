## 使用方式 [#usage]

请在你的 MDX 组件中，将 `img` 替换为 `ImageZoom`。

```tsx title="components/mdx.tsx"
import { ImageZoom } from 'fumadocs-ui/components/image-zoom';
import defaultComponents from 'fumadocs-ui/mdx';
import type { MDXComponents } from 'mdx/types';

export function getMDXComponents(components?: MDXComponents) {
  return {
    ...defaultComponents,
    // [!code ++]
    img: (props) => <ImageZoom {...(props as any)} />,
    ...components,
  } satisfies MDXComponents;
}
```

现在，所有图片都会自动启用图片缩放功能。

```mdx
![Test](/banner.png)
```

### 图片优化 [#image-optimization]

在 Next.js 中，若 `<Image />` 组件未指定 [`sizes` 属性](https://nextjs.org/docs/app/api-reference/components/image#sizes)，系统会自动为其设置默认值。

## Lightbox [#lightbox]

`<Lightbox />` 内的可缩放图片会在同一个查看器中打开，你可以使用方向键、滑动手势或侧边按钮浏览图片。

<Wrapper>
  <Lightbox>
    <div className="not-prose grid grid-cols-2 gap-2">
      <ImageZoom src="/docs/notebook-tab-mode.png" width={1453} height={963} alt="Notebook 布局" title="选项卡模式：导航列" />

      <ImageZoom
        src="/docs/notebook-nav-mode.png"
        width={1451}
        height={954}
        alt="Notebook 布局"
        caption={
      <>
        Nav 模式：顶部，请参阅 <a href="/docs/ui/layouts/notebook#nav-mode">Notebook 布局</a>
      </>
    }
      />
    </div>
  </Lightbox>
</Wrapper>

用它包覆页面内容，即可浏览整个页面中的所有图片：

```tsx title="app/docs/[[...slug]]/page.tsx"
import { Lightbox } from 'fumadocs-ui/components/image-zoom';

<DocsBody>
  {/* [!code ++] */}
  <Lightbox>
    <MDX components={getMDXComponents()} />
    {/* [!code ++] */}
  </Lightbox>
</DocsBody>;
```

### 图说 [#caption]

图片的标题 (title) 会显示为图说。

```mdx
![Notebook Layout](/notebook.png 'Tab mode: navbar')
```

若要加入链接等丰富内容，请传入 `caption`。

```tsx
<ImageZoom
  src="/notebook.png"
  alt="Notebook Layout"
  caption={
    <>
      See <a href="/docs/ui/layouts/notebook">Notebook Layout</a>
    </>
  }
/>
```

### 图库 [#gallery]

若要让一组图片可单独浏览，请将它们包在另一个 `<Lightbox />` 中，例如以网格排列：

```mdx
<Lightbox>
<div className="not-prose grid grid-cols-2 gap-2">

![Light Mode](/light.png)

![Dark Mode](/dark.png)

</div>
</Lightbox>
```
