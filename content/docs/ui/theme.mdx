## 概览 [#overview]

Fumadocs UI 通过 Tailwind CSS preset 加入专属的色彩、动画与工具类别。

### 设置 [#setup]

仅支持 Tailwind CSS v4，此 preset 也会一并将 Fumadocs UI 本身加入 source：

```css title="Tailwind CSS"
@import 'tailwindcss';
@import 'fumadocs-ui/css/neutral.css';
@import 'fumadocs-ui/css/preset.css';
```

若你使用 **Shadcn UI**，可以改用 `shadcn` 默认样式，Fumadocs UI 会直接沿用你 Shadcn UI 主题的色彩。

```css
@import 'tailwindcss';
@import 'fumadocs-ui/css/shadcn.css';
@import 'fumadocs-ui/css/preset.css';
```

详细信息请参阅[色彩](#colors)。

### Preflight 变更 [#preflight-changes]

使用 Tailwind CSS 插件或预先构建的样式表后，默认的边框、文字与背景
颜色会随之改变。

### 浅色／深色模式 [#lightdark-modes]

Fumadocs 通过 [`next-themes`](https://github.com/pacocoursey/next-themes) 支持浅色／深色模式，此功能已内置于 Root Provider 中。

详情请参阅 [Root Provider](/docs/ui/layouts/root-provider#theme-provider)。

### RTL 布局 [#rtl-layout]

支持 RTL (由右至左) 布局。

若要激活 RTL，请将 body 与 root provider 的 `dir` prop 设为 `rtl`。

```tsx
import { RootProvider } from 'fumadocs-ui/provider/<framework>';
import type { ReactNode } from 'react';

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body dir="rtl">
        <RootProvider dir="rtl">{children}</RootProvider>
      </body>
    </html>
  );
}
```

### 布局宽度 [#layout-width]

你可以使用 CSS 变量自定义文档布局的最大宽度。

```css
:root {
  --fd-layout-width: 1400px;
}
```

### 排版 [#typography]

我们内置了一个从 [Tailwind CSS Typography](https://tailwindcss.com/docs/typography-plugin) 分支 (fork) 而来的插件。

此插件提供 `prose` 类别，以及用来自定义样式的各种变体。

```tsx
<div className="prose">
  <h1>Good Heading</h1>
</div>
```

将 `prose-sm` 或 `prose-xs` 与 `prose` 搭配使用，即可应用 `text-sm` 或 `text-xs` 的字体大小与行高，并搭配经过视觉校正的字重：

```tsx
<div className="prose prose-sm">...</div>
```

> 此插件专为搭配 Fumadocs UI 的 MDX 组件而设计，因此可能会与 `@tailwindcss/typography` 发生冲突。
>
> 若你需要改用 `@tailwindcss/typography` 取代默认插件，请[设置 `className` 选项](https://github.com/tailwindlabs/tailwindcss-typography/blob/main/README.md#changing-the-default-class-name)以避免冲突。
>
> ```sass
> @import 'tailwindcss';
> @plugin "@tailwindcss/typography" {
>   className: wysiwyg;
> }
> ```
