Fumadocs UI 透过 Tailwind CSS preset 加入专属的色彩、动画与工具类别。

### 设定 [#setup]

仅支援 Tailwind CSS v4，此 preset 也会一并将 Fumadocs UI 本身加入 source：

```css title="Tailwind CSS"
@import 'tailwindcss';
@import 'fumadocs-ui/css/neutral.css';
@import 'fumadocs-ui/css/preset.css';
```

若您使用 **Shadcn UI**，可以改用 `shadcn` 预设样式，Fumadocs UI 会直接沿用您 Shadcn UI 主题的色彩。

```css
@import 'tailwindcss';
@import 'fumadocs-ui/css/shadcn.css';
@import 'fumadocs-ui/css/preset.css';
```

详细资讯请参阅[色彩](#colors)。

### Preflight 变更 [#preflight-changes]

使用 Tailwind CSS 外挂或预先建置的样式表后，预设的边框、文字与背景
颜色会随之改变。

### 浅色／深色模式 [#lightdark-modes]

Fumadocs 透过 [`next-themes`](https://github.com/pacocoursey/next-themes) 支援浅色／深色模式，此功能已内建于 Root Provider 中。

详情请参阅 [Root Provider](/docs/ui/layouts/root-provider#theme-provider)。

### RTL 版面配置 [#rtl-layout]

支援 RTL (由右至左) 版面配置。

若要启用 RTL，请将 body 与 root provider 的 `dir` prop 设为 `rtl`。

```tsx
import { RootProvider } from 'fumadocs-ui/provider/<framework>';
import type { ReactNode } from 'react';

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body dir="rtl">
        <RootProvider dir="rtl">{children}</RootProvider>
      </body>
    </html>
  );
}
```
您可以使用 CSS 变数自订文件版面配置的最大宽度。

```css
:root {
  --fd-layout-width: 1400px;
}
```


此设计系统的灵感源自 [Shadcn UI](https://ui.shadcn.com)，您也可以透过 [CSS／主题变数](https://tailwindcss.com/docs/theme)自订色彩。

```css title="global.css"
@theme {
  --color-fd-background: hsl(0, 0%, 96%);
  --color-fd-foreground: hsl(0, 0%, 3.9%);
  --color-fd-muted: hsl(0, 0%, 96.1%);
  --color-fd-muted-foreground: hsl(0, 0%, 45.1%);
  --color-fd-popover: hsl(0, 0%, 98%);
  --color-fd-popover-foreground: hsl(0, 0%, 15.1%);
  --color-fd-card: hsl(0, 0%, 94.7%);
  --color-fd-card-foreground: hsl(0, 0%, 3.9%);
  --color-fd-border: hsla(0, 0%, 80%, 50%);
  --color-fd-primary: hsl(0, 0%, 9%);
  --color-fd-primary-foreground: hsl(0, 0%, 98%);
  --color-fd-secondary: hsl(0, 0%, 93.1%);
  --color-fd-secondary-foreground: hsl(0, 0%, 9%);
  --color-fd-accent: hsla(0, 0%, 82%, 50%);
  --color-fd-accent-foreground: hsl(0, 0%, 9%);
  --color-fd-ring: hsl(0, 0%, 63.9%);
}

.dark {
  --color-fd-background: hsl(0, 0%, 7.04%);
  --color-fd-foreground: hsl(0, 0%, 92%);
  --color-fd-muted: hsl(0, 0%, 12.9%);
  --color-fd-muted-foreground: hsla(0, 0%, 70%, 0.8);
  --color-fd-popover: hsl(0, 0%, 11.6%);
  --color-fd-popover-foreground: hsl(0, 0%, 86.9%);
  --color-fd-card: hsl(0, 0%, 9.8%);
  --color-fd-card-foreground: hsl(0, 0%, 98%);
  --color-fd-border: hsla(0, 0%, 40%, 20%);
  --color-fd-primary: hsl(0, 0%, 98%);
  --color-fd-primary-foreground: hsl(0, 0%, 9%);
  --color-fd-secondary: hsl(0, 0%, 12.9%);
  --color-fd-secondary-foreground: hsl(0, 0%, 92%);
  --color-fd-accent: hsla(0, 0%, 40.9%, 30%);
```

我们内建了一个从 [Tailwind CSS Typography](https://tailwindcss.com/docs/typography-plugin) 分支 (fork) 而来的外挂。

此外挂提供 `prose` 类别，以及用来自订样式的各种变体。

```tsx
<div className="prose">
  <h1>Good Heading</h1>
</div>
```

将 `prose-sm` 或 `prose-xs` 与 `prose` 搭配使用，即可套用 `text-sm` 或 `text-xs` 的字型大小与行高，并搭配经过视觉校正的字重：

```tsx
<div className="prose prose-sm">...</div>
```

> 此外挂专为搭配 Fumadocs UI 的 MDX 元件而设计，因此可能会与 `@tailwindcss/typography` 发生冲突。
>
> 若您需要改用 `@tailwindcss/typography` 取代预设外挂，请[设定 `className` 选项](https://github.com/tailwindlabs/tailwindcss-typography/blob/main/README.md#changing-the-default-class-name)以避免冲突。
>
> ```sass
> @import 'tailwindcss';
> @plugin "@tailwindcss/typography" {
>   className: wysiwyg;
> }
> ```
