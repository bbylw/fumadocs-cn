由于 Fumadocs 的设计相当有弹性，实作存取控制十分简单。

## 载入器 API [#loader-api]

如果您使用 [`loader()`](/docs/headless/source-api) API，可以视需要建立载入器，并筛选内容来源中的档案，借此限制可存取的内容。


  例如，以下搭配 Fumadocs MDX 的设定只会显示 frontmatter 含有 `permission: public` 的 MDX 档案。

  ```ts title="lib/source.ts"
  import { docs } from 'collections/server';
  import { loader, update } from 'fumadocs-core/source';

  const filteredSource = update(docs.toFumadocsSource())
    .files((files) =>
      files.filter((file) => {
        // 保留 meta 档案（例如 `meta.json`）
        if (file.type === 'meta') return true;

        // 存取档案资料（型别安全）
        return file.data.permission === 'public';
      }),
    )
    .build();

  export const source = loader(filteredSource, {
    baseUrl: '/docs',
  });
  ```

  若设定较为复杂，您可以将 `source` 改写为工厂函式。

  ```ts title="lib/source.ts"
  import { docs } from 'collections/server';
  import { loader, update } from 'fumadocs-core/source';

  // 未快取，实际使用时建议快取在记忆体中。
  export function createSource(permission: 'public' | 'admin') {
    const filteredSource = update(docs.toFumadocsSource())
      .files((files) =>
        files.filter((file) => {
          if (file.type === 'meta') return true;

          return file.data.permission === permission;
        }),
      )
      .build();

    return loader(filteredSource, {
      baseUrl: '/docs',
    });
  }
  ```



  例如，以下设定只会显示 frontmatter 含有 `permission: public` 的页面。

  ```ts title="src/lib/source.ts"
  import { getCollection } from 'astro:content';
  import { loader, update } from 'fumadocs-core/source';
  import { toFumadocsSource } from '@fumadocs/astro/source';

  const filteredSource = update(
    toFumadocsSource(await getCollection('docs'), await getCollection('meta')),
  )
    .files((files) =>
      files.filter((file) => {
        // 保留 meta 档案（例如 `meta.json`）
        if (file.type === 'meta') return true;

        return file.data.permission === 'public';
      }),
    )
    .build();

  export const source = loader(filteredSource, {
    baseUrl: '/docs',
  });
  ```

  若设定较为复杂，您可以将 `source` 改写为工厂函式。

  ```ts title="src/lib/source.ts"
  import { getCollection } from 'astro:content';
  import { loader, update } from 'fumadocs-core/source';
  import { toFumadocsSource } from '@fumadocs/astro/source';

  const pages = await getCollection('docs');
  const metas = await getCollection('meta');

  // 未快取，实际使用时建议快取在记忆体中。
  export function createSource(permission: 'public' | 'admin') {
    const filteredSource = update(toFumadocsSource(pages, metas))
      .files((files) =>
        files.filter((file) => {
          if (file.type === 'meta') return true;

          return file.data.permission === permission;
        }),
      )
      .build();

    return loader(filteredSource, {
      baseUrl: '/docs',
    });
  }
  ```


接著为每位使用者建立来源：

```ts
// [!code --]
import { source } from '@/lib/source';
// [!code ++:4]
import { createSource } from '@/lib/source';

const user = await getUser();
const source = createSource(user.permission);

const page = source.getPage(params.slugs);
```
这种做法的特别之处在于，**存取限制是在输入层级就套用**，而不是在算绘阶段或建置时才进行。

如此可确保受保护的内容完全被过滤掉，且丝毫不牺牲弹性。

## 自订实作 [#custom-implementation]

若不使用载入器 API，请直接在 Astro 中实作存取控制，例如在路由或中介软体中处理。

例如，若要限制特定页面的存取权限：


  ```tsx title="app/docs/[[...slug]]/page.tsx"
  import { notFound } from 'next/navigation';
  import { source } from '@/lib/source';

  export default async function Page(props: PageProps<'/docs/[[...slug]]'>) {
    const params = await props.params;
    const user = await getUser();
    const page = source.getPage(params.slug);

    if (!page) notFound();
    if (page.data.permission !== user.permission) notFound();

    // 算绘页面...
  }
  ```



  ```tsx title="app/routes/docs.tsx"
  import type { Route } from './+types/docs';
  import { source } from '@/lib/source';

  export async function loader({ params, request }: Route.LoaderArgs) {
    const user = await getUser(request);
    const page = source.getPage(params['*'].split('/').filter((v) => v.length > 0));

    if (!page) throw new Response('Not found', { status: 404 });
    if (page.data.permission !== user.permission) throw new Response('Not found', { status: 404 });

    // 回传页面资料...
  }
  ```



  ```tsx title="src/routes/docs/$.tsx"
  import { notFound } from '@tanstack/react-router';
  import { createServerFn } from '@tanstack/react-start';
  import { source } from '@/lib/source';

  const serverLoader = createServerFn({ method: 'GET' })
    .validator((slugs: string[]) => slugs)
    .handler(async ({ data: slugs }) => {
      const user = await getUser();
      const page = source.getPage(slugs);

      if (!page) throw notFound();
      if (page.data.permission !== user.permission) throw notFound();

      // 回传页面资料...
    });
  ```



  ```tsx title="src/pages/docs/[...slugs].tsx"
  import type { PageProps } from 'waku/router';
  import { unstable_notFound } from 'waku/router/server';
  import { source } from '@/lib/source';

  export default async function Page({ slugs }: PageProps<'/docs/[...slugs]'>) {
    const user = await getUser();
    const page = source.getPage(slugs);

    if (!page) unstable_notFound();
    if (page.data.permission !== user.permission) unstable_notFound();

    // 算绘页面...
  }

  // 每次请求时算绘；静态页面建置时没有使用者资讯
  export const getConfig = async () => ({ render: 'dynamic' }) as const;
  ```



  ```astro title="src/pages/docs/[...slug].astro"
  ---
  import { source } from '@/lib/source';

  // 每次请求时算绘，需要转接器
  export const prerender = false;

  const slugs = Astro.params.slug?.split('/').filter((v) => v.length > 0) ?? [];
  const user = await getUser(Astro.request);
  const page = source.getPage(slugs);

  if (!page || page.data.permission !== user.permission) {
    return Astro.rewrite('/404');
  }
  ---

  <!-- 算绘页面... -->
  ```


请注意，页面树 (侧边栏项目) 、搜寻、Markdown 路由及其他细节都需要由您自行处理。

这种做法弹性最高，但 Fumadocs 不会替您处理存取控制。设定较为费工，实作时请参阅 Astro 的文件。
