---
title: 汇出 EPUB
description: 将您的文件汇出为 EPUB 格式，供电子阅读器阅读
---

EPUB 整合可让您将 Fumadocs 文件汇出为 EPUB 档案，方便读者下载您的文件，并在电子阅读器、平板电脑或任何支援 EPUB 的应用程式上阅读。

此整合会将您的 MDX 内容转换为 HTML、解析图片，并产生符合标准且附有目录的 EPUB 档案。

## 设定 [#setup]

Fumadocs CLI 可以自动帮您完成设定。它会建立一个受 `EXPORT_SECRET` 保护的汇出路由，并启用 `includeProcessedMarkdown`：

```package-install
npx @fumadocs/cli feature epub
```

或手动设定：

### 安装 [#installation]

```npm
npm install fumadocs-epub
```

  若要汇出 EPUB，必须在 docs 集合的设定中启用 `includeProcessedMarkdown`：

  ```ts title="source.config.ts"
  import { defineDocs } from 'fumadocs-mdx/config';

  export const docs = defineDocs({
    docs: {
      postprocess: {
        // [!code ++]
        includeProcessedMarkdown: true,
      },
    },
  });
  ```



  若要汇出 EPUB，必须在整合选项中启用 `includeProcessedMarkdown`：

  ```js title="astro.config.mjs"
  import { defineConfig } from 'astro/config';
  import fumadocs from '@fumadocs/astro';

  export default defineConfig({
    integrations: [
      fumadocs({
        includeProcessedMarkdown: true, // [!code ++]
      }),
    ],
  });
  ```


### 建立汇出路由 [#create-export-route]

`createEpubExportAPI` 会建立路由处理常式，并以 `secret` 加以保护：若请求未带有相符的 `Authorization: Bearer <secret>` 标头，就会遭到拒绝；若未设定密钥，路由则会回应 `503`。


  ```ts title="app/export/epub/route.ts"
  import { source } from '@/lib/source';
  import { createEpubExportAPI } from 'fumadocs-epub';

  export const revalidate = false;

  export const { GET } = createEpubExportAPI({
    source,
    title: 'My Documentation',
    author: 'My Team',
    description: 'Documentation for my project',
    cover: '/cover.png',
    secret: process.env.EXPORT_SECRET,
  });
  ```



  ```ts tab="app/routes/export.epub.ts"
  import type { Route } from './+types/export.epub';
  import { source } from '@/lib/source';
  import { createEpubExportAPI } from 'fumadocs-epub';

  const api = createEpubExportAPI({
    source,
    title: 'My Documentation',
    secret: process.env.EXPORT_SECRET,
  });

  export function loader({ request }: Route.LoaderArgs) {
    return api.GET(request);
  }
  ```

  ```ts tab="app/routes.ts"
  import { route, type RouteConfig } from '@react-router/dev/routes';

  export default [
    // [!code ++]
    route('export/epub', 'routes/export.epub.ts'),
  ] satisfies RouteConfig;
  ```



  ```ts title="src/routes/export/epub.ts"
  import { createFileRoute } from '@tanstack/react-router';
  import { source } from '@/lib/source';
  import { createEpubExportAPI } from 'fumadocs-epub';

  const api = createEpubExportAPI({
    source,
    title: 'My Documentation',
    secret: process.env.EXPORT_SECRET,
  });

  export const Route = createFileRoute('/export/epub')({
    server: {
      handlers: {
        GET: ({ request }) => api.GET(request),
      },
    },
  });
  ```



  ```ts title="src/pages/_api/export/epub.ts"
  import { source } from '@/lib/source';
  import { createEpubExportAPI } from 'fumadocs-epub';

  export const { GET } = createEpubExportAPI({
    source,
    title: 'My Documentation',
    secret: process.env.EXPORT_SECRET,
  });
  ```



  ```ts title="src/pages/export/epub.ts"
  import type { APIRoute } from 'astro';
  import { source } from '@/lib/source';
  import { createEpubExportAPI } from 'fumadocs-epub';
  import { getSecret } from 'astro:env/server';

  // 每次请求时算绘，需要转接器
  export const prerender = false;

  const api = createEpubExportAPI({
    source,
    title: 'My Documentation',
    secret: getSecret('EXPORT_SECRET'),
  });

  export const GET: APIRoute = ({ request }) => api.GET(request);
  ```


若要提供公开端点，或想自行产生档案 (例如在指令码中) ，请直接呼叫 `exportEpub()` 并回传缓冲区。

### 使用 CLI [#using-the-cli]

您也可以透过 Fumadocs CLI 汇出 EPUB：


  ```bash
  fumadocs export epub --framework next
  ```

  此指令会从执行于连接埠 `3000` (或 `PORT`) 的伺服器取得档案，并以 `EXPORT_SECRET` 环境变数作为密钥。



  ```bash
  fumadocs export epub --framework astro
  ```

  此指令会从执行于连接埠 `4321` (或 `PORT`) 的伺服器取得档案，并以 `EXPORT_SECRET` 环境变数作为密钥。



  ```bash
  fumadocs export epub --framework react-router
  ```



  ```bash
  fumadocs export epub --framework tanstack-start
  ```



  ```bash
  fumadocs export epub --framework waku
  ```


## 选项 [#options]

`exportEpub` 与 `createEpubExportAPI` 皆接受下列选项：

| 选项             | 型别                   | 说明                                                 |
| -------------- | -------------------- | -------------------------------------------------- |
| `title`        | `string`             | **必填。** 书名                                         |
| `author`       | `string \| string[]` | 作者名称 (可为多位) 。预设：`'anonymous'`                      |
| `description`  | `string`             | 书籍说明                                               |
| `language`     | `string`             | 语言代码 (例如 `'en'`) 。预设：`'en'`                        |
| `publisher`    | `string`             | 出版者名称。预设：`'anonymous'`                             |
| `isbn`         | `string`             | ISBN                                               |
| `cover`        | `string`             | 封面图片。支援 `file://`、`http(s)://`、`/public/...` 或相对路径 |
| `outputPath`   | `string`             | 若有设定，除了回传缓冲区外，也会将 EPUB 写入档案                        |
| `includePages` | `(page) => boolean`  | 筛选：只纳入此函式回传 `true` 的页面                             |
| `excludePages` | `(page) => boolean`  | 筛选：排除此函式回传 `true` 的页面                              |
| `css`          | `string`             | EPUB 的自订 CSS。若省略则使用 `defaultEpubStyles`            |
| `publicDir`    | `string`             | 用于解析 `/public/...` 图片路径的 public 目录。预设：`./public`   |

`createEpubExportAPI` 另外多了两个选项：`secret` (必填，用于保护路由) 与 `filename` (下载的档案名称，预设为 `docs.epub`) 。

### 自订 CSS [#custom-css]

您可以覆写预设的 EPUB 样式：

```ts
import { exportEpub, defaultEpubStyles } from 'fumadocs-epub';

const buffer = await exportEpub({
  source,
  title: 'My Docs',
  author: 'Me',
  css: `${defaultEpubStyles}
/* 自订覆写样式 */
body { font-size: 1.1em; }
`,
});
```
使用 `includePages` 与 `excludePages` 控制要汇出哪些文件：

```ts
const buffer = await exportEpub({
  source,
  title: 'My Docs',
  author: 'Me',
  // 仅纳入 /docs/getting-started 底下的文件
  includePages: (page) => page.path.startsWith('getting-started'),
  // 排除特定路径
  excludePages: (page) => page.path === 'changelog',
});
```
MDX 中的图片会自动解析：

* **相对路径** (例如 `./image.png`) ：以页面档案所在位置为基准解析
* **公开路径** (例如 `/og.png`) ：从 `public` 目录解析
* **远端 URL** (例如 `https://...`) ：原样嵌入
